## QuiverAI

QuiverAI is an AI company building models for vector graphics. Its official home page frames the work as "Generating, Editing, and Animating vector graphics" — production-ready, editable SVG assets for product, brand, and marketing workflows — with the tagline "Built by researchers. Made for designers." See the [official website](https://quiver.ai/).

## Products and developer entry points

- Arrow 2 model: the flagship model, described as bringing faster generation and stronger design instincts, with an Arrow 2 Telos variant; the site dates the Arrow 2 launch to September 7, 2026.
- API: `https://api.quiver.ai/v1` exposes text-to-SVG and image-to-SVG endpoints plus an OpenResponses-compatible streaming endpoint.
- Developer tools: a Node.js SDK (`@quiverai/sdk`), an npm CLI (`npx quiverai add`, which installs SVGs as React components), and an MCP server for agent workflows with plugins for Cursor and Codex.
- Use cases: logos and illustrations are listed today; typography and animation are marked "Coming soon."

See the [official site](https://quiver.ai/) and its API documentation to get started; the site offers a non-billed sandbox key (with the `sk_test_` prefix) for testing.

## Frequently asked questions

### What company is QuiverAI?

QuiverAI builds generative models for vector graphics — models (the Arrow series) that turn text or bitmaps into editable SVGs — plus a supporting API aimed at design and marketing workflows.

### Where are QuiverAI’s website and API?

The official website is [quiver.ai](https://quiver.ai/); the API base URL is `https://api.quiver.ai/v1`, with documentation and sign-up linked from the home page.

### What is Arrow 2?

Arrow 2 is QuiverAI’s flagship vector-graphics generation model, launched on September 7, 2026 and described as faster with stronger design instincts; an Arrow 2 Telos variant is also listed.

### Can I try QuiverAI for free?

The site offers a non-billed sandbox key (with the `sk_test_` prefix) that returns deterministic output for testing; for production use and commercial plans, use the site’s sign-up and "Contact sales" entries.
