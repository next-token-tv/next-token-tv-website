## Anthropic 是什么

Anthropic 自我定位为"AI 安全与研究公司"（an AI safety and research company），目标是构建可靠、可解释、可控的 AI 系统。公司是公益公司（Public Benefit Corporation），2021 年 1 月由包括 Dario Amodei 与 Daniela Amodei 姐弟在内的前 OpenAI 成员创立，总部位于旧金山。治理上，公司由董事会和 Long-Term Benefit Trust（长期受益信托）共同构成。

## 产品与开发者平台

- [Claude](/wiki/products/claude)：Anthropic 的模型与助手家族，消费者入口是 [claude.ai](https://claude.ai/)。官方公司页列出的模型家族包括 Mythos、Fable、Opus、Sonnet、Haiku。
- [Claude Code](/wiki/products/claude-code)：面向软件工程的编码 Agent；公司页还列出 Claude Cowork、Claude in Chrome、Claude for Microsoft 365 等形态。
- 开发者平台：从 [Claude API 概览](https://platform.claude.com/docs/en/api/overview)接入接口，[模型文档](https://docs.anthropic.com/en/docs/about-claude/models/overview)列出可用模型；云合作包括 AWS、Google Cloud Vertex AI 与 Microsoft Foundry。
- 官方发布：2026 年 9 月 1 日发布 Claude Fable 5.1 与 Mythos 5.1，2026 年 7 月 24 日发布 Claude Opus 5（见 [Anthropic Newsroom](https://www.anthropic.com/news)）。

产品功能与使用边界见各产品条目；本页只覆盖公司与产品线的关系。

## 常见问题

### Anthropic 是什么公司？

Anthropic 是一家 AI 安全与研究公司，公益公司（PBC）形式，2021 年由前 OpenAI 成员创立，总部位于旧金山。官方[公司页面](https://www.anthropic.com/company)写明其目标是构建可靠、可解释、可控的 AI 系统。

### Anthropic 官网在哪里？

公司官网是 [anthropic.com](https://www.anthropic.com/)，Claude 的使用入口是 [claude.ai](https://claude.ai/)，开发者文档在 [docs.anthropic.com](https://docs.anthropic.com/)。

### Anthropic 的 API 在哪里申请？

在 Anthropic 开发者平台创建账户与 API Key，按 [Claude API 概览](https://platform.claude.com/docs/en/api/overview)接入；模型能力与版本见[模型概览文档](https://docs.anthropic.com/en/docs/about-claude/models/overview)。API 与 claude.ai 订阅是分开的体系。

### Anthropic 和 Claude 是什么关系？

Claude 是 Anthropic 研发的模型与产品家族，既包括直接使用的助手，也包括 API 与编码 Agent [Claude Code](/wiki/products/claude-code)。公司背景见本页，产品细节见 [Claude 条目](/wiki/products/claude)。

### Anthropic 和 OpenAI 有什么区别？

两家都是研发前沿模型并提供消费级助手与开发者 API 的公司，但官方自述侧重点不同：Anthropic 强调"AI 安全与研究"，OpenAI 的使命是"确保通用人工智能造福全人类"（见 [OpenAI 条目](/wiki/brands/openai)）。实际差异要看各自的产品、接口与工作流，不以宣传口径为准。
