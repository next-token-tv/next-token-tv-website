## Google Cloud

Google Cloud 是 Google（Alphabet 旗下）的云计算业务与服务品牌，提供计算、存储、数据库、数据分析、网络与 AI 基础设施等产品线，业务负责人为 Thomas Kurian（据[英文维基百科](https://en.wikipedia.org/wiki/Google_Cloud)）。官方网站见 [cloud.google.com](https://cloud.google.com/)。

## 发展脉络与主要服务

- 2008 年 4 月，Google App Engine 以预览形式发布，这是 Google 的第一个云服务，2011 年 11 月正式商用。
- 此后陆续推出 Cloud Storage 与 BigQuery（2010 年进入预览）、Compute Engine（2012 年预览、2013 年正式商用）等服务，逐渐形成 Google Cloud Platform（GCP）。
- 2021 年 5 月的 Google I/O 上发布了机器学习平台 Vertex AI，是 Google Cloud 上承载 Gemini 等模型 API 的平台之一（见 [Vertex AI 条目](/wiki/products/vertex-ai)）。
- 至少自 2022 年起，Google 以"Google Cloud"作为"Google Cloud Platform"的后继名称来指代整套业务。

除基础设施外，Google Cloud 也承载面向企业的 AI 与数据分析服务，如 BigQuery、Cloud TPU 与各类机器学习 API。

## 常见问题

### Google Cloud 是什么？

Google（Alphabet 旗下）的云计算业务与服务品牌，提供计算、存储、数据库、数据分析与 AI 基础设施等产品，官网见 [cloud.google.com](https://cloud.google.com/)。

### Google Cloud 和 Google Cloud Platform 是什么关系？

Google Cloud Platform（GCP）是早期的平台名称，至少自 2022 年起 Google 用"Google Cloud"作为整套业务的后继名称（据英文维基百科）。

### Google Cloud 是从什么时候开始的？

Google 的第一个云服务 App Engine 于 2008 年 4 月以预览形式发布，2011 年 11 月正式商用；此后逐步扩展形成现在的 Google Cloud。

### Vertex AI 和 Google Cloud 是什么关系？

Vertex AI 是 2021 年 5 月发布的机器学习平台，运行在 Google Cloud 之上，承载 Gemini 等模型的 API；更多介绍见 [Vertex AI 条目](/wiki/products/vertex-ai)。

### 节目里说 Google Cloud 难用是怎么回事？

第十期中参与者反映：某新模型只有通过 Google Cloud 的 Vertex 平台才能接入，AI Studio 接不上且报错多，官方页面也难找。这些是他们当时的个人接入体验，属于对具体使用路径的评价，现状请以 [Google Cloud 官方文档](https://cloud.google.com/docs)为准。
