## Plaud 是什么

Plaud 是研发 AI 录音硬件与笔记服务的品牌，注册主体为 Plaud Inc.。官网将其定位为“AI 笔记品牌”，业务模式是硬件采集声音、软件完成转写与总结：录音设备把对话记录下来，配套的移动、Web 和桌面应用负责转写、摘要、模板化整理和检索。

## 业务与主要产品线

官网列出的硬件产品线包括：Plaud Note 与 Note Pro（卡片形态的录音设备）、Plaud NotePin 与 NotePin S（可穿戴形态），以及语音唤醒的 Plaud agent 设备 Plaud One（预购）。软件侧提供 Plaud 移动应用、Plaud Web 与 Plaud Desktop，官网还列出了开发者 SDK/API。

计费采用硬件加订阅：官网列出的 Starter 计划免费提供每月 300 分钟转写，另有按月或按年付费的 Pro 与 Unlimited 计划及团队方案，转写时长与功能各不相同。当前价格与各档差异见[官方定价页](https://www.plaud.ai/)。

官网页面未载明公司成立年份与总部所在地，本条目不作转述。当前产品线与库存状态以[官网](https://www.plaud.ai/)为准。

## 常见问题

### Plaud 是什么公司？

Plaud 是研发 AI 录音硬件与笔记服务的品牌，官网自述为 AI 笔记（note-taking）品牌，运营主体为 Plaud Inc.。产品覆盖录音硬件、转写总结软件与订阅服务，见 [plaud.ai](https://www.plaud.ai/)。

### Plaud 官网在哪里？

官网是 [plaud.ai](https://www.plaud.ai/)，提供产品购买、移动/Web/桌面应用下载入口和订阅方案说明。

### Plaud Note 和 Note Pro、NotePin 有什么区别？

按官网列示，Plaud Note 与 Note Pro 是卡片形态的录音设备，其中 Note Pro 面向更大的拾音空间；NotePin 与 NotePin S 是可穿戴形态，面向免手持的面对面记录；Plaud One 是预购中的语音唤醒设备。具体参数与适配场景见[官网产品区](https://www.plaud.ai/)。

### Plaud 有免费转写额度吗？

官网列出的 Starter 计划免费提供每月 300 分钟转写；更高时长与模板等功能在付费计划中，当前档位与价格见[官方定价页](https://www.plaud.ai/)。
