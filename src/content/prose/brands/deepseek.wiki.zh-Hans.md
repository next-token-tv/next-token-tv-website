## DeepSeek

DeepSeek 是研发 DeepSeek 模型、提供面向开发者的 API 与 Agent 工具的人工智能公司。官方首页列出 DeepSeek Web、DeepSeek App、DeepSeek Harness、API Platform 和 API Docs 等入口。

## 产品与开发者入口

用户可以从[官方产品入口](https://www.deepseek.com/)访问 Web 或 App，从[API 平台](https://www.deepseek.com/platform/)构建应用，并在[API 文档](https://api-docs.deepseek.com/)中查看当前接口。模型家族的版本、技术报告和模型卡集中在[透明度中心](https://www.deepseek.com/en/transparency/)。具体功能、价格和发布状态都应以这些官方页面的当前内容为准。

相关条目包括 [DeepSeek 模型家族](/wiki/products/deepseek)和 [DeepSeek Harness](/wiki/products/deepseek-harness)。模型家族页面说明模型与 API 的使用边界，Harness 页面介绍面向编码 Agent 工作流的框架。

## 常见问题

### DeepSeek 是什么公司，中文全称是什么？

DeepSeek 是研发人工智能模型及相关服务的公司，中文名为深度求索。官网列出的公司全称是“杭州深度求索人工智能基础技术研究有限公司”，[用户协议](https://cdn.deepseek.com/policies/zh-CN/deepseek-terms-of-use.html)也列明了该主体及其关联公司的运营关系。

### DeepSeek 是哪个国家的公司，在哪里成立？

DeepSeek 是中国公司，2023 年在杭州成立。这个成立信息可见[美联社的公司介绍](https://www.ap.org/news-highlights/spotlights/2025/what-is-deepseek-the-chinese-ai-company-upending-the-stock-market/)。

### DeepSeek 公司官网在哪里？

公司官网是 [deepseek.com](https://www.deepseek.com/)，可从中访问产品、研究资料、API 文档和招聘入口。产品使用方式另见 [DeepSeek 模型条目](/wiki/products/deepseek)。
