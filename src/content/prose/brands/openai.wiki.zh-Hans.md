## OpenAI 是什么

OpenAI 是一家人工智能研究与部署公司，2015 年成立，总部位于美国旧金山。官方"关于"页面写明其使命是"确保通用人工智能（AGI）造福全人类"（ensure that artificial general intelligence benefits all of humanity），并说明公司由非营利组织 OpenAI Foundation 治理，营利实体 OpenAI Group 以公益公司（public benefit corporation）形式运营。

## 产品与开发者平台

官网列出的主要产品线包括：

- [ChatGPT](/wiki/products/chatgpt)：面向个人和组织的 AI 助手，官网区分 ChatGPT、ChatGPT Business、ChatGPT Enterprise、ChatGPT for Education 等计划。
- [Codex](/wiki/products/codex)：面向软件开发的编码 Agent，可在编辑器、终端、桌面应用和云端工作。
- [GPT 模型家族](/wiki/products/gpt)：支撑上述产品的模型系列，当前型号与版本以官网和文档为准。
- API 平台与开发者资源：开发者在 [OpenAI API 平台](https://platform.openai.com/docs/overview)接入接口，在 [OpenAI Developers](https://developers.openai.com/)查看文档；官网还列出 Open Models 与 Apps SDK 等组件。

产品使用细节与边界见各产品条目；品牌页只覆盖公司与产品线的关系。

## 常见问题

### OpenAI 是什么公司？

OpenAI 是一家人工智能研究与部署公司，2015 年成立，总部位于旧金山。官方"关于"页面写明其使命是"确保通用人工智能造福全人类"，公司由非营利的 OpenAI Foundation 治理营利实体 OpenAI Group（公益公司形式）。详见[官方关于页面](https://openai.com/about/)。

### OpenAI 官网在哪里？

公司官网是 [openai.com](https://openai.com/)；ChatGPT 的对话入口是 [chatgpt.com](https://chatgpt.com/)；开发者文档入口是 [developers.openai.com](https://developers.openai.com/)。三者都是官方域名。

### OpenAI 的 API 在哪里接入？

开发者在 [OpenAI API 平台](https://platform.openai.com/docs/overview)创建账户和 API Key，按官方概览文档接入。API 与 ChatGPT 订阅是分开的计费体系，具体功能与额度以平台当前文档为准。

### OpenAI 有哪些主要产品？

面向个人和组织的是 [ChatGPT](/wiki/products/chatgpt)；面向软件工程的是编码 Agent [Codex](/wiki/products/codex)；面向开发者的是 API 平台和 [GPT 模型家族](/wiki/products/gpt)。官网还列出 Open Models、Apps SDK 等开发者组件。

### ChatGPT 和 OpenAI 是什么关系？

ChatGPT 是 OpenAI 旗下的一款产品，公司层面还包括模型、API 平台与开发工具。产品功能和使用边界见 [ChatGPT 条目](/wiki/products/chatgpt)，公司背景见本页"OpenAI 是什么"。
