## OpenClaw Foundation 是什么

OpenClaw Foundation 是维护开源个人 AI 助手 [OpenClaw](/wiki/products/openclaw) 的独立非营利组织。按[官网](https://openclaw.ai/)的说明，它是一家独立的美国 501(c)(3) 非营利组织，负责雇佣核心团队、为每个发布版本签名，并"keeps the whole product MIT licensed"（让整个产品保持 MIT 协议），没有企业版或付费版。OpenClaw 项目由 Peter Steinberger 创建，从周末项目发展为 GitHub 上获星最多的项目之一。

## 组织与资金

- **资金来源**：官网列出的捐赠方包括 University of Michigan、OpenAI、Amazon、Red Hat、Offline Holdings 和 Lobster Computer Company，并明确说明捐赠方不拥有、控制或指导该项目，任何模型厂商在代码中也不享有特权。
- **与 OpenAI 的关系**：官网的原话是"OpenAI is a donor and Peter Steinberger works there; OpenClaw is not an OpenAI product"——OpenAI 是捐赠方，Peter Steinberger 在 OpenAI 工作，但 OpenClaw 不是 OpenAI 的产品。
- **官方入口**：项目官网 [openclaw.ai](https://openclaw.ai/)、[官方文档](https://docs.openclaw.ai/)和 [GitHub 仓库](https://github.com/openclaw/openclaw)。

## 常见问题

### OpenClaw Foundation 是什么组织？

它是维护开源个人助手 [OpenClaw](/wiki/products/openclaw) 的独立美国 501(c)(3) 非营利组织，雇佣核心团队、为发布签名并保持产品 MIT 开源，见[官网](https://openclaw.ai/)。

### OpenClaw Foundation 和 OpenAI 是什么关系？

OpenAI 是该基金会的捐赠方之一，OpenClaw 的创建者 Peter Steinberger 在 OpenAI 工作；官网明确说明 OpenClaw 不是 OpenAI 的产品，捐赠方也不控制项目方向。

### OpenClaw 收费吗？由谁维护？

软件本身保持 MIT 协议、没有企业版或付费版，由基金会雇佣的核心团队与社区维护；成本来自用户自己的硬件与所接模型的 API 用量，代码在 [GitHub](https://github.com/openclaw/openclaw) 获取。
