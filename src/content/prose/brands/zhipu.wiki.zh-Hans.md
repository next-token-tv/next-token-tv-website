## 智谱

智谱是一家以 GLM 大模型为核心的人工智能公司，公司主体为北京智谱华章科技股份有限公司，官网自述为“中国大型独立大模型厂商”。[公司官网](https://www.zhipuai.cn/)显示其已在香港联交所上市，股票代码 02513；据[公开资料](https://en.wikipedia.org/wiki/Zhipu_AI)，公司 2019 年在北京成立，由清华大学相关研究团队孵化，[唐杰](/wiki/people/tang-jie)是创始人之一。

## 业务与主要产品线

智谱的业务围绕同一条模型主线展开：训练 GLM 模型家族，再向上提供消费者入口、开发者平台和 Agent 产品。

- 模型：截至 2026 年 9 月，官网列出 GLM-5.3（长上下文与编程）、GLM-5V-Turbo（多模态）、GLM-5-Turbo 等模型。模型家族整体介绍见 [GLM 条目](/wiki/products/glm)。
- 对话助手：面向终端用户的对话产品为智谱清言（ChatGLM），国际入口 [z.ai](https://z.ai/)。
- 开发者平台：国内的 [BigModel 开放平台](https://bigmodel.cn/)提供模型 API 与微调服务；国际 API 的模型列表和使用方式见 [Z.AI API 文档](https://docs.z.ai/)，其中包含按月订阅的 GLM Coding Plan。
- Agent 产品：[ZCode](/wiki/products/zcode) 是面向规划、编码与调试的智能体开发环境；[AutoGLM](/wiki/products/autoglm) 面向设备操作与任务执行。
- 开源：官方 GitHub 组织 [zai-org](https://github.com/zai-org) 维护 GLM 系列开源模型，以及 CodeGeeX、CogView、CogVideoX 等项目。

模型版本、能力和价格会变化，使用前应以各官方页面的当前内容为准。

## 常见问题

### 智谱是哪家公司？

智谱是以 GLM 大模型为核心的人工智能公司，公司主体为北京智谱华章科技股份有限公司，官方定位为“中国大型独立大模型厂商”，见[公司官网](https://www.zhipuai.cn/)。

### 智谱上市了吗？

上市了。官网公告显示智谱在香港联交所上市，股票代码 02513；据[公开资料](https://en.wikipedia.org/wiki/Zhipu_AI)，其于 2026 年 1 月在港交所完成 IPO。

### 智谱官网和开放平台入口在哪里？

公司官网是 [zhipuai.cn](https://www.zhipuai.cn/)，终端用户对话入口是 [z.ai](https://z.ai/)，开发者使用 [BigModel 开放平台](https://bigmodel.cn/)，国际 API 文档在 [docs.z.ai](https://docs.z.ai/)。

### 智谱 API 在哪里申请？

在 [BigModel 开放平台](https://bigmodel.cn/)（国内）或 [Z.AI API 文档](https://docs.z.ai/)（国际）注册并创建 API Key，然后按官方入门文档选择模型并调用。具体计费以平台价格页为准。

### GLM Coding Plan 是什么？

GLM Coding Plan 是智谱面向编码场景的按月订阅计划，[官方 Quick Start 文档](https://docs.z.ai/)介绍它可以配合 Claude Code、Cline 等编码工具调用 GLM 模型。订阅内容与价格以官方页面当前说明为准。
