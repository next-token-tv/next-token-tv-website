## 硅基流动是什么

硅基流动（SiliconFlow）是一家提供生成式人工智能计算基础设施与模型服务的中国公司，2023 年 8 月成立（见[官网发展历程](https://siliconflow.cn/about)），运营主体为北京硅基流动科技股份有限公司，地址位于北京市海淀区。官网自述为"独立生态词元（Token）供应平台"，使命是"加速 AGI 普惠人类"；国际站在 [siliconflow.com](https://siliconflow.com/)，其 About 页把公司目标表述为成为全球最有影响力的 AI 基础设施提供商之一。

## 业务与主要服务

按官网介绍，硅基流动的业务主要包括：

- 大模型 API 服务（MaaS）：一站式提供语言、语音、图片、视频等场景的模型 API，按量计费；平台上聚合多家厂商的模型，当前可用模型以[官方文档](https://docs.siliconflow.cn/)和模型列表为准。
- 推理加速：自研全栈推理引擎，官网称可显著降低时延、提升吞吐，并支持包括国产芯片在内的多芯片部署。
- 面向企业的专属实例与私有化部署，以及 AI 算力联合运营服务。
- 开源推理工具，如面向扩散模型的 OneDiff 和 BizyAir（见 [siliconflow.com/about](https://siliconflow.com/about)）。

## 常见问题

### 硅基流动是什么公司？

硅基流动（SiliconFlow）是 2023 年 8 月成立的生成式 AI 基础设施公司，运营主体为北京硅基流动科技股份有限公司，提供大模型 API、推理加速与企业部署服务。见[官网发展历程](https://siliconflow.cn/about)。

### 硅基流动官网在哪里？

中国站为 [siliconflow.cn](https://siliconflow.cn/)，国际站为 [siliconflow.com](https://siliconflow.com/)，文档在 [docs.siliconflow.cn](https://docs.siliconflow.cn/)。

### 硅基流动的 API Key 在哪里创建？

登录[硅基流动云控制台](https://cloud.siliconflow.cn/)后可在账户的 API 密钥页面创建，具体步骤见[官方文档](https://docs.siliconflow.cn/)。

### 硅基流动平台上有哪些模型？

平台上聚合了多家厂商的语言、语音、图片、视频模型；当前可用模型列表见[官方文档](https://docs.siliconflow.cn/)与官网模型页，不在本页固定。
