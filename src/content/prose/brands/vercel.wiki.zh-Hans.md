## Vercel 是什么

Vercel 是一家为 Web 应用提供开发、部署与托管基础设施的技术公司，由 Guillermo Rauch 于 2015 年创立，最初名为 ZEIT，2020 年 4 月更名为 Vercel，总部位于美国旧金山。官方 About 页面把公司定位为基础设施公司，提出"人与 Agent 一起构建软件的平台"，称其基础设施要同时服务于写代码的人和编码 Agent。

## 业务与主要产品

- [Vercel 平台](https://vercel.com/)：面向网站与应用的构建、部署和托管服务；据维基百科引用的第三方统计，其托管了约 1.9% 的网站，底层基础设施运行在 AWS 之上（见 [AWS 条目](/wiki/brands/aws)）。
- [Next.js](https://nextjs.org/)：Vercel 创建并维护的开源 Web 框架，最初由创始人 Rauch 开发。
- [v0](https://v0.app/)：2023 年发布的生成式 Web 开发工具，用自然语言提示生成 Web 应用。
- AI SDK：2023 年发布的 TypeScript/JavaScript 库，用于构建流式对话界面。
- Turborepo：2021 年 12 月收购的构建系统。

平台功能、套餐与区域等时效信息以 [Vercel 官网](https://vercel.com/)当前页面为准。

## 常见问题

### Vercel 是什么公司？

Vercel 是提供 Web 应用部署、托管与开发者工具的基础设施公司，2015 年由 Guillermo Rauch 创立，原名 ZEIT，2020 年更名。见[官方 About 页](https://vercel.com/about)与[维基百科条目](https://en.wikipedia.org/wiki/Vercel)。

### Vercel 和 Next.js 是什么关系？

Next.js 是 Vercel 创建并维护的开源 Web 框架，框架源码开放，Vercel 的商业平台为其提供托管与部署。框架文档见 [nextjs.org](https://nextjs.org/)。

### v0 是什么？

v0 是 Vercel 在 2023 年发布的 AI 工具，输入自然语言提示即可生成 Web 应用，入口为 [v0.app](https://v0.app/)。

### Vercel 官网在哪里？

公司官网是 [vercel.com](https://vercel.com/)，公司介绍见 [vercel.com/about](https://vercel.com/about)。
