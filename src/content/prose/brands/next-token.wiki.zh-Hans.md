## Next Token｜词元之外

Next Token｜词元之外是一档关注 AI 技术、产品、创业与创作的视频播客，同时提供音频版，从中文世界的一手经验和观点出发讨论 AI 正在改变什么。节目名称来自生成式模型不断预测的"下一个词元"（next token）；中文名"词元之外"指向预测动作之外的人、产业、产品、社会与文化。官网为 [nexttoken.tv](https://nexttoken.tv/)。

## 品牌与节目

Next Token｜词元之外是总品牌，旗下旗舰周播栏目是 [Next Token Weekly](/wiki/products/next-token-weekly)：由杨攀、歸藏、橘子和向阳乔木四位联合主理人每周以圆桌形式回顾一周的 AI 大事，通过视频、音频与 Show Notes 发布。品牌与栏目是两个层级：Weekly 是节目名，不替代平台上的正式节目名。

节目在第 001 期片头中的自我介绍是"这是一档关注 AI 技术、产品与现实影响的视频播客，同时提供音频版"（[第 001 期节目片头](/weekly/001/transcript#chapter-01)）。收看和收听入口集中在官网节目页 [nexttoken.tv/weekly](https://nexttoken.tv/weekly)，音频发布在小宇宙、Apple Podcasts 与 Spotify，视频发布在哔哩哔哩与 YouTube。线下方面，节目与象外空间、AGI Bar 等场地合作录制，[AGI Bar](/wiki/brands/agi-bar) 是其场地合作伙伴之一。

## 常见问题

### Next Token 是什么节目？

Next Token｜词元之外是一档关注 AI 技术、产品、创业与创作的视频播客，同时提供音频版。旗舰周播 Next Token Weekly 由四位联合主理人每周圆桌对谈一周的 AI 大事。这是官网与节目片头的一致自我介绍。

### Next Token 的官网在哪里？

官网是 [nexttoken.tv](https://nexttoken.tv/)，节目主页在 [nexttoken.tv/weekly](https://nexttoken.tv/weekly)，各期节目的收听、观看与文字稿入口都可以从这里进入。

### 在哪些平台可以收听或收看 Next Token Weekly？

音频在小宇宙、Apple Podcasts 与 Spotify 发布，视频在哔哩哔哩与 YouTube 发布，具体各期入口见[节目主页](https://nexttoken.tv/weekly)。

### Next Token 和 Next Token Weekly 是什么关系？

Next Token｜词元之外是总品牌，Next Token Weekly 是它旗下的旗舰周播栏目。品牌名不等于栏目名，平台上正式节目名以 Weekly 的发行信息为准。

### Next Token 的主理人是谁？

四位联合主理人是杨攀、歸藏、橘子和向阳乔木，每周轮值主持，以圆桌形式讨论。官网[节目页](https://nexttoken.tv/weekly)载明节目不设长期固定主持人。
