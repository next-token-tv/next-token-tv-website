## AWS 是什么

AWS（Amazon Web Services，中文名亚马逊云科技）是亚马逊公司旗下的云计算业务。官方概览白皮书记载，2006 年 AWS 开始以 Web 服务的形式向企业提供 IT 基础设施服务，也就是现在通称的云计算；其产品按需供应、按量计费，客户无需预先采购服务器等固定资产。

## 业务与主要服务

按同一份官方白皮书，AWS 提供的计算、存储、数据库、分析、网络、移动、开发者工具、管理工具、物联网、安全和企业应用等类别的云产品超过 200 种，服务全球 190 个国家的数十万企业。常用的计算、对象存储和无服务器服务等具体产品，可在 [AWS 官网](https://aws.amazon.com/)的产品目录中查询，实际可用区域与型号以官方页面为准。

与节目话题相关的两条线索：一是 Stripe 于 2026 年 6 月 15 日宣布与 AWS 合作，为 AI Agent 提供支付能力（见 [Stripe 新闻稿](https://stripe.com/newsroom/news)）；二是前端平台 Vercel 的托管基础设施运行在 AWS 之上（见 [Vercel 条目](/wiki/brands/vercel)）。

## 常见问题

### AWS 是什么公司？

AWS 不是一个独立公司名下的产品，而是亚马逊公司旗下的云计算业务，2006 年推出，提供按需付费的云服务。这一关系见[中文维基百科的 AWS 条目](https://zh.wikipedia.org/wiki/%E4%BA%9A%E9%A9%AC%E9%80%8A%E4%BA%91%E6%9C%8D%E5%8A%A1)与 [AWS 官方概览白皮书](https://docs.aws.amazon.com/whitepapers/latest/aws-overview/introduction.html)。

### AWS 是哪一年推出的？

官方白皮书写明，AWS 于 2006 年开始以 Web 服务形式提供 IT 基础设施服务；同年先后推出了对象存储与弹性计算两类奠基性服务。

### AWS 提供哪些类型的服务？

计算、存储、数据库、分析、网络、开发者工具、物联网、安全和企业应用等类别，总计超过 200 种云产品。完整分类见 [AWS 官方概览白皮书](https://docs.aws.amazon.com/whitepapers/latest/aws-overview/introduction.html)，最新产品列表以[官网产品目录](https://aws.amazon.com/products/)为准。

### AWS 官网在哪里？

全球站为 [aws.amazon.com](https://aws.amazon.com/)，中文站为 [aws.amazon.com/cn/](https://aws.amazon.com/cn/)，公司介绍见 [About AWS](https://aws.amazon.com/about-aws/)。
