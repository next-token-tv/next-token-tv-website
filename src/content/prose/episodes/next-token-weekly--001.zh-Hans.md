过去一周，新模型密集到几乎没有人能全部试完。GLM 5.3 Flash、Qwen 3.8 Flash Next、MiniMax H3 等新发布，把竞争从“谁更强”推向新的斩杀线：能力是否够用、成本是否足够低，以及普通人能否真正获得体验。

当模型差距越来越难靠榜单感知，免费试用、真实任务与原生 Agent 组合正在成为新的选择逻辑。我们也从 DeepSeek Harness、OpenClaw、WorkBuddy、Grok Bot 和 Omarchy 出发，讨论 Agent 为什么需要一台永不下线的电脑，以及 MCP、Skill、Connector 和 API Key 是否还应该暴露给用户。

再往下，是 Token 生意与 AI 应用的现实：顶级模型继续负责创造，便宜模型不断扩大消费场景；但算力供给、利润空间和组织迭代速度，仍决定着应用能不能成为真正的生意。

本期录制于 2026 年 9 月 3 日，新闻窗口为 8 月 27 日至 9 月 3 日。节目中的观点与预测属于参与者个人判断；产品能力、价格与数据以录制时的公开信息为准。

## 本期讨论

- 模型发布快过用户体验速度之后，我们还应该相信 Benchmark 吗？
- 为什么“便宜且够用”正在成为比绝对能力更重要的模型斩杀线？
- 常驻云端的 Agent 会不会成为下一代个人电脑？隐私与授权如何交换体验？
- “Token 是新货币”意味着什么，AI 应用为什么仍然难做出利润？
- 真正的 AI 原生组织，为什么要求每个人都能从需求到发布完成闭环？

## 人物、产品与术语

- **斩杀线**：本期借用的判断方式——一个产品要么显著更强，要么显著更便宜；缺少明确优势的中间选项会被淘汰。
- **Harness**：连接模型、工具、上下文与执行环境，让 Agent 能持续完成任务的软件框架。
- **常驻 Agent**：运行在持久化电脑或云环境中，可在用户离开设备后继续工作的 Agent。
- **Token Is New Money**：本期讨论中的比喻，指 Token 正成为数字生产力的计量与交换单位。
