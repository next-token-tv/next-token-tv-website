## 🎧 本期简介

DeepSeek 的回答快到不必盯着流式输出，搜索 API 被接进自己的 Agent；网页游戏越做越完整，旧电视换个启动器，又能接着用。这一期，我们从几个实际体验出发，聊 AI 正在怎样改变软件、内容和身边的设备。

从主机游戏移植，到用自己的工作流造剪辑工具，再到把 Codex 和 Grok Bot 搬到客厅，能动手做的事情越来越多。但便利之外，漏洞、证书和 API Key 的安全问题也集中进入了讨论：个人和团队该怎样应对变化？

后半程，我们聊 Vibe Coding 到底是在省时间，还是享受创造本身，以及怎样向 AI 提更大胆的要求。批量整理播客、找回 Slack 里漏掉的讨论、分析微信好友，用一个语音小终端连接自己的 Agent——这些已经用起来的例子，也让一个问题变得更具体：如果智能和 Token 都足够，你最想做什么？

## 💡 本期值得带走的几个问题

**速度快到一定程度，会不会改变我们对软件的想象？**

从“等它写好代码”到“直接得到结果”，大家分享了 DeepSeek 推理、搜索和语音阅读文档的体验。讨论的重点不仅是每秒多少 Token，更是等待变短之后，用户还需不需要关心工具背后的步骤。

**AI 游戏的机会，为什么不只是“用 AI 的游戏”？**

围绕 PokeBonk、游戏移植和网页分发，大家聊到一种不同的成本结构：用智能制作内容，之后由用户反复消费。生产更容易，并不等于每个人都能做出爆款；品味、体验和传播仍然是讨论的核心。

**当门槛降低，安全机制跟得上吗？**

节目从近期讨论的漏洞、证书和 API Key 泄露事件，聊到密码管理和个人 Agent 的权限边界。讨论也回到了具体的使用习惯：怎样管理账号密码，换设备时如何取回凭据，把任务交给 Agent 时又有哪些顾虑？

**Vibe Coding 是工作，还是一种新的创造游戏？**

“花钱买 Token”也可能像给游戏充值。大家分享了做游戏、造工具的快乐，也讨论什么还值得学习：怎样提出好问题、积累判断，以及和真实的人交流协作。

**如果智能和 Token 都足够，你想做什么？**

从转写几百期播客到整理公司的讨论，后半程的实践都指向同一个问题：能不能先提出想要的结果，再给 AI 足够大的空间去完成？

## 🧩 概念解释

- **Token（词元）**：模型处理与生成文本时使用的基本单位。本期围绕生成速度、任务消耗和内容制作成本展开讨论。
- **API（应用程序接口）**：供程序调用某项能力的接口。本期聊到把搜索能力接进自己的 Agent，以及组合搜索、整理和生成步骤。
- **Personal Agent（个人智能体）**：结合个人上下文、记忆与工具执行任务的 AI 助理。本期的例子包括文档朗读、信息整理和设备控制。
- **Harness**：让模型持续执行任务的外围系统，包括工具调用、任务循环和上下文管理。本期讨论它如何影响等待、并发与中途修改需求的体验。
- **Vibe Coding**：通过自然语言与 AI 反复交流来构建软件的方式。本期既聊它的生产用途，也聊做游戏、造工具本身的乐趣。
- **Skill**：供 Agent 重复使用的任务说明与配套资源，可包含步骤、脚本和素材。本期提到搜索能力封装、视频包装和转写等用法。
- **Save Time / Kill Time**：节目用来区分“节省时间”和“消遣、享受过程”的两种体验；同一件事也可能同时具备两者。
