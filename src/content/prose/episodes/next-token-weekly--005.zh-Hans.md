国庆假期，Personal Agent 成了我们的共同话题。我们从 Dots 放进 Codex 后的上手体验、记忆与云电脑权限聊起，讨论 Agent 应该是助理还是数字分身；再聊 Instinct 的订房和商旅模式，以及邮箱、微信与 RSS 的信息开放差异。

这一期也有不少亲手做项目的体验：用 Opus 5.5 写游戏、迁移插件、替换 Markdown 编辑器内核。话题随后转向 Photoshop 功能复现、GPL、游戏反编译与 Mod：当软件越来越容易被重写，分发边界、商业模式和 IP 会怎样变化？

小硬件部分，我们聊到大会发放的 ModRetro、AI Passport，以及给 ESP32 改中文界面、猫动画和语音输出的过程。小米蓝牙遥控器改成语音输入工具，也是这次的实际使用分享。最后从 Descript 的封闭接口聊到“软件成为 Agent 插件”，以及多模型协作、信息源和 Memory 的日常工作流。

## 本期讨论

- Personal Agent 应该做助理，还是做数字分身？记忆与权限如何影响实际体验？
- 从邮件到微信、RSS，信息是否开放会怎样改变 Agent 能做的事？
- 写游戏、换内核、复现功能越来越容易，软件与游戏的价值留在哪里？
- ESP32 和蓝牙遥控器这样的硬件，如何成为 Agent 的输入与输出？
- 软件该把 Agent 放进来，还是开放给现有 Agent 调用？
