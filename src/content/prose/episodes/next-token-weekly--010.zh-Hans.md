## 🎧 本期简介

一个 HTML 文件装下 20 多个 3D 模型、动作、贴图和音乐，压到 8 MB 后还能在手机上玩。歸藏分享了用 Fable 5.2 做游戏和水墨交互的经历：场景、镜头和视觉风格很快就能成形，打击感还得用反馈反复打磨。AI 把创作的起点抬高以后，人的品味体现在哪里？如果作品也更容易被复制，做出第一版之后还能积累什么？

开场聊到黄仁勋辞去英伟达总裁、CEO 和董事会成员职务。四位主理人回顾自己与英伟达有关的经历，讨论换帅之后的算力和游戏显卡。从「语言即世界」聊到 Gemini 4 Carbon 的写作和编码体验，他们也回头检查手头的工作流：模型变强以后，哪些 Skill 应该留下，哪些指令可以删？

后半程从 Instinct 的旅行案例谈起。个人 Agent 可以记住偏好、主动提醒，还能和别人的 Agent 一起安排行程。它解决的问题越多，用户往往也越愿意给它更多权限。讨论最后转向 Seedream 5.5 的图像编辑、即梦画布、近期好物，以及怎样用 Next Token Skill 找到节目原话。

## 💡 本期讨论

- **模型会做设计了，人还在哪些地方做决定？** 同样面对十个候选，能挑出最合适的方案、说清它为什么好，也是产品能力。
- **复制越来越容易，作品的价值还剩什么？** 从 Obsidian 和 OpenDesign 的例子聊到持续迭代、受众信任、分发与开源贡献者。
- **一个个人 Agent 应该拿到多少权限？** 从共享地图和行程提醒出发，聊到账号访问、敏感信息，以及产品应该在何时请求授权。
- **图像模型的稳定性和创造性如何取舍？** 用 Seedream 5.5 的编辑体验讨论，商业图像要保留哪些元素，探索新风格时又需要模型改变什么。
