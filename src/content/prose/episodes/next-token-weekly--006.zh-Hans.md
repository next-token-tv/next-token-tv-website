让 AI 给鼠标写一个 macOS 驱动，把手机录好的视频交给 Bot 剪辑、配素材、做封面，再拉几个影视角色组成自己的“AI 公司”——这一期，我们继续聊 Personal Agent，不过这次有了更多真正用起来的故事。

好用的时候，它能接住一句模糊的需求，自己找工具、调 Skill、交付作品；不好用的时候，几个 Bot 分工明确、讨论热烈，任务却迟迟做不完，Token 倒是消耗得飞快。同样是个人助理，有的能主动提醒学校通知，有的连熟悉的剪辑任务都接不住。差别究竟在模型、记忆，还是产品设计？

我们从 REA 和软硬件逆向聊起，谈到邮件钓鱼与 Agent 的权限边界，也聊国内应用生态为什么让个人助理难以施展。后半程，话题转向 Skill、开源作品和内容创作：当实现一个功能、剪出一条视频越来越容易，什么还值得持续积累？自己的素材、组件、记忆，以及让人愿意停下来看的表达，可能比再装一个工具更重要。

片尾还有一个现场彩蛋：聊完 AI，大家一起抢苹果手机。

## 💡 本期值得带走的几个问题

**“人类在 AI Native，Agent 在 Human Native”：怎么把公司的内耗也复刻了？**

这次的体验里，多角色讨论能提供不同视角，也很有参与感；但反复沟通、协调和修改可能增加耗时与 Token 消耗。大家更认可把可独立执行的工作并行分出去，而不是把每个任务都变成一场团队会议。

**个人助理为什么有的人用得很顺，有的人不知道该干什么？**

一个明确的入口、能接触到的信息，以及已有的 Skill 和素材积累，都会影响上手体验。学校通知、视频剪辑、信息整理，是这期讨论里几个具体的使用场景；产品是否能把上下文和执行过程衔接好，决定了它能不能真正交付。

**模型已经很强了，还需要 Skill 和 Prompt 吗？**

讨论里的一个观察是：基础能力可以交给模型，但个人风格、素材选择和工作习惯仍需要表达。Prompt 可以组织多个 Skill，Skill 也可以封装 Prompt；重要的是让自己的要求和已有积累能被重复使用。

**“六十分就是零分”：作品更容易做出来之后，什么更稀缺？**

片尾那句“只要 AI 把一个东西拉到六十分，那六十分就是零分”，说的是创作门槛变化后的竞争：当类似的作品谁都能做，观众为什么要看你这一份？真实素材、创意和个人辨识度因此更值得打磨。开源作品可能帮助创作者被看见，但大家也提醒，这并不意味着每个人都能获得流量或商业回报。

## 🧩 概念解释

- **Personal Agent（个人智能体）**：围绕个人需求，结合上下文、记忆和工具执行任务的 AI 助理。本期既聊生活信息管理，也聊开发和自媒体工作。
- **逆向工程（Reverse Engineering）**：通过分析已有软件或设备，理解其结构、接口与行为。节目里的驱动开发、技术栈分析和功能研究属于不同的实践场景；能分析或复现，不等于获得了开源许可。
- **Harness**：让模型能够持续执行任务的外围系统，包括工具调用、任务循环、上下文管理和执行约束。本期用它来描述逆向工具外面的 Agent 调度层。
- **Skill**：供 Agent 重复使用的任务说明与配套资源，可包含操作步骤、脚本和素材。视频剪辑、封面制作和信息整理都可以沉淀为 Skill。
- **Routine / Webhook**：Routine 指按约定触发的例行任务；Webhook 是外部系统向指定地址发送事件或数据的接口。本期讨论它们如何让 Agent 接收消息并开展后续工作。
- **Memory（记忆）**：保存并供后续任务检索的偏好、经历、项目资料等信息。本期重点是多个 Agent 之间的记忆共享，以及用项目索引找回可复用的代码与素材。
- **A-Roll / B-Roll**：A-Roll 是承载主要叙事的画面，如口播或访谈；B-Roll 是辅助说明的素材画面，如演示、照片和场景镜头。
- **TTS（Text-to-Speech，文本转语音）**：把文字转换为语音的技术。本期进一步聊到通过提示词控制角色音色、性格和表达方式的体验。
- **AI Slop**：通常用来形容批量生成、同质化且信息价值较低的 AI 内容。本期围绕模板化视频、自动回复和日报展开讨论。
