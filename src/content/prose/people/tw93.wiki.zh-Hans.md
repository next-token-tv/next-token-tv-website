## Tw93

Tw93 是一位以开源工具广为人知的产品工程师与开发者，长期在 GitHub（[Tw93](https://github.com/Tw93)）发布面向 Mac 与效率场景的工具，代表作品包括 Mac 清理与优化工具 [Mole](/wiki/products/mole)、把网页打包成桌面应用的 Pake、Markdown 写作应用妙言（MiaoYan）等。

## 经历与代表作品

以下作品均以其 GitHub 仓库的官方描述为准。

- **Mole**：Mac 清理、卸载、分析、优化与监控工具，提供免费开源的命令行版本（`mo` 命令，可经 Homebrew 安装）与单独分发的原生 Mac 应用（官网 mole.fit），代码以 GPL v3 许可发布，另有实验性的 Windows 分支。
- **Pake**：用一行命令把任意网页打包成桌面应用。
- **MiaoYan（妙言）**：轻量级 Markdown 写作应用。
- **其他**：阅读排版工具 Kami、把工程习惯封装为 Claude 技能的 Waza、面向 AI 编程的 macOS 终端 Kaku、书签工具 Maple，以及记录个人生活的 Weekly 周刊仓库。

## 节目中的提及

Tw93 未参与本页引用的节目。Weekly #003 的[常驻 Agent 与多平台内容分发](/weekly/003/transcript#chapter-19)章节中，向阳乔木说"我前几天在杭州见了 Tw93"，并转述他的用法：让 [Grok Bot](/wiki/products/grok-bot) 帮忙做多平台营销推广，推广 [Mole](/wiki/products/mole) 清理软件——用一台独立电脑定时访问欧洲、美国的一些小众论坛，交给 Grok 判断论坛调性（有的论坛喜欢独立开发者讲故事，有的喜欢知识性干货），并挑选大家"摸鱼"的时间发帖，他只需要提供内容。见[该段落](/weekly/003/transcript#quote-13cbd1a894a6c7b2bc1e)。这是向阳乔木对 Tw93 用法的转述，不代表 Tw93 本人在节目中的发言。

## 常见问题

### Tw93 是谁？

在 GitHub 发布开源工具的开发者，代表作品包括 Mole、Pake 与妙言（MiaoYan），见[其 GitHub 主页](https://github.com/Tw93)。（编辑补充；搜索联想"Tw93 github""Tw93 pake"佐证该需求）

### Mole 是什么工具？

Mole 是 Tw93 开发的 Mac 清理、卸载、分析、优化与监控工具。开源命令行版可执行 `brew install mole` 安装，代码在 GitHub 以 GPL v3 发布；原生 Mac 应用在其官网 [mole.fit](https://mole.fit/) 单独分发。（搜索联想"mole 清理工具""is Tw93 mole safe"）

### Pake 是做什么的？

把任意网页打包成桌面应用的开源工具，由 Tw93 开发，仓库见 [Tw93/Pake](https://github.com/Tw93/Pake)。（搜索联想"Tw93/pake"）
