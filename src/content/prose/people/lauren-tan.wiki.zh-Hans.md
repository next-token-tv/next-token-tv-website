## 定位

软件工程师，公开账号为 poteto，参与 AI 产品及 React 编译器相关工作。可参阅[来源资料](https://github.com/poteto)。

## 经历与代表作品

其 [GitHub 主页](https://github.com/poteto)（账号 poteto，注册于 2012 年）资料写明"Software Engineer @xai-org & @react compiler core team"，即在 xAI 任软件工程师，同时是 React compiler core team 成员；主页另列有八十多个公开仓库。React 官网[团队页](https://react.dev/community/team)将其以 Lauren Tan 之名列入 Compiler 工作组。两处官方资料对所属公司的表述存在时间差（React 官网页写"Engineer at Cursor"，GitHub 自述写 xAI），本条目不作取舍，以两处原文为准。X 账号同为 poteto。

## 节目中的提及

Lauren Tan 没有参与本期录制。第 007 期在"Omarchy、旧手机与重写软件的可能性"章节，歸藏转述：有人把 Grok Bot 里的 Linux 发行版刷成了 [Omarchy](/wiki/products/omarchy)（见[该段落](/weekly/007/transcript#quote-175a9ff7651adf1dbc74)），"然后看起来 Grok Bot 那个人很感兴趣，说 @poteto。艾特那个人，说我们想了解这个细节，你有什么卡点什么的，你跟我们说，我们想多跟你聊聊"（见[该段落](/weekly/007/transcript#quote-2563de5f754183baae93)）。@poteto 即本条目人物的公开账号；"Grok Bot 方面 @ 本人求细节"是主理人对社交媒体互动的转述，相关互动原文本条目未核验。[Grok Bot](/wiki/products/grok-bot) 为 xAI 旗下产品。

## 常见问题

### Lauren Tan 是谁？

公开账号为 poteto 的软件工程师，GitHub 自述为 xAI 软件工程师兼 React compiler core team 成员，见[其 GitHub 主页](https://github.com/poteto)。

是。poteto 是她的 GitHub 与 X 账号，GitHub 资料名为 lauren，React 官网团队页也以 Lauren Tan 之名收录她。

主理人转述称，有人把 Grok Bot 的 Linux 刷成了 Omarchy，Grok Bot 方面随后 @ poteto 表示想了解细节，见[逐字稿相关章节](/weekly/007/transcript#chapter-20)；该互动为主理人转述，本人未参与录制。
