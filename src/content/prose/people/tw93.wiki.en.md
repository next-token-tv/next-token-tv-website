## Tw93

Tw93 is a product engineer and developer known for open-source tools. He publishes Mac and productivity tools on GitHub ([Tw93](https://github.com/Tw93)), best known for [Mole](/en/wiki/products/mole), a Mac cleanup and optimization tool; Pake, which turns webpages into desktop apps; and MiaoYan, a Markdown writing app.

## Background and notable work

The descriptions below follow the official descriptions of his GitHub repositories.

- **Mole**: a Mac tool for cleaning, uninstalling, analyzing, optimizing and monitoring. It ships as a free open-source CLI (the `mo` command, installable via Homebrew) and a separately distributed native Mac app on its website [mole.fit](https://mole.fit/). The code is released under GPL v3, with an experimental Windows branch.
- **Pake**: turns any webpage into a desktop app with one command.
- **MiaoYan**: a lightweight Markdown writing app.
- **Others**: Kami (a reading/typography tool), Waza (packaging engineering habits into Claude skills), Kaku (a macOS terminal built for AI coding), Maple (a bookmarks tool), and the Weekly repository recording his personal newsletter.
