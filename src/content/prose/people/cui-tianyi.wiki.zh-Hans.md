## 定位

崔添翼（Tianyi Cui）是[DeepSeek](/wiki/brands/deepseek)旗下 DeepSeek Harness 团队（"DeepSeek Harness 组"）的成员，在微博以本名活动，账号简介的标语是"Agent = Model + Harness"。

## 经历与代表作品

其[微博账号](https://www.sina.cn/media/7542534202)（显示名"崔添翼"，2020 年 12 月注册）的置顶自我介绍写明："感谢 @微博AI 邀请入驻微博，我是 DeepSeek Harness 组的崔添翼"。账号资料定位为香港，发布的内容围绕 DeepSeek Harness 的开源与迭代、[DeepSeek](/wiki/brands/deepseek) 模型版本更新以及团队招聘信息。除微博账号信息外，其他公开履历材料有限，本条目仅记录可核验的上述事实。[DeepSeek Harness](/wiki/products/deepseek-harness) 是 DeepSeek 推出的开源 Harness（智能体运行环境），"Agent = Model + Harness" 也是该团队对智能体构成方式的表述。

## 节目中的提及

崔添翼没有参与本期录制。第 009 期在"Harness 与插件生态"章节，[DeepSeek Harness](/wiki/products/deepseek-harness) 的生态讨论中，歸藏提到与团队建立联系的过程："其实之前（崔）添翼加我了，但他比较忙"（见[该段落](/weekly/009/transcript#quote-d6c7ef56d581b4718464)）。在"Agent 与个人上下文"章节讨论 Super Agent 概念时，向阳乔木转述："因为添翼说了，它也不是说更强是吧？它只是说这个能组合出不同的 Agent 的"（见[该段落](/weekly/009/transcript#quote-cdcb2ef06db1a46e250b)）。这两处均为节目参与者对崔添翼言行的转述，不代表他本人在节目中的表态；转述的具体观点未经本人确认。

## 常见问题

### 崔添翼和 DeepSeek 是什么关系？

他是 DeepSeek 的 DeepSeek Harness 团队成员，负责该智能体运行环境相关的工作；这一身份来自其微博账号的自我介绍，账号标语"Agent = Model + Harness"与 DeepSeek Harness 的产品定位一致。
