## yetone

yetone 是开源开发者，GitHub 账号为 [yetone](https://github.com/yetone)。代表项目包括 Neovim 的 AI 编程插件 Avante（avante.nvim）和跨平台翻译工具 NextAI Translator。

## 经历与代表作品

- **[Avante（avante.nvim）](https://github.com/avante-corp/avante.nvim)**：仓库简介为 "Use your Neovim like using Cursor AI IDE!"（像使用 Cursor AI IDE 一样使用 Neovim）的 AI 编程插件，位于 avante-corp 组织下，是其 [GitHub 主页](https://github.com/yetone)的置顶项目之一。
- **[NextAI Translator](https://github.com/nextai-translator/nextai-translator)**：划词翻译浏览器插件和跨平台桌面端应用，同为 GitHub 置顶项目。项目 README 写明，由于收到 OpenAI 的商标归属警告，该项目和产品更名为 nextai translator（此前名为 openai-translator）。
- **[Magpie](https://github.com/yetone/magpie)**（[usemagpie.ai](https://usemagpie.ai)，2026 年推出）：菜单栏里的模型聚合工具，仓库简介为 "Every agent's model. One place."——让 Codex 用 DeepSeek、Claude Code 用 Kimi 等，把不同编码 Agent 接到自选模型上。
- **[Cumora](https://github.com/yetone/cumora)**（[cumora.ai](https://cumora.ai)，2026 年推出）：仓库简介为 "Where agent teams gather."——把 AI Agent 作为一等队友的跨平台团队聊天应用，支持云端或自带 Claude Code / Codex。
