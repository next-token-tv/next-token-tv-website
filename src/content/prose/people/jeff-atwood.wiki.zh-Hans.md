## Jeff Atwood

Jeff Atwood 是一名美国软件开发者（1970 年出生，据英文维基百科），以编程博客 Coding Horror 的作者身份为人所知，该博客开办于 2004 年。他是程序员问答网站 Stack Overflow 的联合创始人之一（2008 年，与 Joel Spolsky 共同创办），也是开源论坛软件 Discourse 的联合创始人。

## 经历与代表作品

**Coding Horror（2004 年）。** 据英文维基百科，Atwood 于 2004 年开办 Coding Horror 博客，写作方向是编程与"人的因素"（human factors），长期保持更新。

**Stack Overflow（2008 年）。** 他与 Joel Spolsky 于 2008 年联合创办程序员问答网站 Stack Overflow，该网站后来发展为 Stack Exchange 问答网络；据英文维基百科，Stack Overflow 在 2021 年以 18 亿美元出售给 Prosus。

**Discourse（2013 年）。** 据英文维基百科，Atwood 于 2013 年 2 月 5 日宣布创办 Civilized Discourse Construction Kit, Inc.，开发开源讨论软件 Discourse，动机是对当时论坛软件的不满；他于 2023 年 2 月 1 日卸任 CEO，转任执行董事长。产品见 [discourse.org](https://www.discourse.org/)。

**Atwood 定律。** "任何能用 JavaScript 写的应用，最终都会被 JavaScript 写出来"（原文：any application that can be written in JavaScript, will eventually be written in JavaScript）。这一被称为 Atwood 定律的说法出自他 2009 年 8 月 14 日的博客文章 "All Programming Is Web Programming"，见[原文](https://blog.codinghorror.com/all-programming-is-web-programming/)：文中写道，用 JavaScript 写 Photoshop、Word 或 Excel "毫无工程意义"，但受众与分发能力会让这类事情发生。

## 节目中的提及

Jeff Atwood 没有参与本期录制。第十期在["从一百多兆压到 8 兆：小红书小工具与浏览器分发"](/weekly/010/transcript#chapter-06)章节中，歸藏讲述他把一个 100 多兆的 HTML 游戏压缩到 8 兆并上传小红书小工具后，杨攀说他昨天在推特发帖时引用了这个定律：["之前有个叫 Atwood，有一个定律说。能用 JavaScript 实现的，最终都将被 JavaScript 实现"](/weekly/010/transcript#quote-42627bb2cf6a408257a7)，并补充说 JavaScript 运行在浏览器里、结合上 HTML。橘子接着引用 Three.js 的话：["世界终于发现大家只需要浏览器就够了"](/weekly/010/transcript#quote-95b9dee4c6549c3a2096)。这是参与者引用 Atwood 定律来支持浏览器分发效率的论点，是杨攀、橘子等人的发言，不代表 Atwood 本人在节目中的表态。

另需说明：同一期["AI 时代的人月神话：功能越多，产品越好吗"](/weekly/010/transcript#chapter-25)章节讨论了《人月神话》式的功能膨胀问题——橘子称他正在写一篇名为"AI 时代人月神话"的文章——但该章发言中并未提及 Atwood 本人；Atwood 与这本书的关联不在节目讨论范围内，本条目不作展开。

## 常见问题

### Jeff Atwood 是谁？

美国软件开发者、Coding Horror 博客（2004 年开办）作者，Stack Overflow（2008 年，与 Joel Spolsky）和 Discourse（2013 年）的联合创始人，见[英文维基百科条目](https://en.wikipedia.org/wiki/Jeff_Atwood)。

### 什么是 Atwood 定律？

Atwood 2009 年在 Coding Horror 文章 "All Programming Is Web Programming" 中的说法："any application that can be written in JavaScript, will eventually be written in JavaScript"——任何能用 JavaScript 实现的应用，最终都会被 JavaScript 实现。见[原文](https://blog.codinghorror.com/all-programming-is-web-programming/)。

### Stack Overflow 是谁创立的？

Jeff Atwood 与 Joel Spolsky 于 2008 年联合创立；网站后来发展为 Stack Exchange 问答网络，2021 年以 18 亿美元出售给 Prosus（据英文维基百科）。

### Discourse 是什么？Jeff Atwood 和它是什么关系？

Discourse 是 Atwood 于 2013 年 2 月宣布创办的 Civilized Discourse Construction Kit, Inc. 开发的开源讨论软件，见 [discourse.org](https://www.discourse.org/)；他是联合创始人，2023 年 2 月起转任执行董事长（据英文维基百科）。
