## 花叔（Huashu）

花叔是一名用 AI 做产品、以开源 Skills（技能包）闻名的创作者，GitHub 账号为 [alchaincyf](https://github.com/alchaincyf)。他在个人主页自述为"一个不会写代码的创造者"，主张用 AI 把想法直接做成产品，并把做过的项目写成教程和"橙皮书"。他的定位接近 AI 时代的独立创作者：一边做产品，一边把方法论沉淀为可复用的开源工具。

## 经历与代表作品

花叔的 GitHub 资料简介为"AI Native Coder. Ship products without writing code."，并列出他的三个代表作：女娲.skill（nuwa-skill）、花叔 Design（huashu-design）和达尔文.skill（darwin-skill）。

代表项目包括：

- [nuwa-skill（女娲.skill）](https://github.com/alchaincyf/nuwa-skill)：把一个人的心智模型、决策启发式和表达方式"蒸馏"成可反复调用的 Skill，仓序述为"你想蒸馏的下一个员工，何必是同事"。他还用女娲生成了张雪峰.skill、纳瓦尔.skill 等人物视角的衍生 Skill。
- [huashu-design（花叔 Design）](https://github.com/alchaincyf/huashu-design)：面向 Claude Code 的 HTML 原生设计 Skill，用于做原型、幻灯片、动画和信息图。
- [darwin-skill（达尔文.skill）](https://github.com/alchaincyf/darwin-skill)：一个让 Skill 自我进化的系统，按"评估→改进→测试→保留或回滚"的流程迭代。
- 其他工具向项目：huashu-chrome（让 Agent 带登录态操控 Chrome）、huashu-mac-use（操作没有 API 的 Mac 原生应用）、huashu-art-motion（用代码生成艺术风格动画）、FanBox（Coding Agent 的驾驶舱）等。
- [huashu-skills](https://github.com/alchaincyf/huashu-skills) 是他全部开源 Skills 的总目录，仓序述为包含旗舰、人物视角和内置共数十个 Skill。

除开源项目外，他把做项目的经验写成教程与"橙皮书"，发布在 [bookai.top](https://bookai.top)（该链接出自其 GitHub 个人主页）。他在个人主页中提到的产品创作经历还包括"小猫补光灯"等用 AI 做出的应用。

## 节目中的提及

花叔未参与本页引用的节目。Weekly #006 的"Skill 加上自己的名字：既方便调用，也是一次个人品牌传播"章节中，向阳乔木分享了一个技巧：把自己开源的 Skill 在仓库里统一打上名字前缀，方便对 Agent 一句话批量安装。杨攀接着说"就是乔木的 Skill 前缀都是带乔木的，那个谁花叔也是吧？"，歸藏回应"对，现在都是"（见[该段落](/weekly/006/transcript#quote-a48bc5e8247526f63f99)）。这里花叔被作为给开源 Skill 加个人名字前缀的创作者之一提及，属于杨攀的发言，不代表花叔本人的表态。他的开源仓库（如 huashu-design 等）确实使用 huashu 前缀，与这一说法一致。可阅读[第 006 期对应章节](/weekly/006/transcript#chapter-19)。

## 常见问题

### 花叔是谁？

花叔（GitHub: [alchaincyf](https://github.com/alchaincyf)）是一名用 AI 做产品的创作者和开源 Agent Skills 作者，代表作有女娲.skill、花叔 Design、达尔文.skill 等，自称"不会写代码的创造者"。

### 女娲.skill 是什么？

一个开源 Skill 生成工具，把一个人的心智模型、决策方法和表达方式蒸馏成可反复调用的 Skill；张雪峰.skill、纳瓦尔.skill 等人物视角 Skill 即由女娲生成，详见 [nuwa-skill 仓库](https://github.com/alchaincyf/nuwa-skill)。

### 花叔的开源 Skills 在哪里获取？

他的 [GitHub 主页](https://github.com/alchaincyf)下有各 Skill 的独立仓库，[huashu-skills](https://github.com/alchaincyf/huashu-skills) 是全部 Skills 的总目录，含分层分类与安装说明。
