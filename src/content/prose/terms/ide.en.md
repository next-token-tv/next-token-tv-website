## Definition

An integrated development environment (IDE) is a single graphical application that combines code editing, building, debugging and running. Xcode, Android Studio and Visual Studio Code are common examples.

## How it works

The editor provides syntax highlighting, completion and refactoring. When a build is triggered, the IDE invokes the underlying toolchain — compilers, interpreters — to do the actual work; a debugger works with breakpoints to inspect variables and call stacks. The IDE's value is wiring these steps into one coherent experience.

## Usage

Mobile and large engineering projects often depend on an IDE to manage complex build configurations and debugging. Other developers prefer a lightweight editor plus [CLI](/en/wiki/terms/cli) tools to accomplish the same work.

## Related and confusable terms

The difference from a [CLI](/en/wiki/terms/cli) is mostly the interaction model: an IDE is graphical, a CLI is text-based — but the two are not exclusive, since IDEs frequently wrap command-line tools.
