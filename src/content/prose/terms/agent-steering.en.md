## Definition

Agent steering supplies additional instructions or corrections while an agent is working so subsequent actions can respond to new input.

## Usage and related concepts

It differs from waiting for completion before sending a follow-up. Systems vary in when input is applied and how running tools are handled. Steering does not automatically undo actions already performed.
