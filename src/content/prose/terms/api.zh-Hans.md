## 定义

应用程序编程接口（API）是一套约定，规定软件组件之间如何调用功能、传递参数和接收结果。调用方只需遵循约定，不需要了解被调用方的内部实现。

## 工作方式

调用方按接口文档构造请求，例如 HTTP 请求中的方法、路径、参数与认证信息；被调用方处理请求后，按约定的数据格式（常见为 JSON）返回响应。接口文档规定了可用的操作、输入输出和错误处理方式。

## 使用场景

网页和 App 通过 Web API 获取天气、支付、地图等服务的数据；操作系统与类库也以 API 的形式向开发者暴露能力，例如浏览器提供的 DOM API 与文件系统接口。

## 易混概念

[SDK](/wiki/terms/sdk) 是打包好的一套库、工具与文档，通常围绕某个 API 帮开发者更快接入；[CLI](/wiki/terms/cli) 是给人用的文本命令接口，而 API 是给程序调用的接口。很多服务同时提供 API、SDK 与 CLI 三种接入方式。
