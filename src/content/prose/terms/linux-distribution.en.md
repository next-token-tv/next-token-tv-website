## Definition

A Linux distribution combines the Linux kernel with user programs, system tools, and software management into an installable operating system.

## Usage and related concepts

Distributions differ in default configuration, repositories, and update policies. A kernel, a distribution, and a desktop environment occupy different layers; changing distributions is more than replacing an application interface.
