## 定义

超文本标记语言（HTML）是定义网页结构与内容的标记语言，用元素和属性描述标题、段落、链接、图片等，由 WHATWG 维护为 HTML Living Standard。

## 工作方式

浏览器获取 HTML 文档后将其解析成 DOM 树，再结合 CSS 与 JavaScript 完成渲染与交互。元素以标签书写（如 `<a>`、`<p>`、`<img>`），语义化标签还能向搜索引擎和辅助技术传达含义。

## 使用场景

HTML 是所有网页的基础；HTML 邮件模板与文档导出格式中也常见内嵌的 HTML 片段。

## 易混概念

[DOM](/wiki/terms/dom) 是浏览器解析 HTML 之后生成的可编程对象树，不是同一回事；[Markdown](/wiki/terms/markdown) 语法更简、常转换为 HTML；[JSON](/wiki/terms/json) 存放结构化数据而非文档结构。
