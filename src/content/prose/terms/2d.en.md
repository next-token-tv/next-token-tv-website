## Definition

2D refers to a plane with only two dimensions, length and width. 2D computer graphics work directly with images on a flat surface rather than building solid models, making it the oldest and most widespread form of computer graphics.

## How it works

2D imagery is represented by pixels (bitmaps) or mathematically described shapes (vectors), and drawing amounts to arranging shapes, text and colors on a plane by coordinates. A display's picture is itself two-dimensional.

## Usage

Illustration, interface icons, layout, 2D animation and web graphics all fall under 2D graphics. [SVG](/en/wiki/terms/svg) and [GIF](/en/wiki/terms/gif) are typical 2D image formats on the vector and bitmap paths respectively.

## Related and confusable terms

The difference between 2D and [3D](/en/wiki/terms/3d) is whether a solid model is involved: 3D models objects first and renders them into a flat image, while 2D draws directly on the plane.
