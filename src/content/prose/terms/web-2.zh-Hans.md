## 定义

Web 2.0 是 2004 年前后由 O'Reilly Media 推广的概念，指以用户生成内容、参与式社区和网站作为平台为特征的互联网阶段。

## 工作方式

网页从静态文档变为可读写的平台：用户在博客、维基与社交网络上发布内容，网站开放 [API](/wiki/terms/api) 供第三方组合数据，[RSS](/wiki/terms/rss) 订阅与标签让信息可以被聚合与再组织。

## 使用场景

博客、维基百科、社交网络、视频社区等参与者主导的产品形态，都建立在 Web 2.0 的思路上。

## 易混概念

Web 2.0 描述的是互联网使用方式与产品形态的变迁，而非某项具体技术；开放 [API](/wiki/terms/api) 是它常用的实现手段之一，但二者一个指时代与理念，一个指接口技术。
