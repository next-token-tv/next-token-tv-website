## Definition

A cache stores reusable data or computed results so later requests can avoid repeating the full retrieval or computation.

## Usage and related concepts

Browser assets, query results, and model context may all be cached. Reuse depends on the data and system rules, while stale entries need updating or invalidation. Different systems implement different caching mechanisms.
