## 定义

智能体记忆指 AI 系统跨会话持久保存并复用信息的机制：对话结束后，用户的事实、偏好与工作内容仍被留存，供之后调用。它通常落在单次对话的上下文窗口之外，以文件或数据库等形式长期存在。

## 工作方式

常见做法是把记忆读写到外部存储——文件、向量库或结构化数据——由智能体在需要时检索并注入上下文。记忆又常分为短期（会话内的状态）与长期（跨会话的持久信息）两类，写入什么、何时检索是产品设计的核心问题。

## 使用场景

这一用法在 Next Token 节目的讨论中反复出现：参与者谈到 ChatGPT、豆包等产品的 Memory，也谈到把个人记忆放在 Markdown 文件与 Git 仓库里自管的方案，以及手机助手把收藏行为自动写入 Memory 的例子。共性是让智能体"认识你"，不必每次从头介绍自己。

## 易混概念

记忆与[上下文](/wiki/terms/context)经常被放在一起谈：上下文指一次推理时模型实际能看到的输入窗口，转瞬即逝；记忆是跨会话的持久信息，需要在需要时进入上下文才会生效。节目中也出现过"是 Memory 还是 Context"的当场追问。
