## Definition

llms.txt is a proposed file convention for giving language models and agents a concise information entry point to a website.

## Usage and related concepts

The file can introduce a site and link important documentation. It differs from robots.txt crawling directives, grants no access rights, and does not guarantee that every agent will read it.
