## Definition

Platform as a service provides an environment for deploying and running applications while the provider manages underlying infrastructure.

## Usage and related concepts

Users focus on their applications and settings rather than administering every underlying layer. PaaS differs from consuming finished software as SaaS; managed hosting does not eliminate application configuration or credential responsibilities.
