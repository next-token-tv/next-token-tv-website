## Definition

An API key is an identifier or credential supplied with API requests, often linking usage to a project, quota, or billing account.

## Usage and related concepts

The authority attached to a key depends on the service; it need not represent a complete user identity. A key is distinct from the API itself, a user password, or a public-key certificate.
