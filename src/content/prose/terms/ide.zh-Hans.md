## 定义

集成开发环境（IDE）是把代码编辑、构建、调试和运行等功能集成在同一图形界面中的开发软件。Xcode、Android Studio 和 Visual Studio Code 都是常见例子。

## 工作方式

编辑器提供语法高亮、补全与重构；保存或触发构建时，IDE 调用编译器、解释器等底层工具链完成实际工作；调试器配合断点查看变量与调用栈。IDE 的价值在于把这些流程整合成连贯的体验。

## 使用场景

移动端和大型工程项目常依赖 IDE 管理复杂的构建配置与调试流程；也有开发者选择轻量编辑器加 [CLI](/wiki/terms/cli) 工具的组合完成同样的工作。

## 易混概念

与 [CLI](/wiki/terms/cli) 的区别主要在交互方式：IDE 靠图形界面，CLI 靠文本命令，但两者并不互斥——IDE 内部往往封装了命令行工具。
