## Definition

The episode uses “trust flywheel” to describe a loop between personal agents and their users. When an agent repeatedly delivers useful results, users may delegate more tasks. The added context can help the agent offer more relevant support.

## Example

A travel agent can offer better reminders after learning an itinerary and dietary preferences. Each new account or data permission still calls for a decision based on the task.
