## 定义

运行时（runtime）指程序实际执行时所处的环境与支撑系统，包括内存管理、任务调度、标准库以及与操作系统的交互。这个词也常指承载某种语言执行的具体软件，例如 Node.js 或浏览器中的 JavaScript 引擎。

## 工作方式

程序启动后，由运行时负责加载代码、分配内存、执行并回收资源；带垃圾回收的语言由运行时自动管理内存。运行时通过内置 API 向程序暴露能力，比如读写文件或发起网络请求。

## 使用场景

同一段 JavaScript 在浏览器运行时里可以操作页面，在 Node.js 运行时里则可以读写文件——程序能用哪些内置能力取决于运行时。Java 程序则运行在 JVM 之上。

## 易混概念

[API](/wiki/terms/api) 是运行时暴露给程序的调用约定，运行时则是执行这些调用所在的环境。运行时（runtime）与编译时（compile time）相对：前者是程序执行阶段，后者是把源码翻译为目标代码的阶段。
