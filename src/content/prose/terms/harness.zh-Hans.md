## 定义

智能体运行框架（Agent Harness）指包围模型的软件运行层：它把一个只会生成文本的模型，变成能实际执行任务的[智能体](/wiki/terms/agent)。Anthropic 在描述 Claude Agent SDK 时直接使用了"agent harness"一词。

## 工作方式

运行框架负责驱动智能体循环——收集上下文，然后调用工具采取行动，再核验结果并重复。它管理着工具接入、上下文窗口、权限控制与错误处理，让模型不必关心底层细节，只需专注于决策。

## 使用场景

Claude Code 就是运行框架的一个代表：同一个模型配上不同的框架，就能分别胜任编码、深度研究或浏览器操作。对开发者而言，选择或实现一个运行框架，是构建智能体应用的主要工程工作之一。

## 易混概念

运行框架与[智能体](/wiki/terms/agent)是"底座与产物"的关系：框架提供循环与工具，智能体是框架之上的行为主体。它还决定了[多智能体协作](/wiki/terms/agent-teams)如何编排；框架加载的领域扩展通常以[智能体技能](/wiki/terms/agent-skills)的形式提供。
