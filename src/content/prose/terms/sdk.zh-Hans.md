## 定义

软件开发工具包（SDK）是面向特定平台或服务的开发资源集合，通常包含类库、API、文档、示例代码以及构建与调试工具。目标是让开发者不必从零开始，就能在目标平台上开发应用或接入服务。

## 工作方式

开发者在项目中引入 SDK 提供的库并调用其中的接口，SDK 内部再把调用转换为对平台能力或远程服务的请求；构建时，工具链会把依赖 SDK 的代码打包成可运行的应用。

## 使用场景

为 iOS 或 Android 开发应用需要安装对应平台的 SDK；接入支付、地图、统计等第三方服务时，通常也优先使用官方 SDK 而不是直接调用底层 API。

## 易混概念

[API](/wiki/terms/api) 是调用约定本身，SDK 则是把库、工具与文档打包后的实体，很多 SDK 的核心内容就是封装好的 API。开发者还常配合 [CLI](/wiki/terms/cli) 工具完成基于 SDK 的构建、模拟器管理与部署。
