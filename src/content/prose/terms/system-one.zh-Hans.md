## 定义

System One（System One Model，系统一模型）是 TypeSafe AI 提出的模型类别，官方定义为"构建用来做快速、结构化决策、供软件直接使用的一类前沿模型"。它不是心理学概念本身，而是一家公司对自家模型类的命名；命名借自卡尼曼《思考，快与慢》中快速直觉的 System 1 与缓慢深思的 System 2 之分。

## 工作方式

按官方口径，这类模型不逐 token 生成供人阅读的文本，而是传入状态（state）和带类型的问题，直接返回结构化的值、概率分布和置信度，官方称其采用新的架构与并行采样方式。官方把 Jev 称为第一款公开的 System One 模型，接口归纳为 Choice、Score、Noul 三类判断原语。

## 使用场景

官方定位是软件工作流中的快速结构化判断层：分类、路由、评分、抽取、批量筛选，以及校验大语言模型的输出。节目第 003 期有多个章节讨论 Jev 的实际用法与局限，详见站内 Jev 模型的产品页。

## 易混概念

与 [Token](/wiki/terms/token) 的关系：System One 模型仍以 token 为基础的技术栈命名体系为背景，但官方描述它不走逐 token 生成文本的路径，所以与聊天模型的关键差异不在 token 本身，而在输出是结构化判断还是自由文本。也要区分 System One（产品类别名）与心理学中泛指直觉思维的 System 1。
