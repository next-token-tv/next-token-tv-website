## 定义

图形用户界面（GUI，Graphical User Interface）是让用户通过窗口、图标、菜单和指针等可视元素操作计算机的界面，取代需要记忆命令的纯文本命令行。这一思路源自 Xerox PARC 的研究，后经 Apple Macintosh 与 Microsoft Windows 推广，成为桌面系统的主流形态。

## 工作方式

GUI 依赖"所见即所指"的隐喻：屏幕上的图标和窗口对应文件与程序，用户用鼠标或触控进行指向、点击与拖拽。系统监听这些输入事件，更新界面状态并给出视觉反馈。

## 使用场景

桌面与移动操作系统、网页以及绝大多数应用软件都以 GUI 为主要交互方式。凡是面向大众、需要降低学习成本的软件，通常优先提供 GUI。

## 易混概念

GUI 是 [UI](/wiki/terms/ui) 的一种具体形态：UI 泛指一切人机交互接触面，还包括命令行与语音界面。[UX](/wiki/terms/ux) 则更进一步，关注用户使用产品的整体过程与感受，而不只是界面本身。
