## Definition

Firmware is program code and data held in a device’s nonvolatile storage to implement basic device functions.

## Usage and related concepts

Firmware updates can alter device behavior and capabilities but must match the hardware. In device modification, a “ROM” often means a system image; this differs from ROM as a hardware storage technology.
