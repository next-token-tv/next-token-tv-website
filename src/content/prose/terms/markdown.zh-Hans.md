## 定义

Markdown 是一种轻量级标记语言，用易读的纯文本符号（如 `#`、`*`、`>`）表示标题、列表、链接、引用等结构，编写后可转换为 HTML 等格式。

## 工作方式

作者直接编写纯文本，渲染器解析这些记号并输出 HTML 或其他格式。原始语法在不同工具间存在方言差异，CommonMark 规范为此统一了解析行为，Daring Fireball 的语法文档则是最初的参考。

## 使用场景

GitHub README、技术文档、博客与静态网站生成器（如 Astro、Hugo）都使用 Markdown；因为它是纯文本，非常适合版本控制和跨平台协作。

## 易混概念

[HTML](/wiki/terms/html) 直接描述网页结构，Markdown 则以可读性为先、通常再转换成 HTML；[JSON](/wiki/terms/json) 面向机器解析的结构化数据，不用于排版正文。
