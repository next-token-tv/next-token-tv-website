## Definition

A coding agent is an [agent](/en/wiki/terms/agent) focused on software development. It uses tools in a repository and development environment to read and edit files, execute commands, run tests, and continue working from the results.

## How it works

Given a failing test, a coding agent can find the relevant implementation, change it, and rerun the test. Common tasks include understanding code, implementing features, debugging, and refactoring. Available actions depend on its tools and permissions.

## Related concepts

Coding Agent describes a system's capabilities and workflow, rather than a particular model or product. [Claude Code](/en/wiki/products/claude-code) is a concrete tool. [Vibe Coding](/en/wiki/terms/vibe-coding) describes a human approach to programming with AI; using a coding agent can still involve careful code review and testing.
