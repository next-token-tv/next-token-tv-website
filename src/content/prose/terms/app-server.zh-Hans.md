## 定义

应用服务器是承载应用业务逻辑、向客户端提供应用层服务的软件环境。典型例子有 Java 生态的 Tomcat、Jetty，以及各种语言的 Web 框架运行时（如 Node.js、Gunicorn）。

## 工作方式

请求通常先到达 Web 服务器或反向代理，动态请求再被转发给应用服务器，由它执行应用代码、访问数据库后生成响应。它能管理进程或线程池、连接池等运行时资源，让开发者专注业务逻辑。

## 使用场景

几乎每一个需要动态处理的网站与 API 服务背后都有应用服务器：电商下单、内容后台、模型推理接口都运行在这类环境里。部署时通常一台 [VPS](/wiki/terms/vps) 上就运行着一个或多个应用服务器实例。

## 易混概念

应用服务器与 [server](/wiki/terms/server) 不同：前者是软件概念（运行应用的程序），后者既可指硬件也可指监听请求的软件；与 [ssh](/wiki/terms/ssh) 更是两个层面——SSH 是用来远程管理这些服务器的协议。
