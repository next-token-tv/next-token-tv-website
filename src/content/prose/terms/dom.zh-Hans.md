## 定义

文档对象模型（DOM）是浏览器把 HTML 或 XML 文档解析成的对象树，节点对应元素、文本和属性。程序通过标准接口读写这棵树，从而查询和修改页面。DOM 标准由 WHATWG 维护。

## 工作方式

加载文档后，解析器构建节点树；JavaScript 通过 `document` 等入口查询节点、修改属性或插入新节点，浏览器随后更新渲染。监听点击、输入等事件也发生在 DOM 节点上。

## 使用场景

前端框架与库底层最终都通过 DOM 操作更新界面；动态加载内容、实现交互效果和改进无障碍支持，都依赖页面的 DOM 结构。

## 易混概念

[HTML](/wiki/terms/html) 是描述文档的源码文本，DOM 是解析后可操作的内存对象树——修改 DOM 不会改动服务器上的原始 HTML 文件。
