## Definition

Environment variables are named values supplied to a process by its execution environment, commonly for configuration, paths, or service connections.

## Usage and related concepts

The same program can receive different settings in different environments without changing its code. Variables may contain secrets, but the mechanism is not inherently a secure secret store; access and logging still matter.
