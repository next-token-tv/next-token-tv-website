## What Macaron is

Macaron is a personal AI agent aimed at everyday life. Its official page positions it against work-oriented agents — "Other AI agents help you work. Macaron helps you live better." — and describes a personal test plus Deep Memory that remembers what matters to the user, growing like a friend over time. The official page does not name the operating company.

## Uses and boundaries

By its official description, Macaron emphasizes building real, usable tools (mini-apps) from a single simple request rather than demos; users reach it through the app or web entry points listed on the [official website](https://macaron.im/). Personalization is built on preferences and memory the user provides, so it involves choices about consent and privacy for personal life data: what is remembered and what is cleared should be managed in the product's own privacy settings. Pricing is not shown on the official page and should be taken from official channels.

## FAQ

### What is Macaron?

A personal AI agent for everyday life that, by its official positioning, uses memory and personalization to help users live better rather than only work faster, and generates practical mini-apps on request. See the [official website](https://macaron.im/).

### Is there a Macaron app? How do I get it?

The official page offers "Get the app" and "Try now" entries; current platforms and download options are shown on the [official website](https://macaron.im/).

### What is Macaron's Deep Memory?

The official page describes Deep Memory as remembering what matters to the user and growing with use, which is where its personalization comes from. Because it relies on user data, pay attention to the memory and privacy settings inside the product.

### How much does Macaron cost?

The official page does not display pricing; plans and free usage should be confirmed through official channels.
