## Microsoft Azure

Microsoft Azure is the cloud computing platform of [Microsoft](/en/wiki/brands/microsoft). The official page defines it as a cloud computing platform for building, deploying, and managing solutions in the cloud (see the [official page](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-azure/)). The platform was announced in October 2008 at a Microsoft developer conference, launched commercially on February 1, 2010 as Windows Azure, and renamed Microsoft Azure in March 2014 (per [English Wikipedia](https://en.wikipedia.org/wiki/Microsoft_Azure)).

## Main service categories

The official page groups Azure services into compute (virtual machines, serverless, containers and Kubernetes), storage and databases (Azure SQL, Cosmos DB, and others), networking, analytics and data (Fabric, Databricks), AI and machine learning (Azure AI Foundry, Azure OpenAI, Azure Machine Learning), and security, governance, and management.

## Frequently asked questions

### What is Microsoft Azure?

The cloud computing platform of Microsoft, offering compute, storage, databases, networking, analytics, and AI services; the official definition is on the [What is Azure page](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-azure/).

### When was Azure launched?

The platform was announced in October 2008, launched commercially on February 1, 2010 as Windows Azure, and renamed Microsoft Azure in March 2014 (per English Wikipedia).

### Which company owns Azure?

[Microsoft](/en/wiki/brands/microsoft).

### What AI services does Azure offer?

The AI and machine learning category on the official page includes Azure AI Foundry, Azure OpenAI, and Azure Machine Learning, among others.
