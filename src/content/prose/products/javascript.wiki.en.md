## Definition

JavaScript, often abbreviated JS, is a programming language used for web interactions, application logic, and server-side programs.

## Usage and related concepts

In browsers, JavaScript handles events, updates pages, and makes network requests. Visitor analytics scripts are one use. Node.js is a runtime and Three.js is a graphics library; neither is the language itself.
