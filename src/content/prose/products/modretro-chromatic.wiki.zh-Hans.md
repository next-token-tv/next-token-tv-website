## Chromatic 是什么

Chromatic 是 [ModRetro](/wiki/brands/modretro) 推出的复古掌上游戏机，运行原版 Game Boy 与 Game Boy Color 实体卡带，也是该公司 2024 年重启后的首款硬件。官方商品页称其为"终极卡带游戏机"——插上卡带即可游玩，没有下载、登录和广告打断。

## 掌机特性（官方商品页口径）

- **兼容性**：完整兼容原版 Game Boy、Game Boy Color 与 ModRetro Chromatic 卡带。
- **屏幕**：官方称由 ModRetro 从零自研的"Pixel-Perfect Display"，用于按原始创作者的意图显示 Game Boy 游戏；面板玻璃可选 Gorilla Glass 或 Sapphire。
- **机身**：轻量镁合金外壳。
- **多人联机**：通过 ModRetro Link Cable 对战或合作。
- **供电**：可使用 AA 电池或 ModRetro Rechargeable Power Core 充电电源核，插电时 USB 直通充电。
- **录制与直播**：官方称可通过 USB-C 直接录制或把游玩画面串流到 Mac 或 PC，并兼容 Discord。
- **卡带更新**：Cart Clinic 工具可直接在掌机上为 ModRetro 游戏打补丁，无需额外硬件。
- **延迟**：官方称与原版 Game Boy 硬件做到毫秒级匹配。

以上为官方商品页的厂商描述；机型的使用与维护细节见[官方手册](https://support.modretro.com/en_us/chromatic-manual-S1cy8e_0Zx)。

## 同一产品线：M64 主机

Chromatic 之后，ModRetro 推出了复刻 Nintendo 64 的 M64 家用主机：官方商品页称其完整兼容原版 N64 卡带与手柄，还原游戏运行节奏与音频，通过 HDMI 输出 720p/1080p/1440p/4K 分辨率，提供 CRT 滤镜与超频等自定义选项，并可通过无线或有线更新解锁新功能。N64、Game Boy 等商标归 Nintendo 所有，官方页面注明 Nintendo 与 ModRetro 无关联。

## 常见问题

### Chromatic 支持哪些卡带？

原版 Game Boy、Game Boy Color 卡带以及 ModRetro Chromatic 卡带；官方兼容性列表不包含 Game Boy Advance 等其他平台的卡带。

### Chromatic 多少钱？

官方商店按屏幕玻璃材质分档：Gorilla Glass 版与 Sapphire 版价格不同，截至 2026 年 10 月分别标价 $199.99 与 $299.99，每台随机附赠 Tetris 卡带。当前价格与配色见[官方商店](https://modretro.com/)。

### Chromatic 和 M64 有什么区别？

Chromatic 是运行 Game Boy/Game Boy Color 卡带的掌机；M64 是运行 Nintendo 64 卡带的家用主机，通过 HDMI 连接电视输出。两者都属于 ModRetro 的复古硬件产品线。

### Chromatic 怎么供电？

官方商品页列出两种方式：AA 电池，或换用 ModRetro Rechargeable Power Core 充电电源核；接 USB 供电时可在不放电池的情况下游玩并充电。
