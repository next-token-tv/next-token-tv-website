## What macOS is

macOS is the desktop operating system [Apple](/en/wiki/brands/apple) develops for Mac computers, part of an OS family alongside iOS, iPadOS, watchOS, and visionOS: iOS powers the [iPhone](/en/wiki/products/iphone), while macOS powers the Mac desktop and laptop lines. Macs ship with macOS preinstalled, and updates are pushed free through System Settings > Software Update. The current version name, features, and compatibility are on the [official macOS page](https://www.apple.com/macos/). For Mac hardware use cases, see the [Mac Studio](/en/wiki/products/mac-studio) and [Mac mini](/en/wiki/products/mac-mini) entries.

## macOS 27 and key capabilities

On September 14, 2026, Apple shipped macOS 27 (Golden Gate) and the rest of its new OS generation as free updates. Per official material, the Mac highlights of this generation are: the [Siri AI](/en/wiki/products/siri) beta powered by Apple Intelligence (English first), a dedicated Siri app whose conversations carry over from iPhone through iCloud, Visual Intelligence that answers questions about anything on screen via a screenshot, Write with Siri available wherever you type, an enhanced Liquid Glass design, and a broad set of performance improvements.

Boundaries: official footnotes state that Apple Intelligence requires Mac models with M1 or later; Siri AI needs an Apple Intelligence–enabled device set to a supported language and is rolling out in English first; features that rely on server-side models are subject to daily usage limits. For language and region scope and the full compatibility list, the [official macOS page](https://www.apple.com/macos/) is authoritative.

## Frequently asked questions

### What is macOS, and how does it differ from iOS?

macOS is Apple's desktop operating system for Mac computers; iOS is its mobile operating system for iPhone. Both belong to the same OS family and cooperate through iCloud and Handoff, but their interaction models, window management, and app ecosystems are separate. See the [iOS](/en/wiki/products/ios) entry and the [official macOS page](https://www.apple.com/macos/).

### When was macOS 27 released?

On September 14, 2026, Apple announced in a newsroom post that macOS 27 began rolling out that day as a free update alongside iOS 27 and iPadOS 27; the version is named Golden Gate. See the [official newsroom post](https://www.apple.com/newsroom/2026/09/major-updates-for-apples-software-platforms-are-now-available/).

### What is new in macOS 27?

Per the official page, macOS 27 brings the Siri AI beta (English first), a dedicated Siri app, Visual Intelligence, Write with Siri, Liquid Glass design refinements, and performance improvements. The full list is on the [official macOS 27 page](https://www.apple.com/macos/).

### Which Macs can run macOS 27?

The full compatibility list is maintained on the [official macOS page](https://www.apple.com/macos/). Official footnotes state that Apple Intelligence features, including Siri AI, require Mac models with M1 or later.

### Does Siri AI on Mac support Chinese?

The official newsroom post states that Siri AI ships as a beta in English first, with French, Japanese, Korean, Portuguese, and Spanish following in October 2026; Chinese availability should be checked against the latest wording on the [official page](https://www.apple.com/macos/).

### How do I update macOS?

On a Mac, open System Settings > General > Software Update to check and install; system updates are free. Major versions typically ship each fall alongside new hardware.
