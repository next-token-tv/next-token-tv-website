## What Windows is

Windows is the family of operating systems for personal computers developed by Microsoft, spanning laptops, desktops, gaming PCs, and 2-in-1 devices. The official product page currently presents Windows 11 as the headline version, highlighting Snap layouts, Copilot inside Microsoft apps, the gaming ecosystem, and Windows Hello sign-in. Devices and features are described on the [official Windows page](https://www.microsoft.com/windows/).

## Versions and boundaries

According to the official support page, Windows 10 reached end of support on October 14, 2025: the system keeps running, but Microsoft no longer provides software updates, security fixes, or technical assistance. The paths the page offers are a free upgrade to Windows 11 through Windows Update for eligible PCs, the Extended Security Updates (ESU) program, or buying a new PC; see the [official end-of-support page](https://www.microsoft.com/en-us/windows/end-of-support).

For everyday use, Windows arrives preinstalled with a device or through official channels; AI features such as Copilot can depend on subscriptions, hardware, or region. Compared with macOS or Linux, the practical differences lie in hardware choice, software ecosystem, and system administration — the right pick depends on the workload.

## Frequently asked questions

### Where is the official Windows website?

The official product page is [microsoft.com/windows](https://www.microsoft.com/windows/), with the current version, device types, and feature descriptions. Downloads and upgrade tools should also come from official Microsoft domains rather than third-party download sites.

### Is Windows 10 still supported?

No. The official support page states Windows 10 reached end of support on October 14, 2025, after which there are no software updates, security fixes, or technical assistance; options include upgrading to Windows 11, the Extended Security Updates program, or replacing the device, per the [official page](https://www.microsoft.com/en-us/windows/end-of-support).

### Is the upgrade from Windows 10 to Windows 11 free?

The official support page says eligible Windows 10 PCs can upgrade to Windows 11 for free through Windows Update; whether a given PC meets the minimum hardware requirements is determined by the official upgrade page and system checks.

### Is there a Windows 12?

The official Windows product page currently lists Windows 11 and carries no information about a new version. Any official release would be announced on the [Microsoft Windows page](https://www.microsoft.com/windows/); rumors, screenshots, and leaks elsewhere should not be treated as evidence.
