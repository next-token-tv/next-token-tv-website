## What Microsoft Excel is

Microsoft Excel is the spreadsheet application from [Microsoft](/en/wiki/brands/microsoft), first released on September 30, 1985 for Macintosh and followed by a Windows version in 1987. It has been a core application of [Microsoft Office](/en/wiki/products/microsoft-office) and Microsoft 365 ever since, with a free web version also available. Workbooks and worksheets organize data; the core capabilities are formulas and functions, pivot tables, charts, conditional formatting, and automation through macros (VBA).

Recent extensions follow two tracks: integration with [Microsoft Copilot](/en/wiki/products/microsoft-copilot) for analyzing data with natural language inside the grid, and programming interfaces — in 2023 Microsoft announced a public preview of Python in Excel, bringing a Python runtime into cell calculations.

## Uses and differences

How you use Excel depends on the entry point: the desktop app comes with a Microsoft 365 subscription or a one-time license; the web version is free with a Microsoft account at the [Microsoft 365 web portal](https://www.microsoft365.com/); mobile apps cover the rest. On file formats, the default since 2007 is `.xlsx` (Office Open XML), while the older `.xls` still opens.

Two things are easy to confuse: Excel is a single application, while Microsoft 365 is the subscription bundling Word, PowerPoint, and others; and "spreadsheet software" is the category, where Excel competes with Google Sheets, WPS Spreadsheet, and similar products — files import and export between them, but features do not map one to one.

## Frequently asked questions

### Is Excel free?

The web version is free: sign in with a Microsoft account at the [Microsoft 365 web portal](https://www.microsoft365.com/) to create and edit spreadsheets. The desktop Excel requires a Microsoft 365 subscription or a separate license. Mobile apps are free for viewing, with editing limited by screen size and account.

### When was Excel released?

Excel first shipped on September 30, 1985 for Macintosh, with a Windows version in 1987. It predates the Microsoft Office suite itself and later became the spreadsheet component of the suite.

### What is the difference between .xlsx and .xls?

`.xlsx` is the default format since Excel 2007, based on the Office Open XML standard, producing smaller and more resilient files; `.xls` is the older 97-2003 format. Current Excel opens both, but new features assume `.xlsx`.

### Excel or Google Sheets?

Both are spreadsheet applications: Excel is stronger for desktop analysis depth, pivot tables, and compatibility with the Office ecosystem; Google Sheets is stronger for real-time multiplayer collaboration and no-install web use. Files move between them, but complex formulas and macros (VBA versus Apps Script) are not compatible, so check them when migrating.

### Does Excel have AI features?

Yes: Copilot in Excel lets the model analyze data, build formulas, and generate charts from natural-language prompts, as part of Microsoft 365 Copilot; since 2023 Microsoft has also offered a public preview of Python in Excel. Availability depends on the subscription tier — see the [Microsoft 365 Excel page](https://www.microsoft.com/en-us/microsoft-365/excel).
