## 定义

V2EX 是面向开发者、设计师及其他创意工作者的在线讨论社区。官方 About 页自述口号 "V2EX = way to explore"，称社区汇聚了超过 750,000 名主要来自互联网、游戏和媒体行业的创意工作者，见[官方 About 页](https://www.v2ex.com/about)。

## 工作方式

成员发布主题与回复，分享自己正在做的有趣事物、交流想法。社区设有明确规则：不讨论盗版、不全文转载他人文章、反对"沙发"类无信息量回复、禁止人身攻击与人肉搜索，并且"请不要把 AI 生成的内容发送到这里"。站点由自研的 Project Babel 社区软件驱动，页脚提供帮助与 API 文档入口。

## 使用场景

常见用法包括展示个人项目、与同行交流技术和行业话题、寻找合作与新机会；官方介绍把 V2EX 描述为创意工作者"生活和事业的一部分"。

## 易混概念

名字含义有据可查：官方口号为 "way to explore"，About 页的历史记录还提到 2006 年上线时 "way too extreme" 也是其含义之一。另外，V2EX 帖子常被截图传播到站外，帖子内容代表发帖者个人观点，不代表社区立场。

## 常见问题

### V2EX 是什么网站？

面向开发者、设计师等创意工作者的讨论社区，围绕工作、技术与生活话题交流；官方介绍见 [About 页](https://www.v2ex.com/about)。

### V2EX 怎么注册？需要邀请码吗？

注册入口在 [v2ex.com](https://www.v2ex.com/) 的 Sign Up 页面；注册方式与开放条件以站内说明为准。

### V2EX 有 API 吗？

官方 About 页页脚提供 API 与帮助文档入口，接口说明见站内 [Help](https://www.v2ex.com/help) 与 API 文档。
