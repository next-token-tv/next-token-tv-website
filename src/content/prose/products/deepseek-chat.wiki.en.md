## Definition

DeepSeek Chat is DeepSeek's AI chat product for individual users, available as a web app and a mobile app, with the web entry at [chat.deepseek.com](https://chat.deepseek.com/). It calls the DeepSeek model family to produce answers; official change records are kept on the [API docs updates page](https://api-docs.deepseek.com/updates/).

## How it works

You ask questions in the chat interface and the app calls DeepSeek models to respond; the models and features inside the app change with official updates, so the current model names and capabilities follow the [official transparency center](https://www.deepseek.com/transparency/) and model list rather than the app name. The chat app is not the model itself: the same model family is also served to developers through the API.

## Usage

Typical uses are everyday Q&A, writing, code questions and retrieval-style prompts, straight from the web or a phone. Developers who want the models inside their own applications or agents use the [DeepSeek open platform](https://platform.deepseek.com/) API instead of the chat app.

## Related and confusable terms

Three layers are easy to confuse: [DeepSeek models](/en/wiki/products/deepseek) form the model family, while [DeepSeek the company](/en/wiki/brands/deepseek) is their provider; this entry's chat app (DeepSeek App) is the consumer-facing interface; and the API on the [open platform](https://platform.deepseek.com/) is the metered developer service. The [DeepSeek Search / Fetch API](/en/wiki/products/deepseek-search), which exposes search and page retrieval separately, is yet another layer.

## Frequently asked questions

### Where is the official DeepSeek chat entry?

The web entry is [chat.deepseek.com](https://chat.deepseek.com/); the mobile app comes from the app stores — use the app published by DeepSeek officially, and follow the [official page](https://chat.deepseek.com/) for entries.

### Which model does the DeepSeek app use?

It calls the DeepSeek model family; current model names and features change with official updates and are listed on the [transparency center](https://www.deepseek.com/transparency/) and model list.

### How does the DeepSeek app differ from the DeepSeek API?

The app is the consumer chat entry; the API is the metered service developers use on the [open platform](https://platform.deepseek.com/) to build their own applications, with separate accounts and billing.
