## ChatGPT 是什么

ChatGPT 是 OpenAI 面向个人和组织提供的通用人工智能助手。官方将它用于头脑风暴、写作、学习、规划、数学、编程，以及文件和图像分析等日常任务。它以对话为主要交互方式，具体工具、地区可用性和账户条件会随产品更新而变化，应以[官方 FAQ](https://help.openai.com/en/articles/12677804-what-is-chatgpt-faq)为准。

## 用途与边界

ChatGPT 适合把一个目标、背景和交付格式说清楚，让助手帮助解释、起草、整理或分析材料。需要事实准确的工作时，用户仍应核对来源、计算和关键结论；流畅回答不等于自动完成了事实验证。文件、图像、联网搜索、语音等功能也可能受账户、地区或产品界面限制。

ChatGPT 适合辅助思考和整理，但重要事实与决定仍需人工核验；软件开发中若要直接读写代码并运行检查，可继续了解 [Codex](/wiki/products/codex)。

## 常见问题

### ChatGPT 官网在哪里？

官方网页版入口是 [chatgpt.com](https://chatgpt.com/)。功能和登录要求以页面与[官方 FAQ](https://help.openai.com/en/articles/12677804-what-is-chatgpt-faq)为准。

### ChatGPT 可以做什么？

官方 FAQ 列出的典型任务包括头脑风暴、写作、学习、规划、数学、编程，以及分析文件或图像。实际可用功能取决于当前产品、账户和地区，不能只凭他人的界面截图推断。

### ChatGPT 有没有官方应用？

有。OpenAI FAQ 列出 iOS 和 Android 应用；从 [ChatGPT 官方入口](https://chatgpt.com/)或 FAQ 的官方链接进入，避免从不明下载站获取安装包。

### ChatGPT API 和 ChatGPT 是一回事吗？

不是。ChatGPT 是面向用户的助手；开发者 API 通过 [OpenAI API 平台](https://platform.openai.com/docs/overview)单独接入和计费。

### ChatGPT 免费吗？

OpenAI 提供 Free 等使用计划，也有需要订阅的计划；功能和使用额度按计划变化。当前计划与限制应查看[ChatGPT 定价页](https://chatgpt.com/pricing/)。

### ChatGPT 和 Codex 有什么区别？

ChatGPT 是面向广泛任务的助手；[Codex](/wiki/products/codex)专注软件开发工作流，强调在编辑器、终端、桌面应用或云端完成编码任务。两者的具体产品边界仍以各自官方文档为准。
