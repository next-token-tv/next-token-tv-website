## ChatCut 是什么

ChatCut 是 ChatCut Inc. 推出的视频编辑器，官方文档称其为"你对话的 AI 视频编辑器"（the AI video editor you talk to）：AI Agent 内置在编辑工作区中，可以用自然语言让 Agent 组装或修改剪辑，也可以自己在多轨时间线上做精细调整。官方文档明确它的定位是 AI 视频编辑器而不是视频生成器——生成媒体只是单个生成任务，结果进入素材库，与导入素材放在同一条时间线上（见[官方文档](https://chatcut.io/docs/what-is-chatcut)）。

## 三种使用入口

按官方文档，产品提供桌面应用（macOS Apple Silicon、Intel 芯片与 Windows 版本）、Web 应用和 Agent 插件三种入口，区别只在对话发生的位置，编辑步骤相同。Agent 插件方面，官方提供 ChatGPT/Codex 插件、Claude Code 插件和 Grok Bot 插件，可以在这些 Agent 中直接编辑桌面端项目。

## 主要功能

- 面向口播、访谈、播客、教程和录屏类素材收紧剪辑，从长项目产出短视频版本。
- 生成视频、动态图形、图片、音乐、字幕与配音，官方文档列出 Seedance 等视频模型。
- 在逐字稿面板中按文字删除或重排语句来编辑口播内容。
- 导出视频、音频、字幕与 XML：支持 Premiere / DaVinci XML，以及可在剪映 / CapCut 中继续编辑的草稿。

## 常见问题

### ChatCut 是什么？

一个内置 AI Agent 的视频编辑器：用自然语言让 Agent 剪辑，也可在多轨时间线上手动调整，提供桌面、Web 和 Agent 插件三种入口，见[官方文档](https://chatcut.io/docs/what-is-chatcut)。

### ChatCut 是视频生成器吗？

按官方文档的区分，ChatCut 是 AI 视频编辑器：Agent 能读取项目上下文并直接修改正在编辑的时间线，视频生成只是提交单个媒体生成任务，生成结果仍回到时间线上编辑。

### ChatCut 和剪映、CapCut 是什么关系？

它们是不同公司的独立产品，ChatCut 不是剪映的组件或插件。[剪映](/wiki/products/jianying)是独立的视频编辑应用；ChatCut 支持导出可在剪映 / CapCut 中继续编辑的草稿，属于素材交接能力（见[官方文档](https://chatcut.io/docs/what-is-chatcut)）。

### ChatCut 适合剪什么素材？

官方文档称它最适合以语音为主的素材：口播、访谈、播客、教程、网络研讨会和录屏；逐字稿面板把语音当作文字审阅，时间线仍可手动调整。

### ChatCut 怎么收费？

按积分（credits）计费，有免费与 Pro 档；具体方案与额度以[官方定价页](https://chatcut.io/pricing)为准。
