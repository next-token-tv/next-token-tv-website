## What ChatGPT is

ChatGPT is OpenAI’s general-purpose AI assistant for individuals and organizations. OpenAI describes everyday uses including brainstorming, writing, studying, planning, math, coding, and analyzing files or images. It is primarily conversational, while tools, regional availability, and account requirements can change; check the [official FAQ](https://help.openai.com/en/articles/12677804-what-is-chatgpt-faq) for current details.

## Uses and boundaries

ChatGPT works best when a user states a goal, relevant context, and desired output. It can explain, draft, organize, and analyze material, but fluent text is not proof that a claim or calculation is correct. File, image, voice, and search features can depend on the product surface, account, and region.

ChatGPT is useful for thinking and organizing, while important facts and decisions still need human review. For software work that requires an agent to operate on a repository and run checks, see [Codex](/en/wiki/products/codex).

## Frequently asked questions

### Where is the official ChatGPT website?

The official web entry is [chatgpt.com](https://chatgpt.com/). Current access and features are described in the [official FAQ](https://help.openai.com/en/articles/12677804-what-is-chatgpt-faq).

### What can ChatGPT do?

OpenAI’s FAQ lists brainstorming, writing, studying, planning, math, coding, and file or image analysis as typical uses. The exact feature set depends on the current product, account, and region, so another user’s interface does not establish what is available to you.

### Does ChatGPT have official apps?

Yes. OpenAI’s FAQ lists iOS and Android apps. Start from the [official ChatGPT entry](https://chatgpt.com/) or the FAQ’s official links rather than an unverified download site.

### Is the ChatGPT API the same as ChatGPT?

No. ChatGPT is the user-facing assistant; developers access the API separately through the [OpenAI API platform](https://platform.openai.com/docs/overview) and its billing.

### Is ChatGPT free?

OpenAI offers a Free plan alongside subscription plans, with features and usage limits varying by plan. Check the current [ChatGPT pricing page](https://chatgpt.com/pricing/).

### How is ChatGPT different from Codex?

ChatGPT is a broad assistant, while [Codex](/en/wiki/products/codex) is focused on software-development workflows across editors, terminals, the desktop app, and the cloud. The current boundaries are defined by each product’s official documentation.
