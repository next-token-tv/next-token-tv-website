## Devin Desktop and Windsurf

Devin Desktop is [Cognition](/en/wiki/brands/cognition)'s new name for the Windsurf desktop IDE. It retains the editor and adds an interface for managing local and cloud agents. Per the official FAQ, the rename ships as a standard over-the-air update: the IDE, extensions, workflows, settings, and in-progress work remain intact, and existing plans and pricing are unchanged. The Windsurf extension for JetBrains remains available separately under its original name. [Devin](/en/wiki/products/devin) is Cognition's software engineering agent, whose tasks can be managed from the desktop app.

## What the desktop app does

The official page describes Devin Desktop as "the command center for managing all your agents in one place":

- Editor and agents together: the full Windsurf IDE experience plus interfaces such as Spaces, a Kanban view, and multi-agent management.
- Local and cloud sessions: sessions run on your machine or in Devin Cloud and move between them with the same context.
- Multi-agent work: Devin can split long tasks across subagents, each producing its own pull requests.
- Code review: agent changes appear as diffs that can be reviewed line by line.

## Frequently asked questions

### What is the relationship between Windsurf and Devin Desktop?

Devin Desktop is the renamed and extended Windsurf desktop IDE: Cognition kept the editor and added agent management, delivered through an automatic update with existing plans, pricing, extensions, and settings carried over.

### How is Devin Desktop different from Devin?

[Devin](/en/wiki/products/devin) is the software engineering agent itself, with a web app, team integrations, and an API as entry points. Devin Desktop is the desktop client that combines the editor and the interface for managing local and cloud agents in one application.

### Does updating from Windsurf lose any data?

Per the official FAQ, the rename arrives as an over-the-air update and the IDE, extensions, workflows, settings, and in-progress work all remain intact; only the name and branding change.

### Where can I learn about or get Devin Desktop?

The official entry point is [devin.ai/desktop](https://devin.ai/desktop), with getting-started guidance in the [documentation](https://docs.devin.ai/desktop/getting-started).
