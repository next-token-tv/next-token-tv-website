## What Minecraft is

Minecraft is an open-world sandbox game developed by the Swedish studio Mojang Studios. The official site describes it as an "open world sandbox game" where players explore, survive, build, and create in a world made of blocks; its own summary of the gameplay is to explore your own unique world, survive the night, and create anything you can imagine. According to the same [official about page](https://www.minecraft.net/en-us/about-minecraft), the first version of Minecraft was released for PC players in 2009, with the full version releasing in 2011.

Mojang was acquired by Microsoft in November 2014; Microsoft's annual report describes it as Mojang Synergies AB, "the Swedish video game developer of the Minecraft gaming franchise." The Minecraft site footer carries both the Mojang AB copyright and the Microsoft trademark. Beyond the main game, the official site lists the spin-offs Minecraft Dungeons, Minecraft Legends, and Minecraft Education; for corporate ownership see [Microsoft](/en/wiki/brands/microsoft).

## Gameplay and editions

Minecraft has no single set goal: players gather resources, craft items, build structures, explore terrain, and fight hostile mobs, or collaborate on multiplayer servers. The official about page states that because the game is a sandbox, there is no official "end" to it, although many players say they have "beaten the game" once they kill the Ender Dragon.

The game has two main edition lines: Java Edition and Bedrock Edition. The official download and server pages provide separate entries for each, with Java players able to run their own multiplayer servers and Bedrock focused on cross-device play; the Realms subscription runs a personal server for you. Updates arrive as "game drops," which the official page says typically happen several times per year. Pricing and bundle details are time-sensitive: check the [official store](https://www.minecraft.net/en-us/store) and [download page](https://www.minecraft.net/en-us/download).

In mainland China a localized edition of the game is operated separately; its site is [mc.163.com](https://mc.163.com/), which offers desktop and mobile downloads and states that the Bedrock version can play cross-platform with Windows.

## Frequently asked questions

### What type of game is Minecraft?

Minecraft's official FAQ describes it as an open world sandbox game combining action-adventure, creativity, and building. See the [official about page](https://www.minecraft.net/en-us/about-minecraft).

### Where can I download Minecraft?

The global official entry is the [Minecraft download page](https://www.minecraft.net/en-us/download), and the official site offers a free trial. Avoid third-party download sites.

### How much does Minecraft cost?

The base game is a paid purchase (with an official free trial), and prices vary by platform, edition, and region. Current prices for Java and Bedrock are shown on the [official store page](https://www.minecraft.net/en-us/store).

### What is the difference between Java Edition and Bedrock Edition?

Java Edition and Bedrock Edition are the game's two main edition lines, each with its own download and multiplayer server entries: Java has long been associated with PC self-hosted servers, while Bedrock focuses on cross-device play. Which one you choose depends on whom you want to play with and which servers you want to join; see the [official download page](https://www.minecraft.net/en-us/download) and the official help center.

### Can you beat Minecraft?

The official FAQ answers this directly: as a sandbox game there is no official "end," but many players consider the game beaten once they kill the Ender Dragon.

### Is Minecraft a multiplayer game?

Yes. The official page notes you can play online — joining or running multiplayer servers in Java, and using Bedrock's multiplayer options or Realms. See the [official about page](https://www.minecraft.net/en-us/about-minecraft).
