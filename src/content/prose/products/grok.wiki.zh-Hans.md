## Grok 是什么

Grok 是 xAI 推出的前沿模型与 AI 助手产品家族。xAI 于 2026 年 2 月[宣布并入 SpaceX](https://x.ai/news/xai-joins-spacex)后，官网以 SpaceXAI 品牌运营，Grok 覆盖推理、代码、语音、图像与视频等模态。它同时指两类东西：面向普通用户的 [Grok 助手](https://x.ai/grok/)（聊天、搜索、图像与视频生成、语音对话），以及供开发者调用的模型 API。本文整体介绍这个家族；云端常驻的自主 Agent 产品 Grok Bot 是同一条产品线下的独立产品，见 [Grok Bot](/wiki/products/grok-bot)。

## 产品形态与使用方式

面向用户的入口包括 [grok.com](https://grok.com/) 网页版、iOS 与 Android 应用，以及 X 平台内的 Grok。按官方页面，助手支持日常对话与写作、结合实时网页与 X 内容的搜索并给出引用、文生图与文生视频（Imagine）、语音对话、文件与图片理解，以及并行处理复杂问题的多智能体模式。

面向开发者的入口是[官方文档站](https://docs.x.ai/)：统一 API 覆盖文本、代码、语音、图像与视频，提供 OpenAI 兼容端点（api.x.ai/v1）与 Python、TypeScript 等 SDK。具体在售或最新的模型版本会变化，应以官方模型页为准。

## 使用边界

Grok 助手可免费试用，[SuperGrok 订阅](https://grok.com/plans)提供更高使用额度与优先访问；开发者 API 按用量计费，企业客户另有定制配额与部署选项。具体价格与额度不在本页固定，见官方页面。与所有 AI 助手一样，搜索与生成内容的准确性需要自行核验，官方页面标注的功能与地区可用性可能随版本更新变化。

## 常见问题

### Grok 是什么？

Grok 是 SpaceXAI（xAI 并入 SpaceX 后的品牌）旗下的前沿模型与 AI 助手家族，提供网页与移动端助手、X 平台内入口和开发者 API。见[官方介绍](https://x.ai/grok/)。

### Grok 是哪家公司的？

Grok 由 xAI 研发；xAI 于 2026 年 2 月宣布并入 SpaceX，此后官网以 SpaceXAI 名义运营。见[并入公告](https://x.ai/news/xai-joins-spacex)。

### Grok 和 Grok Bot 有什么区别？

Grok 是模型与助手家族（聊天、搜索、生成、API）；Grok Bot 是同产品线下的自主 Agent，运行在一台持久的云端电脑上，通过消息布置多步任务。两者互链参考：[Grok Bot](/wiki/products/grok-bot)。

### Grok 怎么收费？

官方助手页面写明可免费试用，SuperGrok 订阅提供更高额度与优先访问；开发者 API 按用量计费。套餐与费率见 [grok.com/plans](https://grok.com/plans) 与官方价格说明，不在本页固定数字。

### Grok API 在哪里接入？

开发者从[官方文档站](https://docs.x.ai/)获取 API Key 与接入说明，接口提供 OpenAI 兼容端点（api.x.ai/v1）和 Python、TypeScript 等 SDK。

### Grok 这个词还有其他含义吗？

有。作为英文词，grok 出自罗伯特·海因莱因 1961 年的科幻小说《异乡异客》，是小说中的火星词汇。搜索时若看到词源类结果，与 xAI 的 Grok 产品无关。
