## Qoder 是什么

Qoder 是一个面向软件开发与多步骤任务的 AI Agent 平台。[官方文档](https://docs.qoder.com/product-series/what-is-qoder)将其描述为"agentic platform for real work"，覆盖软件开发、终端工作流、托管云端执行、日常办公与长期数字角色，核心是"理解任务—规划—使用工具执行—验证—迭代"的闭环，而不是只提供建议或聊天。

官方入口为 [qoder.com](https://qoder.com/) 与 [docs.qoder.com](https://docs.qoder.com/product-series/what-is-qoder)。官方页面未标注运营公司主体；Weekly 节目中杨攀称其为"阿里 Qoder"，这是参与者的说法。

## 产品形态与使用边界

按官方文档与官网，Qoder 产品家族包括：

- Qoder IDE：Agent 化的开发环境，Quest 模式用于长期、多步任务的委托，并能生成技术设计文档（Spec）；配套 Repo Wiki，持续同步项目结构与实现细节。
- Qoder CLI：终端里的编码 Agent，可扩展到脚本与自动化。
- Cloud Agents：通过 API 使用托管 Agent，提供环境、会话与 SSE 事件流输出。
- QoderWork：委托文档、表格、调研、浏览器与桌面任务。
- QoderWake：长期运行的"数字员工"（官方称 Wakers），承担持续职责与自动化，例如软件开发 Wake 处理功能实现、Bug 修复与 PR 审查。
- JetBrains 插件、移动端与网页端（远程监控任务与审批）、Agent SDK（官方给出 npm 包）以及企业版治理能力。
- 计费：积分制；官方页面标注新用户可获 2 周 Pro 试用，之后可订阅或降级到 Free 计划。当前套餐见[官方网站](https://qoder.com/)。

## 常见问题

### Qoder 是什么？

一个面向软件开发与多步骤任务的 AI Agent 平台，形态覆盖 IDE（含 Quest 委托）、终端 CLI、托管云端 Agent、办公委托（QoderWork）与数字员工（QoderWake），见[官方文档](https://docs.qoder.com/product-series/what-is-qoder)。

### Qoder 是哪家公司的？

官方站点与文档未标注运营公司主体。Weekly 节目中杨攀称其为"阿里 Qoder"，这是参与者的说法；归属信息请以官方页面为准。

### Qoder 有哪些使用形态？

按官方文档：Qoder IDE 与 Quest 模式、JetBrains 插件、Qoder CLI、Cloud Agents（API 托管）、QoderWork（文档/表格/调研/浏览器/桌面任务）、QoderWake（数字员工）、移动端与网页端，另有 Agent SDK 与企业版治理能力。

### Qoder 免费吗？

官方页面标注新用户有 2 周 Pro 试用，之后可付费订阅或降级到 Free 计划；用量按积分计。当前套餐与价格见[官方网站](https://qoder.com/)。

### Qoder 和 QoderWork、QoderWake 有什么区别？

Qoder 主打软件开发；QoderWork 把文档、表格、调研、浏览器和桌面任务委托给 Agent；QoderWake 是长期在岗的"数字员工"，承担持续职责。三者同属官方文档描述的 Qoder 产品家族，面向的任务类型不同。
