## WeChat Input

WeChat Input (微信输入法) is the Chinese input method produced by WeChat officially. Its official website is [z.weixin.qq.com](https://z.weixin.qq.com/), which describes the product as delivering an efficient typing experience, precise suggestion strategies, and varied creative features, under the tagline "简洁好用打字快" (simple, easy to use, fast typing). Within the WeChat product family it is an input tool, a different layer from [WeChat](/en/wiki/products/wechat) as a messaging platform; the common name "微信键盘" (WeChat Keyboard) refers to the same product.

## Platforms and boundaries

The official site lists version entries for Mac, Windows, iOS, and Android, with speech-to-text (voice input) among its publicly promoted capabilities. As an input method it handles text and voice entry itself; messaging, office work, and other higher-level scenarios are handled by WeChat or other apps. The degree of support for capabilities such as custom voice dictionaries changes with releases; check the official site and app store update notes.

## Discussion in the show

In Weekly #002's chapter “语音输入：准确率之外的使用摩擦” (Voice input: friction beyond accuracy), Yang Pan said he [currently uses both Typeless and WeChat Input](/weekly/002/transcript#quote-d55f5ee52262b97c51ae) (Chinese transcript); he added that the product's one problem, in his view, is that [it still cannot customize the voice input dictionary](/weekly/002/transcript#quote-95d776331f70b6a7bc7e) — otherwise he would stop using the Tab key; on long-form transcription he judged that [WeChat Input handles long text well enough](/weekly/002/transcript#quote-99501e6a172d49600114). In the same chapter Guizang discussed the pain of input methods that bind voice input to their own keyboard dictionary. These are the participants' personal experiences at the time, not a product review.

## Frequently asked questions

### Where is the official WeChat Input website?

The official site is [z.weixin.qq.com](https://z.weixin.qq.com/), which links to the download entries for each platform.

### Which platforms does WeChat Input support?

The official site provides entries for Mac, Windows, iOS, and Android; current installers and supported system versions are listed on the [official website](https://z.weixin.qq.com/).

### What is the relationship between WeChat Input and "WeChat Keyboard"?

"微信键盘" (WeChat Keyboard) is a common name for the product — this site also lists it as an alias. The product's official name is 微信输入法 (WeChat Input); both refer to the same Chinese input tool from WeChat.

### Is WeChat Input's voice input any good?

The official site presents speech-to-text as one of the product's directions. Experiences vary: on the show, Yang Pan found its long-form transcription acceptable while noting that custom voice dictionaries were not yet supported — see [discussion in the show](#discussion-in-the-show).
