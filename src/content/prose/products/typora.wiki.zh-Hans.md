## Typora 是什么

Typora 是一款[官方称为 "minimal markdown editor"](https://typora.io/)的 Markdown 编辑器：它去掉了独立的预览窗口和模式切换，源码与渲染结果在同一界面中即时呈现，官方称这一体验为 "What You See Is What You Mean"。软件支持 macOS、Windows 与 Linux，采用付费许可（官方页面标注 15 天免费试用，一份许可最多 3 台设备），当前价格以[官网](https://typora.io/)为准。

## 功能与使用边界

Typora 的功能围绕写作场景组织：图片支持拖拽插入与缩放、表格可拖拽调整、代码块带语法高亮；数学公式走 MathJax，流程图支持 Mermaid 与 flowchart；另有专注模式、打字机模式、文件树与大纲面板、`[TOC]`、脚注和 YAML Front Matter。导出覆盖 PDF（含书签）、docx、LaTeX、Epub 等格式，主题通过 CSS 自定义。它定位是本地编辑器：文档保存在用户自己的文件系统里，协作与云端同步需要借助其他工具完成。

## 常见问题

### Typora 免费吗？

不免费。[官方页面](https://typora.io/)标注提供 15 天免费试用，正式使用需购买许可，一份许可最多用于 3 台设备；价格与许可条款以官网为准。

### Typora 支持哪些平台？

官方提供 macOS、Windows 与 Linux 版本；Windows 覆盖 x64、32 位与 ARM 构建。下载入口见[官网](https://typora.io/)。

### Typora 和普通 Markdown 编辑器有什么区别？

主要区别是即时预览：Typora 没有独立的预览窗口或"编辑/预览"模式切换，输入的 Markdown 在同一界面直接渲染，官方称其为 "What You See Is What You Mean"。
