## Microsoft Excel 是什么

Microsoft Excel 是[微软](/wiki/brands/microsoft)的电子表格应用，1985 年 9 月 30 日首发于 Macintosh 平台，1987 年推出 Windows 版本，此后一直是 [Microsoft Office](/wiki/products/microsoft-office)／Microsoft 365 套件中的核心应用，也提供免费网页版。它以工作簿和工作表组织数据，核心能力包括公式与函数、数据透视表、图表、条件格式，以及用宏（VBA）做自动化。

近年的能力扩展集中在两条线：一是与 [Microsoft Copilot](/wiki/products/microsoft-copilot) 的结合，在表格里用自然语言分析数据；二是编程接口，2023 年微软公开预览了 Excel 中的 Python 支持，把 Python 运行时接进了单元格计算。

## 使用与区别

Excel 的使用方式取决于入口：桌面应用随 Microsoft 365 订阅或一次性授权提供；网页版用 Microsoft 账户登录即可免费使用，见 [Microsoft 365 网页版入口](https://www.microsoft365.com/)；移动端有对应 App。文件格式上，2007 年起的默认格式是 `.xlsx`（Office Open XML），旧版 `.xls` 仍可打开。

两个容易混淆的对象：Excel 是单个应用，Microsoft 365 是包含 Word、PowerPoint 等多个应用的订阅服务；"表格软件"是品类，Excel 与 Google Sheets、WPS 表格等是同类竞争产品，文件可以互相导入导出但功能并不一一对应。

## 常见问题

### Excel 是免费的吗？

Excel 网页版免费：用 Microsoft 账户登录 [Microsoft 365 网页版](https://www.microsoft365.com/)即可创建和编辑表格；桌面版 Excel 需要 Microsoft 365 订阅或单独购买授权。移动 App 可免费查看，编辑功能受屏幕尺寸和账户限制。

### Excel 是什么时候发布的？

Excel 于 1985 年 9 月 30 日首发于 Macintosh，1987 年推出 Windows 版本。它早于 Microsoft Office 套件本身，后来成为套件中的表格组件。

### .xlsx 和 .xls 有什么区别？

`.xlsx` 是 Excel 2007 起的默认格式，基于 Office Open XML 标准，文件更小、抗损坏性更好；`.xls` 是 97-2003 时代的旧格式。新版 Excel 两者都能打开，但新功能以 `.xlsx` 为准。

### Excel 和 Google Sheets 怎么选？

两者都是电子表格应用：Excel 强在桌面端的分析深度、数据透视表和与 Office 生态的兼容；Google Sheets 强在多人实时协作和网页端免安装。文件可互相导入导出，但复杂公式、宏（VBA 与 Apps Script）互不兼容，跨产品迁移时需要检查。

### Excel 里有 AI 功能吗？

有：Copilot in Excel 可以用自然语言让模型分析数据、生成公式和图表，属于 Microsoft 365 Copilot 的一部分；2023 年起微软还公开预览了 Excel 中的 Python 支持。功能可用性取决于订阅档位，以 [Microsoft 365 Excel 页面](https://www.microsoft.com/en-us/microsoft-365/excel)为准。
