## What Synology NAS is

Synology NAS is the umbrella term for Synology's network-attached storage product range, covering data storage, file sharing, synchronization, and backups from home to enterprise scale. Hardware is divided into series by positioning: the J series for entry-level file consolidation, the Value series for private cloud and secure sharing, the Plus series for enhanced data protection and management, XS/XS+ for high-performance enterprise scenarios, the all-flash FS series, the enterprise and high-density SA, HD, and PAS series, the UC series for SAN environments, and the AI-powered NVR DVA series. DS-prefixed DiskStations are tower/desktop models; RS-prefixed RackStations are rackmount models. The full catalog is on the [official products page](https://www.synology.com/en-global/products).

## DSM and key packages

Synology NAS runs on DiskStation Manager (DSM), which Synology describes as "the intuitive operating system that powers every Synology NAS." Common packages include Synology Drive (sync and access files across devices), Hyper Backup (a comprehensive backup solution), Synology Photos (organizing and sharing photos), Surveillance (monitoring and video management), and the Active Backup family; supported models can also run containers through the Container Manager package. DSM versions and package availability change over time; check the [official DSM page](https://www.synology.com/en-global/dsm) and the Package Center.

## Frequently asked questions

### Where is the official Synology website?

The global site is [synology.com](https://www.synology.com/), with the Chinese site at [synology.cn](https://www.synology.cn/zh-cn/products); both carry the product catalog and package documentation.

### What is DSM?

DSM (DiskStation Manager) is the operating system of Synology NAS — officially described as the intuitive OS powering every Synology NAS. File management, backup, photos, and surveillance run on it as packages.

### How do I choose a Synology NAS?

Series map to purposes: entry-level home file storage starts at the J and Value series; advanced data protection and performance move up to Plus and XS; all-flash and enterprise workloads use FS, SA, HD, and PAS. Compare models in the [official catalog](https://www.synology.com/en-global/products).

### Can Synology NAS run Docker?

Synology offers the Container Manager package for running containers on supported models; see the [official package page](https://www.synology.com/en-global/dsm/packages/ContainerManager) for applicable models and features.
