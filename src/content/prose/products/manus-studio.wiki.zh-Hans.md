## Manus Studio 是什么

Manus Studio 是 [Manus](/wiki/products/manus) 的桌面工作区。官方页面将其描述为"你可与 AI 一起构建"的全新工作区：网站、视频与游戏的创建和编辑，可以与你自己的本地文件和工具放在一起进行，并通过手动控制打磨细节。它与网页版 Manus、移动端及 [Manus Cue](/wiki/products/manus-cue) 同属 Manus 的产品体系，但形态与入口不同。

## 用途与使用边界

按官方页面口径，Manus Studio 直接使用本地文件、文件夹与工具，项目可以从已有工作出发；另有 Computer Use 能力，让 Manus 在你电脑上的自有工作区中操作，而你仍在自己的界面上。Agent 跨设备同步：官方页面描述可以从 Cue 把 Agent 带到桌面端继续。

平台方面，官方提供 macOS（Apple Silicon）与 Windows（Microsoft Store）版本下载。与 Manus 主体一样，资费结构以[官方价格页](https://manus.im/pricing)为准；本地文件权限、生成结果的验收与归还边界仍由使用者把控。

## 常见问题

### Manus Studio 是什么？

Manus 的桌面工作区：结合本地文件与工具，创建和编辑网站、视频与游戏，Agent 可跨设备与网页版、Cue 衔接。见[官方页面](https://manus.im/desktop)。

### Manus Studio 支持哪些系统？

官方页面提供 macOS（Apple Silicon）与 Windows（经 Microsoft Store）版本下载；系统要求以官方下载页为准。

### Manus Studio 和 Manus Cue 是什么关系？

两者是 Manus 体系里不同的产品：Studio 是桌面工作区，Cue 是 Manus 的另一款产品形态（见 [Manus Cue](/wiki/products/manus-cue) 条目）。官方页面描述 Agent 可以在 Cue 与桌面端之间同步继续；节目中参与者也明确区分了这两个产品。

### Manus Studio 怎么收费？

官方桌面页未展示价格；Manus 的订阅与资费见[官方价格页](https://manus.im/pricing)。
