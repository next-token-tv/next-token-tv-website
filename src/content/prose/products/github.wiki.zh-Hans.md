## GitHub 是什么

GitHub 是面向开发者的代码托管与协作平台，官方的定位是"The complete developer platform to build, scale, and deliver secure software"。它由 GitHub, Inc. 运营，2018 年起是[微软](/wiki/brands/microsoft)的子公司。GitHub 基于 Git 这个分布式版本控制工具提供托管服务，用 Git 做版本管理、用 GitHub 做协作、自动化和软件分发。

## 用途与使用边界

按官方介绍，平台的常用能力包括：托管 Git 仓库并通过 Pull Request 和 Issues 进行代码评审与任务管理；用 [Actions](https://github.com/features/actions) 自动化构建、测试和部署等工作流；用 Codespaces 快速获得云端开发环境；代码安全扫描与密钥保护；通过 Sponsors 资助开源开发者。AI 方面，官方提供 [Copilot](https://github.com/features/copilot) 编码助手，可以把任务从 Issue 一路推进到合并。

GitHub 本身不替代开发者的工程判断：代码评审、权限配置、密钥管理和依赖安全仍由使用者和团队负责。平台的免费与付费计划、功能配额会调整，以[官方页面](https://github.com/about)为准。

## 常见问题

### GitHub 是什么？

GitHub 是基于 Git 的代码托管与协作平台：开发者把代码放在仓库里，通过 Pull Request、Issues、Actions 等功能完成评审、跟踪、自动化和发布，官方定位见 [github.com/about](https://github.com/about)。

### GitHub 和 Git 有什么区别？

Git 是一个分布式版本控制工具，由开发者在本地和服务器上使用；GitHub 是基于 Git 的在线托管与协作平台，在版本管理之外提供评审、自动化、安全和 AI 等服务。没有 GitHub 也可以用 Git，但两者通常配合使用。

### GitHub 的官网和注册入口在哪里？

官网是 [github.com](https://github.com/)，首页即可注册账号；平台介绍见 [About 页面](https://github.com/about)。桌面端、移动端和命令行工具都从官方页面进入。

### GitHub Copilot 是什么？

Copilot 是 GitHub 官方提供的 AI 编码助手，官方页面描述它可以"write better code with AI"，并支持把任务从 Issue 推进到合并。功能、套餐和价格见 [Copilot 官方页面](https://github.com/features/copilot/)。

### GitHub 上的开源代码怎么下载？

每个仓库页面的 Code 按钮提供克隆（clone）地址和打包下载；clone 需要本机安装 Git。具体操作以 [GitHub Docs](https://docs.github.com/) 为准。
