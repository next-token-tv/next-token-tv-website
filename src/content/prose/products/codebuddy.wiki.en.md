## What CodeBuddy is

CodeBuddy is an AI coding assistant from Tencent Cloud, positioned by its maker as an intelligent programming tool that brings AI into the whole process from product concept to product release. It comes in two forms — CodeBuddy IDE (an all-in-one development workbench) and CodeBuddy Code (a command-line tool) — plus editor plugins for mainstream development environments. The international site is [codebuddy.ai](https://www.codebuddy.ai/); the Chinese entry point is the [Tencent Cloud CodeBuddy page](https://copilot.tencent.com/).

## Usage and boundaries

- CodeBuddy IDE: the official introduction centers on "Conversation as Programming" — generating structured requirement documents (PRD) from natural language, producing design mockups from prompts or sketches, and converting designs to front-end and back-end code through built-in Figma functionality, alongside real-time code completion, multi-file code generation and inline chat. See the [official IDE introduction](https://www.codebuddy.ai/docs/ide/Introduction).
- CodeBuddy Code (CLI): drives development tasks from the terminal in natural language. The official documentation covers installation, login, Shell/file/network operations, task orchestration, MCP, IDE integrations, GitLab CI/CD and Dev Container, aimed at professional developers automating work inside existing terminal workflows. See the [CLI documentation](https://www.codebuddy.ai/docs/cli/overview).
- Editor plugins: the official Chinese documentation describes code completion, code explanation, code review, unit tests, inline chat, a RAG knowledge base, custom agents, the Craft agent and MCP Server, with integration chapters for Visual Studio 2022, Xcode and the WeChat mini-program development IDE. Entry point: the [official documentation](https://www.codebuddy.ai/docs).

Features, available models and distribution across these forms change with releases; consult the official documentation before relying on them.

## Frequently asked questions

### Who makes CodeBuddy?

CodeBuddy is made by Tencent Cloud. The international site [codebuddy.ai](https://www.codebuddy.ai/) titles the product "Tencent Cloud Code Assistant CodeBuddy", and the Chinese entry point is the [Tencent Cloud product page](https://copilot.tencent.com/).

### What is the difference between CodeBuddy IDE and CodeBuddy Code?

Per the [official documentation](https://www.codebuddy.ai/docs/ide/Introduction), CodeBuddy IDE is a graphical workbench covering requirements, design, development and deployment, while CodeBuddy Code is a [command-line tool](https://www.codebuddy.ai/docs/cli/overview) for natural-language-driven work in an existing terminal workflow. They target different roles and can be used together.

### How do I install the CodeBuddy CLI?

Installation steps and system requirements are in the official [CLI installation guide](https://www.codebuddy.ai/docs/cli/installation); after installing, follow the [Quickstart](https://www.codebuddy.ai/docs/cli/quickstart) to sign in.

### Are CodeBuddy and WorkBuddy the same thing?

No. CodeBuddy is Tencent Cloud's AI coding assistant; [WorkBuddy](/en/wiki/products/workbuddy) is a separate office-oriented agent product with no corporate relationship to CodeBuddy. The podcast mentions them side by side when discussing how vendors' product lineups align, not because they are one product.
