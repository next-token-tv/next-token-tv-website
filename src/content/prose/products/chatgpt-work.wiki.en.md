## What ChatGPT Work is

ChatGPT Work is the work agent inside ChatGPT for longer, multi-step tasks and finished deliverables. Per the [official help article](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex), ChatGPT contains three modes — Chat, Work, and Codex: Chat handles quick conversational help, Codex is dedicated to software development and technical work, and Work researches a topic, analyzes information, or produces a document, spreadsheet, presentation, report, or site. Tasks can run once, repeat on a schedule or trigger, or monitor for changes through Scheduled Tasks, while you review progress, answer questions, and approve actions.

## Usage and boundaries

The typical pattern is to hand Work a goal, context, and delivery requirements, then let it complete the steps and return a finished artifact. On web and mobile, Work runs in the cloud; in the desktop app, Work can use local files and apps with permission, and the official article notes that messages and task context may be stored in the cloud even when work runs locally. Its usage follows the same structure as Codex, with allowances that vary by subscription plan — see the [official article](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex) and the [ChatGPT pricing page](https://chatgpt.com/pricing/).

This entry covers the work agent itself; the general assistant is described in the [ChatGPT](/en/wiki/products/chatgpt) entry. Against [Codex](/en/wiki/products/codex), the difference is that Codex has a separate desktop-app view dedicated to software development, while Work targets general document- and research-type deliverables.

## Frequently asked questions

### What is ChatGPT Work?

It is the work agent inside ChatGPT for longer, multi-step tasks and finished deliverables — documents, spreadsheets, presentations, reports, sites — with scheduled and triggered runs, per the [official help article](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex).

### Are ChatGPT Work and Codex the same thing?

No. The official article positions Codex as dedicated to software development and technical work, with a separate desktop-app view; Work covers research, analysis, and document-type deliverables. They share the same usage structure but have different workflows and entry points.

### What is the difference between ChatGPT Work and regular Chat?

Chat handles quick conversational help; Work completes multi-step tasks and returns a deliverable, syncing across web, mobile, and desktop, where cloud Work chats remain visible. The practical rule: for a finished document or report use Work, for an answer use Chat.

### Where can I use ChatGPT Work?

Work is integrated into ChatGPT: web and mobile run in the cloud, and the desktop app (macOS/Windows) can use local files and apps with permission. The official article notes availability is expanding gradually; current entry points and limits follow the [official article](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex).

### Does ChatGPT Work cost extra?

Work follows the same usage structure as Codex, consuming allowance faster or slower depending on task complexity, input and output size, and reasoning settings, within your plan's quota. Current plans and allowances are on the [ChatGPT pricing page](https://chatgpt.com/pricing/) and in the [official article](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex).
