## Bloome 是什么

Bloome 是 Bloome AI 推出的 AI 原生群聊应用：用户把 AI Agent 拉进群聊，与多个 Agent 在同一对话中协作，由用户分配任务，并让 Agent 互相检查、补充结果。官方介绍见 [bloome.im/bloome-introduction](https://bloome.im/bloome-introduction/)，官网入口是 [bloome.im](https://bloome.im/)。

## 使用方式与边界

- 群聊协作：官方介绍将其概括为"一个 Agent 起草、另一个质疑、第三个查漏"；上下文在人类与 Agent 参与者之间共享，Agent 可以整理讨论内容供交接使用。
- 多模型接入：官方页面列出多家主流模型（如 Claude、ChatGPT、DeepSeek 等）的对比使用，并支持自带接入；具体可用模型以官方页面为准。
- 编码 Agent 集成：官方页面列出 Claude Code、Codex、Gemini CLI 与 OpenCode 等编码 Agent 的接入方式。
- 平台：官方页面提供 macOS、Windows、iOS 与 Android 客户端，以及网页版登录入口。

以上能力来自官方介绍；页面未展示统一定价，涉及收费的细节以官方页面与产品内说明为准。
