## What Codex is

Codex is OpenAI’s coding agent for software development across editors, terminals, the desktop app, and the cloud. Its role is more than returning a code fragment: it can help understand a repository, edit files, run checks, and produce work that a person can review. Current entry points and capabilities belong to the [Codex product page](https://openai.com/codex/) and [developer documentation](https://developers.openai.com/codex/).

## Uses and boundaries

Codex is suited to feature work, fixes, refactors, tests, and documentation when the task, repository context, project rules, and verification steps are clear. Results still depend on the context supplied, tool permissions, tests, and human review. Passing tests alone does not establish that architecture, dependencies, data handling, or security are correct.

Codex output still needs diff review and project checks. For general conversation and file analysis, see [ChatGPT](/en/wiki/products/chatgpt).

## Frequently asked questions

### What is Codex?

Codex is OpenAI’s coding agent for software-development tasks across editors, terminals, the desktop app, and the cloud. Unlike a tool that only returns a snippet, it is designed to help move a repository task through context, changes, and verification.

### How do I get started with Codex?

Start at the [Codex product page](https://openai.com/codex/) and use the [developer documentation](https://developers.openai.com/codex/) to select an editor, terminal, or cloud workflow. 

### Where do I start with Codex CLI or the app?

Use the [Codex developer documentation](https://developers.openai.com/codex/) to choose the CLI, editor, desktop, or cloud entry point. Confirmation and execution depend on the surface; review the diff and run project checks before committing.

### Where can I check Codex usage?

For Codex with a ChatGPT plan, the [official usage guide](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan) points to Settings or the usage dashboard. API model pricing is a separate question.

### How is Codex different from Claude Code and ChatGPT?

[ChatGPT](/en/wiki/products/chatgpt) is a general assistant; Codex and [Claude Code](/en/wiki/products/claude-code) focus on software-engineering tasks, provided by OpenAI and Anthropic respectively. Compare the actual entry point, tools, and permissions for the workflow.
