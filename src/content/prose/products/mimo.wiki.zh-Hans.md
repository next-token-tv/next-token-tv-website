## MiMo 是什么

MiMo 是小米研发的 AI 模型家族，覆盖推理、编程、智能体执行、多模态理解以及语音合成与识别，官方站点为 [mimo.mi.com](https://mimo.mi.com/)。官方新闻页显示，MiMo-V2.5 系列于 2026 年开启公测，页面列出 `mimo-v2.5`、`mimo-v2.5-pro`、MiMo-V2.5-TTS 系列和 MiMo-V2.5-ASR 等成员，其中 V2.5 系列支持百万级上下文，官方还宣布了该系列的开源计划。模型名称、成员与状态以[官方模型介绍](https://mimo.mi.com/models/zh-CN/mimo-v2.5)和[官方动态页](https://mimo.mi.com/docs/zh-CN/news/latest/v2.5-news)为准。

## 用途与使用边界

MiMo 提供与 OpenAI、Anthropic 兼容的 API，按 Token Plan 订阅或用量计费；官方站点还列有 MiMo Desktop、MiMo Code、MiMo Claw、MiMo Studio 等产品和 Claude Code 等第三方工具的接入说明。开发者接入时应使用官方站点提供的 API 地址和模型名称，不要凭名称猜测能力或价格。

需要区分"Mimo"指代：与其他同名缩写（如通信领域的 MIMO 技术）无关时，本条目指小米的模型家族。模型会在版本演进中调整价格、配额和开源范围，这类时效状态应以官方页面为准。

## 常见问题

### MiMo 是什么，是小米的吗？

是。MiMo 是小米研发的 AI 模型家族，覆盖推理、编程、智能体和多模态任务；官方站点 [mimo.mi.com](https://mimo.mi.com/) 页脚署名 Xiaomi，社区账号也在 GitHub 和 Hugging Face 的 XiaomiMiMo 名下。注意与通信领域 MIMO（多输入多输出技术）等同名术语区分。

### MiMo 官网在哪里？

官方站点是 [mimo.mi.com](https://mimo.mi.com/)，包含模型介绍、API 文档、动态和产品入口；不要从不明镜像站获取模型或安装包。

### MiMo 有 API 吗，怎么收费？

有。官方提供与 OpenAI、Anthropic 兼容的 API，计费采用 Token Plan 订阅与用量结合的方式，官方还列出夜间折扣等规则。当前模型清单与费率见[官方站点](https://mimo.mi.com/)与[定价说明](https://mimo.mi.com/docs/zh-CN/news/latest/v2.5-news)，本文不固定具体价格。

### MiMo 开源了吗？

官方新闻页宣布 MiMo-V2.5 与 MiMo-V2.5-Pro 有开源计划；开源范围、许可证和放出的时间安排以[官方动态页](https://mimo.mi.com/docs/zh-CN/news/latest/v2.5-news)和 GitHub 上 XiaomiMiMo 组织的发布为准。
