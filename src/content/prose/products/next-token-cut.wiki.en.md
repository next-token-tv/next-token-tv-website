## Definition

Next Token Cut is a local editing and subtitle workspace built by Next Token host Yang Pan for producing the show. In the episode he describes it as "a Studio with a dedicated UI that helps us cut the show". The tool has no public product page; everything publicly known comes from the episode itself. See the [episode 007 page](https://nexttoken.tv/weekly/007).

## How it works

Per the episode, it is an interface and feature set tailored to its maker’s own editing workflow, replacing general-purpose editing software for this show’s cutting and subtitle pipeline. Its feature scope, implementation, and runtime environment are not documented publicly, so this page does not speculate.

## Usage

It is used in producing the Next Token podcast. In the same discussion, Yang Pan notes that creators such as Liu Run and Kuaidao Qingyi are doing similar things — building editing studios customized to their own workflows — which is his observation about a broader practice, not a documented capability of the tool.

## Related and confusable terms

Next Token Cut is a production tool and is catalogued separately from the [Next Token](/en/wiki/brands/next-token) show brand; it is also not a published product in the same category as general-purpose editors like CapCut (剪映), whose role came up only as context in the discussion.

## Episode discussion

In Weekly #007, in the chapter “自己造剪辑工具：自动化与渲染的等待” (Chinese transcript), Yang Pan explains the origin: "to edit our show, I built something called Next Token Cut, a Studio", and observes that more and more creators are building editing tools around their own workflows this way ([paragraph](/weekly/007/transcript#quote-5fb955bdd7acfba2b75f)). The same chapter also covers the waiting time of AI-generated edits and how video rendering depends on the device’s CPU/GPU. See the [chapter](/weekly/007/transcript#chapter-05).
