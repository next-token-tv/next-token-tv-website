## Windows 是什么

Windows 是 Microsoft 开发的个人电脑操作系统家族，覆盖笔记本、台式机、游戏 PC 和二合一设备等形态。官方产品页当前以 Windows 11 为主要版本，介绍窗口贴靠布局、Microsoft 应用内的 Copilot、游戏生态和 Windows Hello 登录等内容；产品形态与功能的最新口径见 [Microsoft Windows 官方页](https://www.microsoft.com/windows/)。

## 版本与使用边界

按官方支持页，Windows 10 已于 2025 年 10 月 14 日结束支持：系统仍可继续运行，但 Microsoft 不再提供软件更新、安全修复和技术支持。官方给出的后续路径包括：符合条件的电脑通过 Windows Update 免费升级到 Windows 11、加入扩展安全更新（ESU）计划，或购买新电脑，详见[官方支持状态页](https://www.microsoft.com/en-us/windows/end-of-support)。

对日常使用而言，Windows 的入口是随设备预装或从官方渠道获取的系统本体；AI 功能（如 Copilot）可能依赖订阅、硬件或地区条件。与 macOS、Linux 等系统相比，Windows 的差别主要体现在硬件选择范围、软件生态和系统管理方式上，具体取舍取决于使用场景。

## 常见问题

### Windows 官网在哪里？

官方产品页是 [microsoft.com/windows](https://www.microsoft.com/windows/)，包含当前版本介绍、设备类型和功能说明。下载和升级相关的入口也应从 Microsoft 官方域名进入，避免使用第三方下载站。

### Windows 10 还受支持吗？

不支持了。官方支持页写明 Windows 10 于 2025 年 10 月 14 日结束支持，之后不再有软件更新、安全修复和技术支持；可选路径包括升级 Windows 11、扩展安全更新（ESU）计划或更换设备，详见[官方页面](https://www.microsoft.com/en-us/windows/end-of-support)。

### 从 Windows 10 升级到 Windows 11 免费吗？

官方支持页说明，符合条件的 Windows 10 电脑可以通过 Windows Update 免费升级到 Windows 11；是否满足最低硬件要求以官方升级页面和系统检测为准。

### Windows 12 出了吗？

Windows 官方产品页当前列出的是 Windows 11，页面没有新版本的信息。新版本若有官方发布，会在 [Microsoft Windows 官方页](https://www.microsoft.com/windows/)公布；网络上的传闻、截图和泄露不应作为依据。
