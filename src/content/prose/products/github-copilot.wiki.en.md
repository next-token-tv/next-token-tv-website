## What GitHub Copilot is

GitHub Copilot is an AI coding assistant and coding agent from GitHub. On June 29, 2021, GitHub released Copilot in technical preview, running in VS Code on top of OpenAI Codex; on June 21, 2022, it left preview as a paid subscription for individual developers (free for students and verified open-source maintainers); in December 2024 a free tier was added. Plugins for JetBrains, Visual Studio, and other editors followed during the preview period.

GitHub Copilot now covers several stages of software development: code completions and next-edit suggestions, Copilot Chat, code review, and a coding agent — you can assign an issue to Copilot, and a cloud agent completes the change on its own branch and returns a pull request (introduced in public preview in 2025). There is also Copilot CLI, plus model selection spanning multiple providers, including connecting your own API key or local models.

## Uses and differences

GitHub Copilot reaches you in three ways: editor extensions (officially supporting Visual Studio Code, Visual Studio, JetBrains IDEs, Xcode, Vim, Neovim, Zed, Eclipse, and more), the command line (Copilot CLI), and GitHub itself — using the agent and review features directly on issues and pull requests. Plans range from a free tier to individual Pro and business offerings; quotas and prices are on the [official pricing page](https://github.com/features/copilot/plans).

It is not a chatbot product: GitHub Copilot is for developers and works against codebases, issues, and pull requests. The general-purpose assistant for questions, search, and content creation is a separate product, [Microsoft Copilot](/en/wiki/products/microsoft-copilot).

## Related concepts

GitHub Copilot and [Microsoft Copilot](/en/wiki/products/microsoft-copilot) share the Microsoft family and a similar name, but not a role: GitHub Copilot is the developer's coding assistant and agent, built around repositories and software-engineering workflows, while Microsoft Copilot is a personal AI assistant for everyday users. When you read claims like "Copilot cited some website" in the press, check which product is meant — the two have different information paths. Microsoft 365 Copilot, the work-focused Copilot inside the Microsoft 365 apps, is yet another product and not GitHub Copilot.

## Frequently asked questions

### Is GitHub Copilot free?

Since December 2024 there has been a free tier with a monthly quota of completions and basic features; students and teachers can get free access through verification. Paid individual plans sit above the free tier. Current quotas are on the [official pricing page](https://github.com/features/copilot/plans).

### How is GitHub Copilot priced?

Individuals get a free tier and paid plans; businesses have separate offerings, differing in model choice, agent usage, and review features. Current prices and plan contents are on the [official pricing page](https://github.com/features/copilot/plans).

### Which editors does GitHub Copilot support?

Officially Visual Studio Code, Visual Studio, JetBrains IDEs, Xcode, Vim, Neovim, Zed, and Eclipse, plus Copilot CLI and entry points on GitHub and mobile. The full list is in the [GitHub Copilot documentation](https://docs.github.com/en/copilot).

### Can GitHub Copilot complete a task on its own?

Yes, within limits: in the coding-agent mode you assign an issue to Copilot, it creates a branch in the cloud, writes the change, and returns a pull request for human review and merge. The capability was introduced in public preview in 2025; current scope is described in the [GitHub Copilot documentation](https://docs.github.com/en/copilot).

### How is GitHub Copilot different from Microsoft Copilot?

They are different products: GitHub Copilot is the developer-facing coding assistant and coding agent built around repositories, issues, and pull requests; [Microsoft Copilot](/en/wiki/products/microsoft-copilot) is the general-purpose AI assistant for individual users. Similar names, different entry points, subscriptions, and uses.
