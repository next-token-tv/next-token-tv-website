## Jimeng AI

Jimeng (Jimeng AI) is a consumer AI image and video generation application whose site tagline reads "即刻造梦" ("dream instantly"). The official page lists three capability areas: AI image generation supports text-to-image and image-to-image, with edits such as background replacement, style association, style preservation, and pose preservation; video generation turns text or images into clips, with first-frame and last-frame image inputs for controllability and Chinese-language prompting as a stated strength; the smart canvas offers inpainting, one-click outpainting, object removal, cutout, and multi-layer editing. The site also hosts a community where users share works and remix others' creations. Features and available models change; the [Jimeng website](https://jimeng.jianying.com/) is authoritative before use.

## Ownership and ecosystem

The footer of the Jimeng site names Shenzhen Lianmeng Technology Co., Ltd. as the operator — the same entity behind Jianying (known internationally as CapCut) — and the domain jimeng.jianying.com places it in ByteDance's product line (see [ByteDance](/en/wiki/brands/bytedance)). Its division of labor with [Jianying](/en/wiki/products/jianying) differs: Jianying is for editing finished videos, while Jimeng generates footage and imagery.

Jimeng's international counterpart is Dreamina, hosted at [dreamina.capcut.com](https://dreamina.capcut.com/). Seed, ByteDance's video generation model family ([Seedance](/en/wiki/products/seedance)), is labeled "Dreamina Seedance 2.5" on the BytePlus cloud service; which model version backs each feature inside the domestic Jimeng app is not itemized on official pages, so in-app information is authoritative. Membership and credit billing are time-sensitive; see the subscription page on the official site.

## Discussion in the show

Episode 005, in the chapter "从 Descript 到软件成为 Agent 插件" (From Descript to software as agent plugins), discussed whether software should turn itself into an agent plugin. Orange cited Jianying's MCP as an example, and [Guizang corrected him: "Jianying doesn't have one — Jimeng has an MCP, Jimeng has a CLI"](/weekly/005/transcript#quote-823cd0b3011a633e8f55), holding Jimeng up as an example of a content app opening interfaces to the agent ecosystem. [Yang Pan then framed the whole discussion as "software should stop building its own agents and turn itself into an agent harness"](/weekly/005/transcript#quote-78ef3e13ccc0b6f81cc1). The claim that Jimeng has an MCP and a CLI is a participant statement; no corresponding official documentation has been found, and developer integration should follow official announcements. ## Frequently asked questions

### What is Jimeng AI?

Jimeng AI is an AI image and video creation application operated by Shenzhen Lianmeng Technology, the entity behind Jianying, within ByteDance's product line. It offers text-to-image, image-to-image, text/image-to-video generation, and canvas editing; the site is [jimeng.jianying.com](https://jimeng.jianying.com/).

### Where is the Jimeng official site?

The web entry point is [jimeng.jianying.com](https://jimeng.jianying.com/); creation features require signing in. The app can be found in app stores under "即梦", with download links on the official site.

### What is the relationship between Jimeng and Jianying?

Both belong to Shenzhen Lianmeng Technology: Jianying is a video editing tool, Jimeng is an AI generation tool, and the jimeng.jianying.com domain reflects that ownership. One is for editing, the other for generating, and their workflows are often combined.

### What is Jimeng's international version?

Jimeng's overseas counterpart is Dreamina at [dreamina.capcut.com](https://dreamina.capcut.com/); the Seedance 2.5 video model on BytePlus is likewise labeled "Dreamina Seedance 2.5". Features and model versions may differ between the two markets.

### Does Jimeng have an API or MCP?

No public developer API entry point is listed on official pages. On episode 005 Guizang said "Jimeng has an MCP, Jimeng has a CLI"; this is a show statement, no corresponding official documentation has been found, and developer integration should follow official channels.
