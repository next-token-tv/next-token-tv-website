## 定义

OPPO Find N 是 [OPPO](/wiki/brands/oppo) 的折叠屏智能手机系列，属于横向对折的大折叠形态。初代 Find N 于 2021 年发布，此后陆续推出 Find N2（2022 年）、Find N3（2023 年）、Find N5（2025 年）等后续机型，并延伸出 Find N2 Flip、Find N3 Flip 等竖向折叠的 Flip 机型。在售型号与官方信息见 [OPPO 官网](https://www.oppo.com/cn/smartphones/)。

## 设计特点

Find N 系列的标志性设计是"窄折叠"：折叠后的机身比例接近普通直板手机，握持长度与常规手机相近，展开后则获得更大的方形内屏。这一形态从初代 Find N 起延续至今，是它与展开比例更修长的其他大折叠机型的主要区别。此外，系列中的 Flip 机型采用竖向折叠，与大折叠形态互补。

## 易混概念

Find N 是大折叠系列，Find N Flip 是竖折机型，两者同属 Find 系列但形态不同；与苹果的 [iPhone](/wiki/products/iphone) 折叠机型、小米等厂商的折叠产品同处一个市场。OPPO 品牌的整体业务见 [OPPO](/wiki/brands/oppo) 条目。

## 常见问题

### OPPO Find N 系列有哪些机型？

初代 Find N（2021 年）之后，大折叠形态陆续推出 Find N2（2022 年）、Find N3（2023 年）、Find N5（2025 年）等，另有 Find N2 Flip、Find N3 Flip 等竖向折叠的 Flip 机型。各机型的官方信息见 [OPPO 官网](https://www.oppo.com/cn/smartphones/)。

### Find N 和 Find Flip 有什么区别？

Find N 系列采用横向对折的大折叠形态，折叠后接近普通手机的尺寸，展开后是更大的内屏；Flip 机型采用竖向折叠，折叠后更短小、展开后与直板手机接近。两者同属 OPPO Find 系列，面向不同使用偏好。

### Find N 系列的窄折叠是什么意思？

"窄折叠"指折叠后的机身较窄、比例接近普通直板手机，握持感与常规手机相近，这是 Find N 系列从初代起的设计特点。第八期节目中橘子也提到它"折起来那个长度跟手机差不多，就很好用"。

### OPPO 折叠屏的折痕表现如何？

第八期节目中，橘子称有人使用 Find N6 数月后看不到折痕，歸藏称 OPPO 的折痕控制比苹果更好——这些是参与者的主观评价。折痕表现因机型、贴膜与使用习惯而异，购买前建议实际体验或参考针对具体机型的评测。
