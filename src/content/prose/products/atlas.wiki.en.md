## What ChatGPT Atlas was

ChatGPT Atlas was a web browser from [OpenAI](/en/wiki/brands/openai) with ChatGPT built in — the official tagline was "The browser with ChatGPT built in." It launched on October 21, 2025 on macOS worldwide for Free, Plus, Pro, and Go users (Business in beta; Enterprise and Edu enabled by plan administrators), with the option to import bookmarks, passwords, and browsing history from an existing browser during setup.

## Features and current status

Features at launch included: calling ChatGPT on the page you are viewing, with ChatGPT memory so chats can draw on past conversations; Agent mode (in preview for Plus, Pro, and Business users), which could research, carry out tasks, and book appointments but — per OpenAI’s own boundaries — could not run code in the browser, download files, or install extensions, could not access other apps or the file system, and paused on sensitive sites such as financial institutions; and optional browser memories that the user could view, archive, or delete. On privacy, browsing content was not used for model training by default, and visibility could be controlled per site from the address bar.

OpenAI’s official announcement page now carries a notice that the product "has since been deprecated" and points users to [ChatGPT Work](/en/wiki/products/chatgpt-work) and the release notes. At launch, Windows, iOS, and Android experiences were listed as "coming soon."

## Frequently asked questions

### What was ChatGPT Atlas?

A web browser with ChatGPT built in, released by OpenAI on October 21, 2025 on macOS. The official announcement page now marks the product as deprecated and points users to [ChatGPT Work](/en/wiki/products/chatgpt-work).

### Can I still download ChatGPT Atlas?

The official announcement page marks it as deprecated and directs users to ChatGPT Work and the release notes; that page offers no replacement download. Check the [official announcement page](https://openai.com/index/introducing-chatgpt-atlas/) for its current status.

### How did ChatGPT Atlas relate to ChatGPT?

Atlas was the form factor of putting ChatGPT inside a browser: ChatGPT callable on any page, tied into ChatGPT memory, with Agent mode and browser memories (all per the launch-time official description).

### Did ChatGPT Atlas have a Windows or mobile version?

At launch, Windows, iOS, and Android experiences were listed as "coming soon," with macOS the only shipping platform; the official page never listed those versions as shipped and now marks the product deprecated.

### What were the limits of Atlas’s Agent mode?

The official launch-time boundaries: no running code in the browser, no downloading files, no installing extensions, no access to other apps or the file system, and pausing on sensitive sites such as financial institutions. OpenAI also warned that agents can be vulnerable to hidden malicious instructions in webpages and recommended logged-out mode and supervision.
