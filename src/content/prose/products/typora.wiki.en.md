## What is Typora

Typora is what its [official site](https://typora.io/) calls a "minimal markdown editor": instead of a separate preview window or an edit/preview mode switch, source and rendered output appear in the same interface, which the site describes as "What You See Is What You Mean". It runs on macOS, Windows, and Linux, and is sold as a paid license (the site lists a 15-day free trial, with one license covering up to 3 devices); current pricing belongs to [the official page](https://typora.io/).

## Features and boundaries

Typora's features center on writing: drag-and-drop images, resizable tables, syntax-highlighted code fences, math via MathJax, diagrams via Mermaid and flowchart, a focus mode and a typewriter mode, a file tree and outline panel, `[TOC]`, footnotes, and YAML front matter. Export covers PDF (with bookmarks), docx, LaTeX, Epub, and more, and themes are customized through CSS. It is a local editor: documents live in the user's own filesystem, and collaboration or cloud sync needs to come from other tools.

## Frequently asked questions

### Is Typora free?

No. The [official site](https://typora.io/) lists a 15-day free trial; continued use requires purchasing a license, and one license covers up to 3 devices. Pricing and license terms belong to the official page.

### Which platforms does Typora support?

Official builds are available for macOS, Windows (x64, 32-bit, and ARM), and Linux. Download links are on [the official site](https://typora.io/).

### How is Typora different from ordinary Markdown editors?

The main difference is live preview: Typora has no separate preview pane or mode switch — Markdown renders in place as you type, which the official site calls "What You See Is What You Mean".
