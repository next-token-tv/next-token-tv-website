## What Grok is

Grok is the frontier-model and AI-assistant family from xAI. After xAI [announced its merger into SpaceX](https://x.ai/news/xai-joins-spacex) in February 2026, the company's site has operated under the SpaceXAI brand, with Grok covering reasoning, code, voice, images, and video. The name refers to two related things: the [Grok assistant](https://x.ai/grok/) for everyday users (chat, search, image and video generation, voice conversations), and the model API for developers. This page covers the family as a whole; Grok Bot, the always-on cloud agent, is a separate product on the same line — see [Grok Bot](/en/wiki/products/grok-bot).

## Product forms and usage

Consumer entry points include the [grok.com](https://grok.com/) web app, iOS and Android apps, and Grok inside X. Per the official pages, the assistant supports everyday chat and writing, search that combines the live web and X with citations, text-to-image and text-to-video generation (Imagine), voice conversations, file and image understanding, and a multi-agent mode that runs parallel agents on complex questions.

The developer entry point is the [official documentation site](https://docs.x.ai/): a unified API spans text, code, voice, images, and video, with an OpenAI-compatible endpoint (api.x.ai/v1) plus Python, TypeScript, and other SDKs. Which models are current changes over time; treat the official model pages as authoritative.

## Boundaries

The Grok assistant is free to try, and a [SuperGrok subscription](https://grok.com/plans) adds higher limits and priority access; the developer API is billed by usage, with custom quotas and deployment options for enterprise customers. This page does not fix prices or quotas — see the official pages. As with any AI assistant, search results and generated content should be verified independently, and officially listed features and regional availability can change between releases.

## FAQ

### What is Grok?

Grok is the frontier-model and AI-assistant family from SpaceXAI (the brand xAI operates under after merging into SpaceX), offering web and mobile assistants, an entry inside X, and a developer API. See the [official introduction](https://x.ai/grok/).

### Who makes Grok?

Grok is developed by xAI; xAI announced its merger into SpaceX in February 2026 and the site now runs under the SpaceXAI name. See the [announcement](https://x.ai/news/xai-joins-spacex).

### What is the difference between Grok and Grok Bot?

Grok is the model and assistant family (chat, search, generation, API); Grok Bot is an autonomous agent on the same product line that runs on a persistent cloud computer and takes multi-step tasks via messages. See [Grok Bot](/en/wiki/products/grok-bot).

### How much does Grok cost?

The official assistant pages say it is free to try, with a SuperGrok subscription adding higher limits and priority access; the developer API is usage-based. Plans and rates are at [grok.com/plans](https://grok.com/plans) and official pricing pages — this page does not fix numbers.

### Where do I get access to the Grok API?

Developers get API keys and integration guides from the [official documentation site](https://docs.x.ai/), which offers an OpenAI-compatible endpoint (api.x.ai/v1) and Python, TypeScript, and other SDKs.

### Does "grok" mean anything else?

Yes. As an English word, "grok" comes from Robert Heinlein's 1961 science-fiction novel *Stranger in a Strange Land*, where it is a Martian term. Etymology results in search results are unrelated to xAI's Grok.
