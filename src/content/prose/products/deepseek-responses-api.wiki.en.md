## Definition

DeepSeek’s Responses-format model API accepts inputs, instructions, and tools, with support for streamed response events.

## Usage and related concepts

DeepSeek documents its own endpoint and Codex integration. Built-in tool availability depends on the model. This interface differs from the separate Search / Fetch API, which can supply search results to applications using other models.
