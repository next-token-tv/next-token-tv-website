## Linear 是什么

Linear 是面向产品与研发团队的工作管理应用，官网将其定位为"产品开发系统"（The system for product development），覆盖问题跟踪（Issues）、项目（Projects）、周期（Cycles）、规划（Initiatives）与文档（Documents）等产品开发全流程，并强调为人类与 Agent 协作的 AI 时代设计。官网是 [linear.app](https://linear.app/)，产品更新发布在 [Changelog](https://linear.app/changelog)。

搜索时注意区分：linear 作为英文形容词和"线性代数"（linear algebra）等数学概念与此产品无关；找这款产品时通常需要加上 app、project management 或域名修饰。

## 用途与使用边界

- 核心工作流：用 Issue 跟踪任务，用 Cycle 按周期规划迭代，用 Project 与 Initiative 组织跨团队目标；官方页面还描述了 Intake——把会话、客户反馈自动转为 issue 并路由、打标、排优先级。
- AI 与 Agent：Linear Agent 可以在 issue 中被点名认领任务、产出 Draft PR 等改动；官方定价页列出的 AI 能力包括 Triage Intelligence、Linear Asks、Code Insights 与 MCP access。Loops 是官方描述的自动化循环：可由工作区事件触发、编辑文档、向 Slack 发送更新，每次运行都是一段可继续对话的 Agent 会话。
- 集成：官方页面列出的集成包括 Slack、GitHub、Zendesk、Intercom 等，另有 API 与 webhook。
- 计费：提供免费版与按人计费的付费档，具体见下文 FAQ 与[官方定价页](https://linear.app/pricing)。

使用边界：Linear 的定位是产品开发协作系统，不是通用项目管理或工单系统；功能与档位随版本变化，以官方页面为准。

## 常见问题

### Linear 是什么软件？

Linear 是面向产品与研发团队的工作管理应用，用于跟踪 issue、规划周期与项目、协调产品开发，官方定位为"产品开发系统"。见[官方网站](https://linear.app/)。

### Linear 怎么收费？有免费版吗？

有。截至 2026 年 9 月，官方定价页列出 Free（免费，不限成员、2 个团队、250 个 issue）、Basic（每人每月 10 美元，按年计费）、Business（每人每月 16 美元，含 Loops、Triage Intelligence 等）与 Enterprise（定制，仅年付）四档。当前档位与价格以[官方定价页](https://linear.app/pricing)为准。

### Linear 和 Jira 有什么区别？

两者都是面向研发团队的工作管理工具。Linear 官方定位强调速度、降噪与为人类和 Agent 协作设计的 AI 工作流；Jira 的定位与生态以其官方资料为准。具体选择取决于团队规模与流程习惯。

### Linear 的 AI 功能有哪些？

按官方资料：Linear Agent 可认领 issue 并完成改动（如提交 Draft PR）；Loops 由工作区事件触发、能编辑文档并向 Slack 发送更新；定价页还列有 Triage Intelligence、Linear Asks、MCP access 等。功能归属的档位随版本变化，见[官方定价页](https://linear.app/pricing)与 [Changelog](https://linear.app/changelog)。

### Linear 支持哪些集成？

官方页面列出的集成包括 Slack、GitHub、Zendesk、Intercom 等，另有 API 与 webhook 接入和 MCP 支持，可用于把外部会话与事件转为 issue 或驱动 Agent。见[官方网站](https://linear.app/)。
