## What Sublime Text is

Sublime Text is a cross-platform text editor developed by Australia's Sublime HQ, billed by its maker as "the sophisticated text editor for code, markup and prose". As of October 2026 the major release is Sublime Text 4, available for Windows, macOS (with native Apple Silicon support), and Linux, including ARM64 builds for devices like the Raspberry Pi. The editor is known for being fast and light: the official site highlights GPU-rendered UI up to 8K resolutions, multi-tab split views, context-aware auto complete, and a syntax engine with TypeScript/JSX/TSX support shipped by default. Plugins are written against a Python API that stays backwards compatible with Sublime Text 3 packages, and the same company makes the Git client Sublime Merge.

## Usage and boundaries

Sublime Text suits quickly opening and editing single files, huge files, and lightweight text processing: it starts fast, uses few resources, and rewards keyboard-driven use, which is why many developers keep it as the "quick editor" alongside a heavier, extension-driven IDE like VS Code. It is an editor rather than an IDE — deep debugging and refactoring come from the plugin ecosystem, managed through community mechanisms such as Package Control.

Its licensing model is unusual: the official download page states the editor "may be downloaded and evaluated for free" with "currently no enforced time limit for the evaluation", but that "a license must be purchased for continued use". In other words, it is not freeware but a try-first, pay-later product.

## Frequently asked questions

### Is Sublime Text free to use?

The official download page allows free download and evaluation — as of October 2026 with no enforced time limit — but a license must be purchased for continued use; license types and pricing are on the [official site](https://www.sublimetext.com/).

### Where is the Sublime Text website and download?

The official site is [sublimetext.com](https://www.sublimetext.com/), offering installers for Windows, macOS, and Linux, with ARM64 Linux builds for devices like the Raspberry Pi.

### Sublime Text vs VS Code — how do they differ?

Sublime Text is built for speed: fast startup and file switching with a small footprint, ideal for quick edits. VS Code leads with its extension ecosystem and IDE-grade debugging and refactoring. Many developers use both — Sublime for quick changes, VS Code for full development.

### Can Sublime Text edit Markdown?

Yes. It is a text editor at heart, with Markdown highlighting out of the box; preview and formatting enhancements come from plugins. For a true WYSIWYG experience, a dedicated editor like [Typora](/en/wiki/products/typora) fits better.
