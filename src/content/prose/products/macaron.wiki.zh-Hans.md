## Macaron 是什么

Macaron（马卡龙）是一款面向日常生活的个人 AI 智能体。官方页面将其定位为与工作向 Agent 相对的生活向产品——"Other AI agents help you work. Macaron helps you live better."——并提出通过"个人测试"与 Deep Memory 记住对用户重要的信息，像朋友一样随使用成长。官方页面未标注运营公司主体。

## 用途与使用边界

按官方页面口径，Macaron 强调"一次简单请求"就生成用户实际需要的工具（mini-apps），而非演示性 Demo；用户通过 App 或网页入口使用，注册与下载入口见[官方网站](https://macaron.im/)。个性化建立在用户主动提供的偏好与记忆之上，因此涉及个人生活数据的授权与隐私取舍：哪些记忆保留、哪些清除，应在产品内的隐私设置里自行管理。价格未在官方页面展示，以官方渠道说明为准。

## 常见问题

### Macaron 是什么？

一款面向日常生活的个人 AI 智能体，官方定位是用记忆与个性化帮助用户生活，而不仅是提高工作效率；提供按需生成的实用小工具。见[官方网站](https://macaron.im/)。

### Macaron 怎么下载，有 App 吗？

官方页面提供 "Get the app" 与 "Try now" 入口；具体平台与下载方式以[官方网站](https://macaron.im/)当前展示为准。

### Macaron 的 Deep Memory 是什么？

官方页面对 Deep Memory 的描述是记住对用户重要的信息、随使用不断成长，个性化由此而来。它依赖用户数据，使用时应留意产品内的记忆与隐私设置。

### Macaron 怎么收费？

官方页面未展示价格；资费与免费额度以官方渠道的当前说明为准。
