## CodeBuddy 是什么

CodeBuddy 是腾讯云推出的 AI 编程助手，官方将其定位为把 AI 引入从产品构想到产品发布全流程的智能编程工具。产品提供两种形态：CodeBuddy IDE（一体化开发工作台）和 CodeBuddy Code（命令行工具），另有接入主流开发环境的编辑器插件。国际版官网是 [codebuddy.ai](https://www.codebuddy.ai/)，中文入口是[腾讯云代码助手页面](https://copilot.tencent.com/)。

## 使用方式与边界

- CodeBuddy IDE：官方介绍以"对话即编程"（Conversation as Programming）为主线，支持用自然语言生成结构化需求文档（PRD）、从自然语言或草图生成设计稿，并内置 Figma 功能把设计稿转换为前后端代码；同时提供实时代码补全、多文件代码生成和内联对话。见[官方 IDE 产品介绍](https://www.codebuddy.ai/docs/ide/Introduction)。
- CodeBuddy Code（CLI）：在终端中以自然语言驱动开发任务，官方文档覆盖安装、登录、Shell/文件/网络操作、任务编排、MCP、IDE 集成、GitLab CI/CD 与 Dev Container 等场景，面向希望在现有终端工作流中自动化任务的专业开发者。见 [CLI 文档](https://www.codebuddy.ai/docs/cli/overview)。
- 编辑器插件：官方中文文档包含代码补全、代码解释、代码评审、单元测试、内联对话、RAG 知识库、自定义智能体、Craft 智能体与 MCP Server 等功能说明，并提供 Visual Studio 2022、Xcode 和微信小程序开发 IDE 的接入章节。入口见[官方文档](https://www.codebuddy.ai/docs)。

各形态的功能、可用模型与获取方式会随版本调整，使用前以官方文档为准。

## 常见问题

### CodeBuddy 是谁家的产品？

CodeBuddy 是腾讯云的 AI 编程助手。国际官网 [codebuddy.ai](https://www.codebuddy.ai/) 的页面标题即为 "Tencent Cloud Code Assistant CodeBuddy"，中文入口为[腾讯云代码助手页面](https://copilot.tencent.com/)。

### CodeBuddy IDE 和 CodeBuddy Code 有什么区别？

按[官方文档](https://www.codebuddy.ai/docs/ide/Introduction)，CodeBuddy IDE 是覆盖需求、设计、开发与部署的图形化工作台；CodeBuddy Code 是[命令行工具](https://www.codebuddy.ai/docs/cli/overview)，用于在现有终端工作流中以自然语言驱动任务。两者面向的角色和场景不同，可以搭配使用。

### CodeBuddy CLI 怎么安装？

安装步骤与系统要求见官方 [CLI 安装文档](https://www.codebuddy.ai/docs/cli/installation)，安装后按 [Quickstart](https://www.codebuddy.ai/docs/cli/quickstart) 登录使用。

### CodeBuddy 和 WorkBuddy 是一回事吗？

不是。CodeBuddy 是腾讯云的 AI 编程助手；[WorkBuddy](/wiki/products/workbuddy) 是另一款独立的办公向 Agent 产品，两者没有从属关系。节目讨论中把它们并列，指的是大厂产品线分布，不是同一产品。
