## What Cursor is

Cursor is an AI coding product that combines code editing, codebase understanding, and agentic task execution. Its documentation describes Agent as an assistant that can complete complex coding tasks, run terminal commands, and edit code; current entry points and features are documented at [Cursor](https://cursor.com/) and [Agent overview](https://cursor.com/docs/agent/overview).

## Uses and boundaries

Cursor fits workflows that need an editor to explore a repository, plan a feature, change multiple files, run checks, and review a diff. Results depend on the model, prompt, rules, repository context, and tool permissions. An automatic edit is not the same as a tested or merge-ready change.

Cursor also offers background agents. A remote background environment differs from the local workspace in repository sync, credentials, network access, and retention; read the current security and configuration documentation before using it. For terminal-oriented coding-agent comparisons, see [Claude Code](/en/wiki/products/claude-code) and [Codex](/en/wiki/products/codex).

## Frequently asked questions

### Where do I download Cursor?

Use the [Cursor website](https://cursor.com/) for the official download and sign-in entry. Cursor is an AI coding editor and agent product for software development.

### Where is the Cursor CLI?

The [Cursor CLI documentation](https://docs.cursor.com/en/cli/overview) provides the command-line entry and current usage guidance; the editor Agent is documented in the [Agent overview](https://cursor.com/docs/agent/overview).

### Is Cursor free?

Cursor offers a free Hobby plan with limited Agent requests. Paid plans provide higher usage or team features; see the [official pricing page](https://cursor.com/pricing/) for the included features and limits.

### How does Cursor differ from Claude Code and Codex?

Cursor combines an editor, codebase context, and agents in one product. Claude Code and Codex emphasize their own terminal, editor, or cloud agent workflows. Compare repository access, tools, permissions, and review practices for the task at hand.
