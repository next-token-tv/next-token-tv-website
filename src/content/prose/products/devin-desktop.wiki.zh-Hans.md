## Devin Desktop 与 Windsurf

Devin Desktop 是 Windsurf 桌面 IDE 的新名称，由 [Cognition](/wiki/brands/cognition) 提供，保留原有编辑器，并加入管理本地和云端智能体的界面。官方说明这次更名以标准的自动更新推送：编辑器、扩展、工作流、设置和进行中的工作全部保留，原有计划与价格不变；JetBrains 版本的 Windsurf 插件仍按原名称单独提供。[Devin](/wiki/products/devin) 是同公司的软件工程智能体，可以通过客户端管理其任务。

## 桌面端能做什么

官方将 Devin Desktop 定位为集中管理所有智能体的指挥台（the command center for managing all your agents in one place）：

- 编辑器与智能体并存：保留 Windsurf IDE 的完整编辑体验，同时加入 Spaces、看板视图和多智能体管理等界面。
- 本地与云端会话：会话可以在自己的机器上运行，也可以在 Devin 云端运行，两边带着相同的上下文切换。
- 多智能体协作：Devin 可以把长任务拆给多个子智能体，各自产出代码提交。
- 代码审查：以代码差异（diff）的形式查看智能体的修改并逐行评审。

## 常见问题

### Windsurf 和 Devin Desktop 是什么关系？

Devin Desktop 是 Windsurf 桌面 IDE 的更名与升级：Cognition 保留原有编辑器并加入智能体管理界面，通过自动更新推送，原有的计划、价格、扩展和设置自动保留。

### Devin Desktop 和 Devin 有什么区别？

[Devin](/wiki/products/devin) 是软件工程智能体本身，网页端、团队集成和 API 都是使用它的入口；Devin Desktop 是桌面客户端，把编辑器和管理本地、云端智能体的界面放在同一个应用里。

### 从 Windsurf 更新到 Devin Desktop 会丢失数据吗？

按官方说明，更名通过自动更新完成，IDE、扩展、工作流、设置和进行中的工作全部保留，只更换名称与品牌。

### 在哪里了解或获取 Devin Desktop？

官方入口是 [devin.ai/desktop](https://devin.ai/desktop)，上手说明见[入门文档](https://docs.devin.ai/desktop/getting-started)。
