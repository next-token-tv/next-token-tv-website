## Web 2.0 Next 是什么

Web 2.0 Next 是由 Next Token（nexttoken.tv）发起的倡议网站，主张在 AI 时代回到"个人网站 + 博客 + 友情链接"的 Web 2.0 传统：自己拥有网站、发布第一手内容，并通过互相链接形成人和 AI Agent 都能理解的可信信息网络。项目代码开源在 [GitHub 仓库 web20next/web20next](https://github.com/web20next/web20next)，提供中英文双语页面，口号是"表达自己，连接他人"。

## 主张与参与方式

网站以五条宣言概括主张：拥有自己的网站并持续添加项目与写作；分享真实内容，对事实、观点和来源负责；让人和 Agent 都能了解你——提供清晰的自我介绍与证据，信息准确、及时、易懂、易于引用；用链接表达欣赏与信任，像博客 roll 时代那样互相链接；共同建设与成长，帮朋友建站、互相回应、维护共享目录。

参与方式：在 [join 页面](https://web20next.com/join)提交自己的网站进入共享目录；官方提供 GitHub Pages 与 Cloudflare Pages 建站和域名注册教程，并有面向 Agent 的指南、[llms.txt](/wiki/terms/llms-txt) 与 RSS 订阅。

## 节目中的讨论

这个想法来自节目自身的讨论。第七期"[Agent 流量、个人网站与开放接口](/weekly/007/transcript#chapter-04)"章节里，向阳乔木提出：在平台反爬的背景下，想做个人 IP 的人应当给 [AI](/wiki/terms/ai) 提供一个可以抓取的网站，做一个对 SEO 和 [GEO](/wiki/terms/geo) 友好的站点，让 AI 更了解你做的事情。

第八期（2026 年 11 月 1 日录制）在"[GEO：AI 从哪里获取信息，又相信谁？](/weekly/008/transcript#chapter-08)"与"[个人网站与友情链接：建立自己的信息来源](/weekly/008/transcript#chapter-09)"两个章节中继续展开：

- [杨攀介绍几位主理人各有域名、互相做友情链接，目的是自己定义自己的信息，在网上有一个人人可引用的 SSOT（Single Source of Truth）](/weekly/008/transcript#quote-03a142f9fb8ae82d0a63)；他在网站上写了零成本建站的指引——托管到 GitHub 或 Cloudflare，每年只花几十元注册域名，复制一条指令交给 Agent 就能完成。
- [歸藏把互相链接理解为"认证"](/weekly/008/transcript#quote-7c1303c80562a9186c9c)：声明这些信息是真实的、我希望向外界传达的形象是这样的；他还提到，如果一个人只活跃在单一平台上，被 AI 幻觉污蔑时几乎没有申辩渠道，所以应当确保自己的真实内容能被 AI 获取。
- 橘子说[这就叫 Trusted Network](/weekly/008/transcript#quote-1dfe190cd49c9cc0dc76)，并说这是 [Instinct](/wiki/products/instinct) 吹的概念；他还提出["人类商业的本质是信任"](/weekly/008/transcript#quote-67beb4a53e921b183b1a)。杨攀提到，[硅谷也有很多人在做类似的事](/weekly/008/transcript#quote-132600184765a84a9d68)。
- [向阳乔木补充说，有的公司愿意花 50 到 100 万元](/weekly/008/transcript#quote-2b28118af4225e695340)，只为保证豆包等 AI 回答自己的电话、地址、法人信息时不出错——把公众信息拆成最小字段做成专门网站，供 AI 爬虫索引。

这些都是参与者的讨论，不代表项目的承诺或任何官方背书。

## 常见问题

### Web 2.0 Next 是什么？

它是 Next Token 发起的倡议网站：主张个人拥有网站、发布真实内容、用友情链接互相连接，让人和 AI Agent 都能通过链接理解真实的人与关系。

### 怎么加入 Web 2.0 Next？

做一个自己的个人网站，然后在 [join 页面](https://web20next.com/join)提交网址进入共享目录；也可以让有 shell 权限的 Agent 按官方指南代办。

### 建站要花钱吗？

按节目中的指引，可以零成本托管在 GitHub Pages 或 Cloudflare Pages 上，每年只需几十元的域名注册费；具体教程见[官网](https://web20next.com/)。

### Web 2.0 Next 和 SEO、GEO 有什么关系？

它的出发点是给 AI 提供可抓取、可引用的关于自己的真实信息：个人网站相当于自己控制的 [GEO](/wiki/terms/geo) 信息源，友情链接网络则为这些信息提供互证的信任结构。
