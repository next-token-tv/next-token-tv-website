## What is Qoder

Qoder is an AI agent platform for software development and multi-step tasks. The [official documentation](https://docs.qoder.com/product-series/what-is-qoder) describes it as an "agentic platform for real work" covering software development, terminal workflows, managed cloud execution, everyday productivity, and long-running digital roles, built around an end-to-end loop of understanding the task, planning, executing with tools, verifying, and iterating — rather than just chatting or suggesting.

The official entries are [qoder.com](https://qoder.com/) and [docs.qoder.com](https://docs.qoder.com/product-series/what-is-qoder). The official pages do not name an operating company; on the Weekly show, Yang Pan called it "Alibaba's Qoder", which is the participant's phrasing.

## Product forms and boundaries

Per the official documentation and site, the Qoder product family includes:

- Qoder IDE: an agentic workspace whose Quest mode handles long-running, multi-step delegation and can generate technical design documents (Specs); paired with Repo Wiki, which keeps project structure and implementation details synchronized.
- Qoder CLI: a terminal-based coding agent, extendable to scripts and automation.
- Cloud Agents: managed agents consumed through APIs, with environments, sessions, and SSE event streams for results.
- QoderWork: delegates documents, spreadsheets, research, browser, and desktop tasks.
- QoderWake: long-running "digital employees" (officially called Wakers) that carry ongoing responsibilities, such as a Software Development Wake handling feature implementation, bug fixes, and PR reviews.
- A JetBrains plugin, mobile and web apps for remote task monitoring and approvals, an Agent SDK (an npm package is listed), and enterprise governance controls.
- Billing: credit-based; the official page notes a free 2-week Pro Trial for new users, after which they can subscribe or be downgraded to a Free plan. Current plans are on the [official site](https://qoder.com/).

## FAQ

### What is Qoder?

An AI agent platform for software development and multi-step tasks, with forms spanning an IDE (with Quest delegation), a terminal CLI, managed cloud agents, office delegation (QoderWork), and digital employees (QoderWake). See the [official documentation](https://docs.qoder.com/product-series/what-is-qoder).

### Which company is behind Qoder?

The official site and documentation do not name an operating company. On the Weekly show, Yang Pan called it "Alibaba's Qoder", which is the participant's phrasing; treat the official pages as authoritative for corporate attribution.

### What forms does Qoder come in?

Per the official documentation: Qoder IDE with Quest mode, a JetBrains plugin, Qoder CLI, Cloud Agents (managed via API), QoderWork for document, spreadsheet, research, browser, and desktop tasks, QoderWake digital employees, mobile and web apps, plus an Agent SDK and enterprise governance.

### Is Qoder free?

Per the official page, new users get a free 2-week Pro Trial, after which they can subscribe or be downgraded to a Free plan; usage is metered in credits. Current plans and prices are on the [official site](https://qoder.com/).

### How do Qoder, QoderWork, and QoderWake differ?

Qoder focuses on software development; QoderWork delegates documents, spreadsheets, research, browser, and desktop tasks; QoderWake provides long-running digital employees with ongoing responsibilities. All three belong to the product family described in the official documentation and target different task types.
