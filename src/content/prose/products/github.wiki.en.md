## What GitHub is

GitHub is a code-hosting and collaboration platform for developers, officially positioned as "The complete developer platform to build, scale, and deliver secure software". It is operated by GitHub, Inc. and has been a subsidiary of [Microsoft](/en/wiki/brands/microsoft) since 2018. GitHub hosts Git — the distributed version control tool — as its foundation: version tracking comes from Git, while collaboration, automation, and software distribution come from GitHub.

## What it does and where it stops

Per the official overview, the platform's everyday capabilities include: hosting Git repositories with pull requests and issues for code review and task tracking; automating build, test, and deployment workflows with [Actions](https://github.com/features/actions); spinning up cloud dev environments with Codespaces; code security scanning and secret protection; and funding open source developers through Sponsors. On the AI side, GitHub offers the [Copilot](https://github.com/features/copilot) coding assistant, which can drive a task from issue to merge.

GitHub does not replace the team's engineering judgment: code review, permission configuration, secret handling, and dependency security remain the responsibility of the users. Free and paid plans and feature quotas change over time; the [official page](https://github.com/about) is the reference.

## Frequently asked questions

### What is GitHub?

GitHub is a Git-based code-hosting and collaboration platform: developers keep code in repositories and use pull requests, issues, and Actions for review, tracking, automation, and releases. The official positioning is on [github.com/about](https://github.com/about).

### How do GitHub and Git differ?

Git is a distributed version control tool used locally and on servers; GitHub is an online hosting and collaboration platform built on Git, adding review, automation, security, and AI services on top. You can use Git without GitHub, but the two usually go together.

### Where are GitHub's website and sign-up?

The site is [github.com](https://github.com/), and accounts can be created from the front page; the platform overview is on the [About page](https://github.com/about). Desktop, mobile, and command-line clients all start from official pages.

### What is GitHub Copilot?

Copilot is GitHub's official AI coding assistant, described as helping you "write better code with AI" and able to drive tasks from issue to merge. Features, plans, and pricing are on the [Copilot page](https://github.com/features/copilot/).

### How do I download open source code from GitHub?

Every repository's Code button offers the clone URL and a packaged download; cloning requires Git installed locally. Follow [GitHub Docs](https://docs.github.com/) for the details.
