## Microsoft Azure

Microsoft Azure 是[微软](/wiki/brands/microsoft)的云计算平台，官方定义其为"云计算平台"，用于在云端构建、部署和管理解决方案（见[官方页面](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-azure/)）。平台于 2008 年 10 月在微软开发者大会上公布，2010 年 2 月以 Windows Azure 名称正式商用，2014 年 3 月更名为 Microsoft Azure（据[英文维基百科](https://en.wikipedia.org/wiki/Microsoft_Azure)）。

## 主要服务类别

官方页面把 Azure 的服务归为计算（虚拟机、无服务器、容器与 Kubernetes）、存储与数据库（Azure SQL、Cosmos DB 等）、网络、分析与数据（Fabric、Databricks）、AI 与机器学习（Azure AI Foundry、Azure OpenAI、Azure Machine Learning），以及安全、治理与管理等类别。

## 常见问题

### Microsoft Azure 是什么？

微软的云计算平台，提供计算、存储、数据库、网络、分析与 AI 等云服务，官方定义见[什么是 Azure 页面](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-azure/)。

### Azure 是哪一年推出的？

平台 2008 年 10 月公布，2010 年 2 月以 Windows Azure 名称正式商用，2014 年 3 月更名为 Microsoft Azure（据英文维基百科）。

### Azure 是哪家公司的产品？

[微软](/wiki/brands/microsoft)。

### Azure 上有哪些 AI 相关服务？

官方页面列出的 AI 与机器学习类别包括 Azure AI Foundry、Azure OpenAI 与 Azure Machine Learning 等。
