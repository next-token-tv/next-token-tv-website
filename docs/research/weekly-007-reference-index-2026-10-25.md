- 游戏语境中的 PS 指 PlayStation；Photoshop 的完整名称仍关联图像编辑产品。
- “骆一航”保留逐字稿原文，本期映射到品玩公开介绍中的骆轶航。
- “点评”仅在第 03 章指向大众点评；其余章节中的普通动词或名词不建立该链接。
- 小爱在旧音箱改造语境中指硬件系列；小智指 xiaozhi-esp32 软件。
- YouMind 的 for-agents 网址关联现有产品，不另建重复条目。
- DeepSeek 公司、模型、对话应用、Search / Fetch API 与 Harness 分别对应其实际层次。
- Mac 泛称遵循既有收录规则，不建立单独的 Mac 总条目；明确的 Mac 系统写法关联 macOS。
- 观猹按媒体与社区品牌收录，观猹大会统一关联观猹，不单列条目。
- 第 04 章的“金刚”指姚金刚；仅在本期使用该简称映射。
- AI、Token、MCP、RSI、eSIM 等通用概念属于术语，不按产品新建；Echo、Be Real 在本期是普通表达。
