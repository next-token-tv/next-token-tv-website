# Wiki 正文与引用

正文覆盖 183 个实体，各有中文和英文版本：产品 112 篇（全部）、品牌 56 篇（全部）、人物 15 篇（除 4 位主理人外全部）。当前不增加术语或概念类型；各批次的 FAQ 需求线索、事实核验记录与跳过理由见 `docs/research/`。

## 正文

本地化 Markdown 位于 `src/content/prose/`，使用 `slot: wiki` 与现有实体 ID 关联。同一实体每种语言最多一篇。正文的 `updatedAt` 为编辑日期，独立于 YAML 事实的 `lastVerifiedAt`；日期不随构建自动更新。可选 `seoTitle` 与 `seoDescription` 描述该语言实际正文。正文介绍保持百科式的时间稳定性：定位与用途优先写与阅读时间无关的稳定事实，历史事件写明具体日期；时效状态优先链接官方实时页面，必要时以"截至 YYYY 年 M 月"锚定，不使用"核验日／本次核验时"等过程性基准，详见[编辑规范](wiki-editorial-plan.md)的"时间稳定性与表述口径"。

页面提供正文、页内目录、面包屑和更新日期。标题区以紧凑黑色横向身份卡搭配文字标题、摘要和可展开的别名列表，卡片以本语言的领域或产品分类为主标题，以品牌／产品为顶部标签（1rem），Next Token / Wiki 为底部署名，并保留橙色标记；正文更新与资料核验日期并列收纳在目录下方，不在底部重复显示。页面原有 H1 保留，Markdown 从 H2 开始。没有正文的实体页面保留现有展示。已有摘要型语言版本继续存在，不因另一语言增加正文而移除语言互链。

有正文的详情页采用内容型布局：基本信息、官方链接、实体关系与相关节目使用紧凑标题和信息行，不显示展示型章节编号，不设置大面积固定高度卡片。页面中段的资料区块上下内边距为 1.5rem，标题为 1.25rem；页头页脚保持站点原有设计。

每篇样板正文包含常见问题，位于介绍和讨论之后、来源之前。问题使用 H3，回答以简短正文直接显示；FAQ 的 H2 进入页内目录。问题根据[关键词与效果口径](wiki-faq-keywords.md)中的搜索需求线索筛选，实际搜索量和点击表现缺失时不宣称热门或高命中；答案依托已核验资料，不批量重复无关问题，不默认折叠或依赖脚本加载。FAQ 不额外生成独立 URL。

正文不进入公开 Wiki API v1；既有实体 ID、URL、数据类型和关系来源不变。事实与经历引用可靠来源；节目观点说明发言人及语境，不把被讨论人物描述为节目参与者。英文文章可以明确标注并引用中文原文，不生成不存在的英文文字稿链接。

## 逐字稿精确引用

章节链接适合引用完整讨论；段落链接适合引用某位发言人的具体一段话。每段右侧的 `¶` 是原生链接，启用 JavaScript 后可复制正式站点的段落 URL。剪贴板不可用时提供可选取的链接文本；无 JavaScript 时仍可通过链接定位并高亮。

段落锚点由发言人身份与归一化原文生成，不依赖换行、章节序号、发言顺序或实体链接标记。插入无关文字不改变原段落的锚点。相同发言人的重复原文使用全文出现次序消歧；修改原文、修正发言人或在相同原文之前插入同样的段落可能改变引用目标。此时需复核已有引用，不能将内容指纹视为跨编辑版本的永久 ID。

不生成行号或未经核验的播放时间。已有 chapter 链接与用于搜索的 turn 链接保留。

产品、品牌和人物正文页的页头视觉区域统一高度：桌面 12rem，窄屏 9rem。人物使用该区域内水平及垂直居中的正方形头像；未配置头像时使用正方形占位卡，主文字取当前语言的短别名（中文卡用含中文的别名，英文卡用纯拉丁别名；页面存在中文别名时英文卡直接用英文全名），无合用别名时显示当前语言完整姓名，不做首字缩拼。三类正文页共用左右栏比例。

三类正文页的身份卡共用同一组件，统一顶部分类标签、橙色标记、分类或姓名主文字、底部 Next Token / Wiki 署名及分隔线。人物正方形卡片与品牌／产品面板同高，在左栏水平居中。人物详情页使用“全部人物”返回链接，分类切换保留在人物列表页。

三类正文页统一使用共享页头与资料区布局：返回导航、正文和辅助资料各自使用同一级 `.shell` 容器，分割线跨容器宽度，文字保留统一左右内边距。标题、正文与资料内容共用栏位比例和间距。

品牌、产品与人物详情的相关节目统一使用 `RelatedEpisodes.astro`，标题为“在 Next Token 中出现”（英文 Mentioned on Next Token），位于详情主体的最后。人物相关文字稿章节归在对应节目行下方，章节提及的节目也纳入列表；节目按期号倒序排列。
