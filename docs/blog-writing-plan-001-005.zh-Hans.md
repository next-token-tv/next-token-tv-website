状态：待选题审核。日期：2026-10-10。

节目中的产品体验以录制时为背景。本计划提炼素材，没有把新闻、产品参数、财务数字、技术推断或法律判断重新核实为事实；每张选题卡列出的边界决定正式写作前还需补什么。**“优先”表示值得先写，不表示事实核验或发布审批已经完成。**

### B01 · 便宜模型正在打开新的使用场景

**建议：后续。核心问题：** 解释便宜模型怎样扩大使用范围，以及复杂任务为什么仍可能值得用强模型。

**可写要点：** 免费试用如何降低尝试成本；高频消费与复杂创造的成本差异；Flash 与前沿模型的任务分工。

**素材出处：** [#001 §03](https://nexttoken.tv/weekly/001/transcript#quote-881880fdb8b857214f65)、[#001 §05](https://nexttoken.tv/weekly/001/transcript#quote-360aa28ae0369e21ed0d)、[#001 §08](https://nexttoken.tv/weekly/001/transcript#quote-8e051d18a5e240b395d3)、[#001 §28](https://nexttoken.tv/weekly/001/transcript#quote-ebd320ef41ad24c06f00)、[#001 §29](https://nexttoken.tv/weekly/001/transcript#quote-9b5b4f7d38e7aa45cd3f)；[#002 §09](https://nexttoken.tv/weekly/002/transcript#quote-27320234708134896512)、[#002 §11](https://nexttoken.tv/weekly/002/transcript#quote-d173d51323547eede732)、[#002 §27](https://nexttoken.tv/weekly/002/transcript#quote-31dc54abe1a50f6cb37b)；[#004 §05](https://nexttoken.tv/weekly/004/transcript#quote-fce4150dc8436f3df1c6)。

**边界与补充：** 不做当前模型排名；价格、额度与性能数字需按写作时点核验，保留使用者之间的分歧。

### B02 · 把真实任务放进模型评测

**建议：后续。核心问题：** 从实际任务出发，解释模型、工具和运行框架共同决定最终体验。

**可写要点：** Harness 完成率与 Token 成本；免费试用产生真实案例；3D 演示容易被感知，但不代表全部能力；持续更新让静态排名迅速过时。；写作、检索与编程需要不同的测试任务。

**素材出处：** [#001 §06](https://nexttoken.tv/weekly/001/transcript#quote-92ea5ff79896fd00a92a)、[#001 §08](https://nexttoken.tv/weekly/001/transcript#quote-8e051d18a5e240b395d3)、[#001 §13](https://nexttoken.tv/weekly/001/transcript#quote-ea83290f01de720c5c8a)；[#002 §03](https://nexttoken.tv/weekly/002/transcript#quote-ccd9509479ed2535f667)、[#002 §06](https://nexttoken.tv/weekly/002/transcript#quote-f04e99372001a9cb9a60)、[#002 §26](https://nexttoken.tv/weekly/002/transcript#quote-e1f2ecea0247c377ea85)、[#002 §07](https://nexttoken.tv/weekly/002/transcript#quote-67d0fdcd92dbde4dd820)；[#003 §10](https://nexttoken.tv/weekly/003/transcript#quote-283872caf0ef6a74a2ce)。

**边界与补充：** 不照搬榜单名次；缓存故障、搜索失败原因与内部训练机制都不能用讨论中的推测定论。

### B03 · 模型名没变，工作流为什么变了？

**建议：后续。核心问题：** 把“模型变笨”的争论拆成可观察的服务变化与稳定性问题。

**可写要点：** 滚动版本与静态模型 ID；更新、路由、计价和兼容性不是同一件事；用户体感和服务商评测都需要复现场景；把失败案例留下来。

**素材出处：** [#001 §13](https://nexttoken.tv/weekly/001/transcript#quote-ea83290f01de720c5c8a)；[#002 §12](https://nexttoken.tv/weekly/002/transcript#quote-3c040c2168faa3d31861)、[#002 §26](https://nexttoken.tv/weekly/002/transcript#quote-e1f2ecea0247c377ea85)。

**边界与补充：** 不指控厂商故意降智；需要补同一任务的版本、设置、输出记录，材料暂不支持故障归因。

### B04 · 从卖 Token 到交付服务：AI 应用的利润空间

**建议：后续。核心问题：** 讨论把模型能力变成可用服务的价值与成本结构。

**可写要点：** 多模态 API 难接、首字延迟与体验摩擦；单纯转售折扣和完整服务的区别；模型便宜之后才可能出现的毛利空间；Token 作为服务计量的比喻。

**素材出处：** [#001 §09](https://nexttoken.tv/weekly/001/transcript#quote-2c8334a1b5f3e32dd231)、[#001 §10](https://nexttoken.tv/weekly/001/transcript#quote-399df2fd435fe42658e5)、[#001 §28](https://nexttoken.tv/weekly/001/transcript#quote-ebd320ef41ad24c06f00)、[#001 §31](https://nexttoken.tv/weekly/001/transcript#quote-0783c632245d53cdf8af)；[#004 §13](https://nexttoken.tv/weekly/004/transcript#quote-36409c36b11adf09038f)；[#005 §13](https://nexttoken.tv/weekly/005/transcript#quote-f1bd249d3df8eb132717)。

**边界与补充：** “Token 是货币”是比喻；不复述未经核实的财务数字，不把预收款当利润，不把具体毛利率当普遍门槛。
