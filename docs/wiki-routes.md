# Wiki routes

- Brand, product and person directories and profiles live under `/wiki/brands/`, `/wiki/products/` and `/wiki/people/`.
- English routes use the `/en/wiki/` prefix.
- All person profiles, including co-hosts, use the same wiki namespace.
- Catalog IDs and YAML locations remain unchanged. Transcript URLs are regenerated by the importer.
- Legacy directory and profile URLs redirect permanently via `public/_redirects`. These deployment redirects do not run in Astro preview.
- Canonical URLs, language alternates, social previews, navigation and sitemaps use the new routes.
