# 火线解读 Jev 新范式；用 Agent 还得买带鱼屏？

三百多条记忆交给一个模型，没有换来一篇总结。

它被要求做的是打分：哪些值得留下，哪些可以舍弃。一次初步试用下来，大约十八条信息被整理了出来。按试用者的观察，模型更偏好抽象的内容，对零碎琐事没那么留情。

这个模型叫 Jev。它不负责把话说得漂亮，甚至不负责说一段话。给出选择、分数，或者一个是非判断，就是它的工作。

这听上去像把语言模型的本事削掉了一大半。可对有些任务来说，少掉的恰好是多余的部分。

## 一万个好友，不需要一万篇分析

另一个试用的规模大得多：约一万名微信好友，二十多个标签。

材料已经有了——聊天记录、共同群组。难的是逐个判断，这个人是不是创始人，是不是 CTO，还符合哪些身份。让模型为每个人写一份分析，既慢，也不是程序真正需要的结果。

于是，标签被拆开了。每次只判断一项，返回“是”或“否”，再去判断下一项。一个人可以拥有多个标签，但不必在一次回答里把它们全部选出来。

任务变成了许多互不依赖的小判断，可以并行运行。同一种思路还被用来扫描每天的聊天，寻找待办事项和重要信息。

这才是 Jev 比较有吸引力的位置：不在聊天框里等待提问，而在程序中反复完成某一步。

但规模大，不代表收益一定大。假如某个环节原本只占工作量的 1%，把它优化 90%，整体也只改善 0.9%。一个足够炫的演示，可能只是优化了本来就不太重要的部分。

好友标签的任务在录制时还没全部跑完，对照测试也没做完。速度和初步结果让人愿意继续试，至于它是否真的比其他小模型更合适，还得等结果。

## 一个干净的答案，也可能是错的

Jev 的简洁还容易带来一种错觉：既然输出如此确定，答案似乎也应该很可靠。

但返回格式和判断准确率是两件事。

传统语言模型输出 JSON，偶尔会把格式弄错，程序因此需要重试、补救。稳定的结构化输出能省掉这类麻烦。至于这个人究竟是不是 CTO，这条信息到底值不值得保留，它仍可能判断错误。

节目中提到的限制也没有消失：多跳推理、复杂指代、计算、日期处理，以及无关上下文的干扰。

因此，smart if else 是个颇贴切的比喻。程序原来需要人写条件，现在其中一些难以穷举的条件交给模型判断。它可以是一个好用的部件，不必因此被期待成一套完整的大脑。

## 配乐的出处，居然是代码

创作工具里也出现了意料之外的用法。

一次软件宣传视频的制作中，配乐起初被以为来自素材网站。追问之后，才发现它是用代码制作的。再加上通过 Blender 生成画面的能力，很容易让人产生一个猜想：通用模型继续变强，会不会顺手把专用模型的工作做掉？

这个猜想在对谈中没有达成一致。

能完成一次配乐，不等于覆盖所有音乐需求。能生成画面，也不等于专用工具失去价值。像 Arrow 这样的 SVG 生成能力，仍能对应图标、设计和印刷里的具体需要；区别或许是用户直接操作它，还是由 Agent 在后台调用它。

多模态还有另一层难度。一段影片的声音、画面和转场共同表达意思，拆成几份文字描述之后，那些关系未必还在。把工具接起来，与把内容一起理解，并不是同一道题。

## 另一件事：屏幕真的放不下了

本期另一个热点不需要那么多想象，它就在显示器上。

Codex 内置浏览器之后，一侧要放会话列表，中间要聊天，旁边还要看网页。如果网页仍想保留原来的宽度，新增的区域从哪里找空间？

买带鱼屏的念头，就是这样来的。

不是 Agent 规定了什么硬件门槛，而是日常工作突然有了多个需要同时看见的区域。关掉聊天区不方便，缩小网页也难受，普通比例的屏幕越分越局促。

不过，加宽只能解决一部分。点开链接，有时在侧栏，有时跳出独立窗口；同一项目的网页散在不同标签页里。窗口在哪里、内容属于哪个任务，这些问题不会随着屏幕尺寸一起变好。

浏览器里加入 Agent，和 Agent 里加入浏览器，因此成了两种值得分开看的路线。对后者的期待，是任务和相关网页能待在一起。它能否成为更顺手的工作方式，还要看这些细节是否真正接上。

## 硬盘先满，入口又多

显示空间之外，存储空间也在报警。

一段个人经历很有代表性：512 GB 开始不够用，换成 2 TB，约三个月又用掉了 1 TB。里面不全是 AI 作品，还有依赖、工作副本、浏览器缓存、虚拟机，以及原始视频素材。

它不是一份购机建议，而是一笔容易被忽略的使用成本。东西做得快了，文件并不会自己整理好。归档可以等，工作文件不能等；便宜的冷存储是否合适，取决于取回时能不能接受等待。

软件入口也在增加。Coding、Office、项目、会话、云端任务——功能各有理由，但用户开始工作之前，要先学会多少分类？

如果只是想完成一件事，先判断它属于 Work 还是 Code，未必是必要的一步。界面可以少问一个问题，未必就少一种能力。

## 做出来之后呢？

视频能做了，配乐也能做了。原来因为不会剪辑、不会制作而停在脑子里的想法，开始有机会成为作品。

但作品完成，不代表有人会看。

观众的一天没有变长。制作的门槛降低之后，什么值得表达、如何找到受众，依然不会自动得到答案。

片子导出了，文件存好了。接下来，才轮到它去面对观众。
