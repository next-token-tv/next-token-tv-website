## 编辑目标

读者即使没有听过节目，也愿意从开头读下去。用具体场景、细节、转折、悬念和有节制的判断推进文章，让读者不断获得新信息。文字有作者的观察和节奏，但不要靠夸张金句、连续反问或空泛的“时代变化”制造兴奋感。

文章以第三人称讲事情本身，不要频繁出现四位主理人的名字，也不要反复写“某某说”“节目中讨论到”。确有必要时，可以给个人经验、原话或有分歧的判断标明归属；不能为了省略姓名，把单次试用写成已验证的普遍事实。保留对立意见、不确定性与尚未完成的测试。

标题尽量沿用正式标题的原意：Jev 与带鱼屏是两个热点，并没有被证实的因果关系。可以在篇章中依次处理，不要虚构一个“Jev 导致 Agent 占据工作台”之类的统一主线。文章仍应覆盖两者，并可取舍节目中的多模态、专用工具、存储、界面入口、内容创作等相关话题；不要为了逐项覆盖而牺牲阅读节奏。

特别注意：Jev 的三百多条记忆、约十八条结果、一万名好友与标签、1% × 90% 的例子，均来自节目中的试用或说明，不是独立性能评测。带鱼屏来自特定 Codex 界面下的个人使用体验，不是使用 Agent 的硬件要求。专用模型是否被取代、浏览器与 Agent 哪种路线会赢，都属于观点，不是定论。涉及模型价格、性能、外部产品现状等可能变化的事实，如未另行核实，不要写成当前事实。
