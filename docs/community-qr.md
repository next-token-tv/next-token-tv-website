# 社群二维码

首页「找到我们」、页脚「加入社群」以及每期中英文详情页共用 `src/content/data/shows/next-token-weekly.yaml` 中的 `community` 配置。历史节目始终展示最新入群码。二维码无需按期重复上传到官网。

## 更新命令

```sh
npm run community:qr -- --input /absolute/path/to/wechat-group.png --valid-before 2026-10-15 --group "听友 2 群"
```

`--valid-before` 为微信原图标明的失效日期，不含当天，按上海时区展示。日期须随每次新码更新，重新绘制不会延长微信邀请的有效期。生成程序不会访问邀请地址或验证群是否已满、是否被撤销。

程序在本地读取原始图片，提取 `https://weixin.qq.com/g/` 入群地址，生成米白底、黑色码点的方形 SVG，并生成供手机保存的 PNG。二维码保持完整四模块静区，中央使用绿色微信 Logo 和白色底，底块不超过码区宽度的 23%，不叠加标题或装饰文字；在 144、156、176、280、320、720 像素下回读校验邀请内容一致后，才更新节目 YAML。输出文件名包含有效期与内容摘要，避免旧码缓存。原图保留，不会被覆盖。

交付文件位于 `public/assets/community/`，SVG 为展示图，PNG 为相册识别与下载图。页面在二维码旁显示入群标题、有效期和保存入口，使用品牌橙色小方块点缀。`qrImage`、`qrPngImage`、宽高、描述、替代文字和 `qrValidBefore` 由命令同步更新；重建与部署仍需单独执行。

页面显示有效期，并在客户端按上海日期隐藏已到期的二维码，保留更新提示和 Discord 入口。新码仍需从微信取得。手机端可保存 PNG 后在微信「扫一扫」中从相册选择；实际入群状态需在微信确认。

小宇宙等外部平台的已发布二维码须由对应发布会话另行更新；官网命令不修改外部平台。
