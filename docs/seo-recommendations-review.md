# SEO 专案：飞书建议取舍与实施范围

评估日期：2026-10-03。来源：[《Next Token 网站增长与改造方案｜SEO、GEO、内容结构和导流》](https://xiangyangqiaomu.feishu.cn/docx/NIuEdglInoiu2wxTwHecYlqfnTQ)，页面标注最后更新为 9 月 21 日；A1–A4、B0–B16 已读取。评估基线为官网仓库 `78ddb74`；下列实施状态以当前工作区为准。

本文记录建议取舍与实施范围。首批改动已写入本地工作区，尚未部署。原文的现场数据属于 9 月 21 日快照，不能当作当前页面数量、故障或性能基线。

## 结论

建议接受原文的主要方向：让节目原始内容持续补充已有知识页，保留事实来源、观点归属与稳定链接，帮助读者从问题进入具体讨论，再找到节目。

优先做基础修复、首页品牌摘要和实体独立分享图；以已有单集文章和 Wiki 做内容复用试点。暂缓同时建设专题、概念、指南、全站搜索和完整自动化内容系统。保留当前文字稿的逐次实体链接规则、筛选 URL 与设计规范，不照搬原文的产品参数。

原文已经明确反对批量薄页、伪造评测、特殊 GEO 格式承诺和为了 SEO 重写技术栈。这些是双方一致的原则，不是原文中需要驳回的建议。

## 首批实施状态

- HTTP 入口：新增 Cloudflare Worker，生产域名 HTTP 请求返回 308，并通过静态资源路由合并旧路径与尾斜杠跳转。仅部署后生效；Worker-first 请求计入 Worker 用量。
- 首页摘要：中英文使用稳定品牌介绍，OG 摘要同步，不再拼接最新一期内容。
- 实体分享图：品牌与产品中英文页面生成 502 张独立 1200×630 PNG；发布检查验证规范 URL、摘要、图片引用及尺寸。PNG 与清单在构建时生成，不进入 Git；发布产物不保留旧哈希图片。
- 预告状态：录制安排使用“进度待确认”的静态中性文案，已进入后期的节目继续显示“节目制作中”。页面、列表、分享图和 llms.txt 共用状态文案；日期经过本身不被当作录制或发布完成的证据。
- URL 规范：README 统一为非根路径不带尾斜杠；精确重定向规则排在通配规则前，161 条规则均被本地资源路由接受。
- 内容试点：[三个实体页的双语正文](seo-content-pilot.md)基于 Weekly #001、#002，附来源段落与证据边界，已应用至六篇本地中英文 Wiki 正文，待部署。
- 效果基线：已核实 GSC 资源、Sitemap 成功状态与 GA4 数据流接收；后台读数保存在网站仓库外的 `../seo-reports/2026-10-03.md`。新增平台出站、成功复制引用事件已通过本地模拟验证；上线接收与可比窗口导出尚待完成。

## 首批交付范围

### 1. 修复已知入口与展示缺口

- HTTP 样本永久跳到最终 HTTPS 地址；检查根路径、单集、实体页及尾斜杠组合，查询参数保留，404 行为正常。
- 首页中英文 description 说明长期定位，不拼接最新一期导语；单集保留自己的摘要。
- 品牌和产品有同语种独立 OG 图；抽样主题、缩略图可读性、匿名访问和 MIME 正确。
- 统一 README 的 URL 事实；复核预告跨日期行为，保留文字稿先发、音频先发等独立状态。

### 2. 用现有内容结构做小规模验证

建议选择 1–2 期已批准原文和 3–5 个相关实体作为工作量范围，不是建页门槛。复用单集文章、Wiki 及其来源链接；不预先要求每个样本都产生新文章。

每项编辑产物应有：所回答的问题、目标既有 URL、来源段落、事实／经验／预测归属、需补的证据、内容差异、受影响中英文页面。交付可以是更新旧页、保留原文或形成草稿；新页面需有独立价值。

验收：同一来源重复处理不重复建页；观点和事实不混淆；不覆盖无关人工编辑；旧段落链接有效；读者能从实体／文章回到原文与节目。试点之后再决定是否需要 ContentUnit 或专题集合。

### 3. 建立可解释的效果基线

核验 Search Console 与 GA4 实际状态，按页面类型、语言、品牌／非品牌查询观察等长 28 天窗口。CTR 用总点击除以总曝光；新页先积累基线。少量平台出站和复制引用事件先验证再使用，不把点击当作实际收听或订阅。

AI 提及、引用链接、错误引用与来源访问分别记录；这些抽样不能代表全平台份额。暂无数据的指标记为 N/A，不承诺排名、增长或引用效果。
